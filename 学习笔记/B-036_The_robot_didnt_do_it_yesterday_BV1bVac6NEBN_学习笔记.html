先看结论

本讲用 The robot didn’t do it yesterday 收束这一轮过去式句型。表面上是第三人称否定，底层任务却是把过去式的预热、规则／不规则动词、时间短语、肯定／否定、人称和内容包串成一个可自由调用的网络。真正会不是快速背出 didn’t，而是能在过去、现在和未来的讨论之间自然穿梭。

1. 第三人称否定仍是 didn’t + 原形

【视频讲解｜约00:00–04:00】课堂指出主语是 robot，但过去否定不再出现三单 -s。

【语法规范化】The robot didn’t do it yesterday. 中 didn’t 已经标记过去，do 保持原形；不是 didn’t did，也不是给 do 再加三单。换成 The robot didn’t go...、The robot didn’t eat... 时，否定结构保持，过去形式由 did not 承担。

2. 四个基本方向可以成组练

【视频讲解｜约00:00–02:00；约04:00–12:00】课堂回顾第一、第三人称的肯定／否定样本，并把过去式学习放到较长的练习周期中。

【补充示例】I did it yesterday.、I didn’t do it yesterday.、The robot did it yesterday.、The robot didn’t do it yesterday.。成人可以用四句作为方向地图，但儿童不必一次被要求完整背诵四格。

3. 规则／不规则动词要进入动词网络

【视频讲解｜约04:00–16:00】课堂谈到规则变化、常见不规则变化以及按组练习的好处。

【整理者语法校核】规则动词常见 -ed，不规则动词需逐词积累；AAA 型如 cut–cut、put–put、read–read 只是记忆分组示例，不能据此推导新词。先选绘本和生活中常见的词，再逐渐增加低频词。

4. 时间、地点和方式都能加入

【视频讲解｜约16:00–24:00】课堂把过去式与时间状语、地点状语等继续连接，并用具体事件扩展讨论。

【补充编排】The robot didn’t cut the paper yesterday.；之后可问 Where did it do it?、Why didn’t it do it?、What happened next?。工具、人物、感受和后续结果都可以来自绘本内容包，不必把过去式练成孤立句。

5. 过去式之后可以回到现在与未来

【视频讲解｜约24:00–30:00】课堂强调一个过去事件可以继续讨论现在的感受、未来的安全安排和类似经历。

【整理理解】例如机器人昨天弄伤手后，可以讨论 Is it okay now?、What will we do next time?。这不是偏离句型，而是过去式真正进入语言网络后的自然串联；安全相关内容由成人直接保护，不等待孩子先说英文。

6. 一轮互动与观察

【补充编排】纸偶机器人昨天没有完成任务，成人说 The robot didn’t do it yesterday.，孩子可先接 yesterday、didn’t 或指图；愿意时再换动词。只观察否定过去式加入后，孩子能否保留事件意义和角色信息，而不是只检查 did 的形式。
