## 一、本讲真正增加了什么

**上一讲解决“它是什么”；这一讲在指认、命名的基础上，增加“我指的是这一个／这里这个”的指示功能，并集中解释一个句型从练习到内化的五个阶段。**

本讲有两条主线，读笔记时不要只记第一条：

1. 句型主线：理解 This is … 的意思，借助近处与远处的对比认识 this / that，再逐步处理问句、否定和混合使用。
2. 方法主线：新句型怎样和旧句型一起滚动；为什么刻意练习不是考试；如何把目标句型带进 Zoom in、绘本和日常交流。

**【整理理解】** 本讲不是“把 It’s a … 换成 This is a … 然后背熟”。如果孩子不知道说话人正指着哪一个，或只有看到固定卡片顺序才会背，完整句子虽然说出来了，学习任务仍未真正完成。

## 三、复习上一讲：别把“学过”当作“已经内化”

### 1. 复习的对象不是只有句子外壳

**【视频讲解｜00:00–01:30】** 开场复习 It’s a … 的变形及其中涉及的语法，但马上回到一个更重要的问题：这些内容要通过什么形式传递给孩子？核心仍是表达功能和意思，不能只知道家长可以把陈述句变成问句。

**【整理理解】** 家长复习时可以分开看三件事：孩子是否知道所指事物、是否理解整句在做什么、是否能把熟悉名词装进句子。只看有没有说出最后一个名词，无法判断整句是否能调用。

### 2. “什么时候进入问句”不是按日历决定

**【视频讲解｜01:30–02:40】** 老师的推进依据是陈述句先说顺，再往后加。有人每天练习时间少、认识的词少，停留时间就可能更长。不能拿统一的一周或两周来证明某个家庭进度正常或异常。

**【整理理解】** 与其问“我已经练满七天，能不能升下一课”，不如观察：换成孩子熟悉的另一张卡，他还能否在少量帮助下说完整句？有没有始终重复同一种遗漏？孩子是在理解后组织，还是等成人说完再机械跟读？

这些观察是便于家长操作的归纳，不是视频给出的考试分数线。

## 四、新句型加入后，旧句型怎么安排

### 1. 新目标与旧复习并行，不是新课覆盖旧课

**【视频讲解｜02:40–03:20】** 今天加入 This is …，并不意味着之前 It’s a … 的陈述和问句全部停止。尚在练习的变形，可以继续放在闯关、循环复习或已有互动中做。

**【整理理解】** 要分清“今天集中练什么”和“生活中仍然用什么”。本轮游戏可以专注 This is …，另一轮仍可以用 It’s a …。这与把两个尚不稳定的句型每张卡交替考问，不是同一回事。

### 2. 内容包是“重点练习＋较广输入”，不是“只许出现当前句型”

**【视频讲解｜03:20–04:25】** 内容包既包含大量刻意练习，也包含其他输入、意义传递和引导输出。家长不能要求孩子把其中所有出现的表达，当天都做到同样稳定、独立、正确地输出。

**【整理理解】** 同一场互动中的语言可以分层：

- 当前目标：今天希望多练的 This is …，需要安排足够机会。
- 已知语言：孩子已经懂的鼓励、选择、动作等表达，可以自然调用。
- 铺垫语言：场景中出现的新说法，有明确意思、有成人帮助，但不以立刻掌握为前提。

错误的做法是把这三层合并成“凡听到过的，下一秒都要答得出”。

## 五、最重要的方法：句型内化的五个阶段

**【视频讲解｜04:25–07:30】** 老师将内化概括为五步。它们描述的是从支持性练习到实际调用的过程，不是五项做完一次就盖章毕业的活动。

| 阶段 | 视频中的重点 | 家长应怎样理解 |
| --- | --- | --- |
| 第一步：随机组句刻意练习 | 在辅助下说；卡住马上帮；没有考孩子的过程。 | 帮孩子成功组织，不等待孩子失败后才给分。 |
| 第二步：Zoom in 扩展 | 与以前的句型建立联系，练发散思维。 | 从当前事物展开，调用已知表达，而非只有一句反复背。 |
| 第三步：低阶绘本讨论 | 在绘本中跨句型使用，也会遇到新词。 | 让句型离开原来的卡片桌面，在新画面中仍有功能。 |
| 第四步：日常交流 | 在生活中继续使用。 | 不只在“上课时”说；遇到真实指认需要时能调用。 |
| 第五步：相近或新句型混合 | 和相近表达混用并选择。 | 不只是会两套外壳，而是知道当前场景用哪一种更合适。 |

### 第一步：辅助不是作弊，正是学习的一部分

**【视频讲解】** 在刻意练习中发现孩子不会，就马上给帮助。老师明确反对把这个过程变成考试。刚学的句型，孩子需要有一段时间在支持下组织大量句子。她在本段举出持续一到两周的练习，并指出只说十句不够；这属于说明持续性和练习量的课堂例子，不能脱离前面对个体进度的讨论，变成统一的达标期限。

**【整理理解】** 例如，孩子看到熟悉的 fish 卡只说 fish，家长可以提供开头 This is …，再与孩子一起完成。目标是使“指向具体事物—调用句型—装入名词”反复连起来，不是让孩子在沉默中证明自己不会。

帮助程度应随表现下降：完整示范、一起说、开头提示、动作提示、自然独立使用。不应把“帮助过”自动等同于“这次没价值”，也不要把“成人带着说”误报为“已经独立掌握”。

### 第二步：Zoom in 是把当前表达与已有经验连起来

**【视频讲解】** Zoom in 不只是多讲几个词，还涉及与旧句型连接、发散和趣味。它让当前刻意练习的句子置于更丰富的情境里。

**【整理理解】** 一张 fish 卡可以不只完成一句指认；还可以加声音、动作，连接孩子熟悉的交流。但扩展应该仍让孩子看得懂、参与得到，不能变成家长独白式展示自己会多少英语。

### 第三、四步：从“会做卡片题”迁移到真实内容

**【视频讲解】** 在低阶绘本和生活中使用，会同时接触其他表达和新词，这不是污染当前句型，而是它逐渐成为交流工具的过程。

**【整理理解】** 同一张鱼卡练熟后，可以换成玩具鱼、绘本里的鱼，再换成日常遇到的可指认对象。变化带来的困难如果过大，就退回熟悉词和更清晰的情境。迁移不等于突然撤掉全部帮助。

### 第五步：能混用，是更后面的要求

**【视频讲解】** 老师把相近表达的混合使用放在后面，强调有些语法的稳定会花很长时间。她以时态、第三人称单数等作说明，反对第一节就要求全对。

**【整理理解】** 视频提到的较长时间是老师用于解释学习过程的例子，不是每个孩子、每个句型都必须经历的年限。也不能倒过来理解成“既然要很久，现在怎么说都不管”。正确示范、适当帮助和不断调用仍然要做。

## 六、This is …：先把意思传递清楚

### 1. 相比 It is …，本讲增加了指示关系

**【视频讲解｜07:30–08:30】** 老师从意思出发比较 It is … 和 This is …。本讲使用的 This is … 情境，需要让孩子感到“这个／这边这个”，而不是只听见新的句子声音。

**【整理理解】** 在眼前物体指认中，this 通常指向说话人所指的近处对象；it 可以回指已有对象，不自带同样明确的近远对比。因此两个句子在某些情境都能说明同一事物，但它们并不是任何场景下完全可互换。

这里讲的是本课的物体指认用法，不穷尽 this / that 的全部英语用途。例如人物介绍、指向一段话、心理距离等，不属于本讲的集中任务。

### 2. 两条教学顺序都能走通

**【视频讲解｜08:30–10:35】** 老师认可两种思路：先在情境中辨认 this / that，再接完整句；或者先练 This is …，之后引入 That is …，再比较。

关键限制不是固定顺序，而是孩子是否开心、阶梯是否足够小、意义有没有传递清楚，以及是否根据实际反应调整。

**【整理理解】** 不能因为家长选了第一条路径，就说先做完整句的家庭一定错误；也不能因为老师认可两条路径，就把所有区别一次端给孩子。灵活是有观察依据的调整，不是无限加量。

## 七、近处和远处怎样在游戏中显出来

### 1. 摆卡片：关系清楚比数量多更重要

**【视频讲解｜10:35–11:20】** 可以把一些卡放近、另一些放远，指着说 this 或 that。视频字幕中的例句包括 This is an egg. 与 That is an egg.。

**【整理理解】** 如果一排卡挨得很近、手指方向也不清楚，孩子不但要猜名词，还要猜家长指哪张；这会让当前“已知词＋新指示表达”的任务额外变难。先少量、拉开距离、指得明确更便于理解。

### 2. 投掷游戏：动作制造近远体验

**【视频讲解｜11:20–12:00】** 老师提到借投掷等已有玩法，让落得近与落得远的东西形成对比。近处配 this，远处配 that；远处说话的声音处理，也可增加距离感。

**【整理理解】** 声音只是让情境更鲜明的辅助手段。不是“大声就一定用 that，小声就一定用 this”；this / that 的选择必须回到所指对象和说话者视角。

**【补充示例】** 用软豆袋向地面两个位置投掷，停下后再指认目标卡。不要边跑边强迫输出，也不要向人脸或易碎物品投掷。玩法服务于指认，不要让竞赛速度压过语言理解。

### 3. 阳台或窗边：有词汇基础再扩展真实对象

**【视频讲解｜12:00–12:30】** 阳台能看到远处的东西，可以用作场景；但它也带来家长是否会说相关词的问题。没有合适真实物体时，可以把熟悉卡片摆出远近。

**【整理理解】** 不要为了“真实生活”同时加入孩子完全陌生的物体、家长不确定的词和新句型。熟悉卡片同样能够传递位置关系；真实不等于必须复杂。

## 八、Zoom in：让一句指认变成孩子愿意参与的体验

### 1. “四维空间和五感”的本讲含义

**【视频讲解｜12:30–13:25】** 老师用“四维空间和五感”描述扩展的底层思路：不要只停留在平面的图片和一句话，还可以增加场景、变化和其他感受。

**【整理理解】** 本讲并未完整展开一套可直接背诵的“四维框架”，因此这里不替老师补造理论体系。可以抓住较确定的操作意图：把物体放回可感知、可互动的场景，利用孩子能理解的声音、动作等增加联系和趣味。

### 2. 游戏不用每次都严格表演句意

**【视频讲解｜13:25–15:10】** 已有的游戏可以继续用。不是每个句型都必须重新设计一个精准再现字面意思的游戏。

**【整理理解】** 需要同时保留两层：语言所指要准确，活动形式可自由。吹鱼卡、拍手或扔豆袋的形式可以不同，但说 This is a fish. 时必须清楚指向 fish，不能为热闹而让语言与对象脱节。

### 3. 初级 Zoom in 可以从音效开始

**【视频讲解｜约 15:10–16:20】** 老师给出加声音的思路，举了 egg、fish、hand 等例子；fish 可以配吹泡泡式互动。后面看到较复杂的图示时，她指出若要表达一碗面条，This is a bowl of noodles. 对当前练习可能较难，可暂时不做这张，改用较容易的 hamburger 等熟悉对象。对初期还不容易加入更复杂扩展的家长，音效就是一个可进入的小步骤。

**【整理理解】** 音效不要求家长讲长篇英语故事。它可以让一句话之后出现孩子愿意期待的结果：指认、说句子、听声音、换角色，再换一个对象。孩子参与比家长表演精彩更重要。

**【补充示例】** 拿安全的碗，用手指轻轻敲一下。家长指着说 This is a bowl.，邀请孩子一起完成，再让孩子决定下一次何时敲。若声音刺耳或孩子不喜欢，就改用拍手或无声动作，不把“音效”也变成硬任务。

## 九、问句、否定和复数：什么时候进入

### 1. 陈述稳后逐步加入一般疑问

**【视频讲解｜16:20–17:00】** 视频出现 Is this a foot? 的例子，讨论在陈述后处理一般疑问和否定。问句不是第一轮所有任务的并行起点。

**【整理理解】** 实际指认时，问句要求孩子理解“成人在核实是不是”，而不只是把 Is 移到前面。孩子可以先理解并回答，随后交换角色，逐步尝试自己发问。

### 2. 否定不是立刻说一整段，困难时可以切开

**【视频讲解｜16:45–17:40】** 老师讨论 This isn’t …、No, this isn’t 等形式，并强调给辅助、看孩子能说到哪里，必要时切小。

**【整理理解】** 切小是支持当前表达，不是长期只接受零散词。如果整句太长，先把否定意思和较短表达说顺，再逐步连成完整句。

**【补充示例】** 家长指着鱼卡问 Is this a foot?，给出 No, it isn’t. 或 No, this isn’t a foot. 的自然示范。本课若要练 this，可明确示范后一种；不要把本来也成立的 it 回答斥为语法错误。

### 3. 复数暂不作为这轮集中任务

**【视频讲解｜16:20–16:35；17:40–19:35】** 本轮不急着同步练复数；复数会在其他内容和后续课程中出现。

**【整理理解】** “暂不集中练”不等于英语里不存在复数，也不等于绘本出现复数就要删掉。当前任务先用单个、熟悉的对象做稳；新内容作为输入时，不要求孩子立即掌握其全部变化。

### 4. 与 A-001 “先不急着做否定”怎样衔接

**【整理理解】** A-001 的提醒是第一阶段不要过载；A-002 说明后续可以根据陈述稳定程度添加问句和否定。两讲不是相互矛盾，而是在讨论不同学习阶段。不能据此给所有孩子规定“第一天禁用否定，第二天必须会否定”。

## 十、孩子总说 It’s …，算错吗？

**【视频讲解｜约 18:20–20:35】** 老师回应孩子用 it 的问题：一些回答在原则上也可以成立；如果当前在练 this，就引导孩子用目标表达。两个表达还不稳定时，先不要混着考。

### 1. 交流正确性和练习目标要分开

**【整理理解】** 孩子看到鱼说 It’s a fish.，可能已经正确完成“说明它是什么”。本轮想练的是 This is a fish.，那么它没有完成本轮目标，但未必犯了语法或意义错误。

家长可以认可已表达的意思，然后自然示范目标句，而不是把孩子一次正确的交流判成全面失败。

### 2. 先按轮次分开，之后才逐卡混合

**【视频讲解】** 可以这一轮使用一个表达，下一轮再练另一个。老师不赞成两个都不稳定时，这张卡要求 it，下一张突然要求 this。

**【整理理解】** 当两个目标都能较稳定调用，再通过清晰情境练选择。不能只把两个开头随机换着念，就说已做到第五阶段的混合内化。

### 3. 本课目标不是让孩子时刻猜家长心里的标准答案

**【整理理解】** 如果家长只给一张卡，情境并未区别不同指示关系，却要求孩子猜出“我今天必须听到 this”，训练会滑向读心式考试。明确今天这一轮的玩法，给目标示范，再随着稳定程度增加变化，才与讲解的支持性练习相符。

## 十一、老师为什么反复批评“此时此刻必须说对”

**【视频讲解｜20:40–25:40】** 这一段篇幅很长。老师用名字、代词和走路等类比，说明人会在持续使用中逐渐学会。她反对将每次亲子互动都变成即时标准答案考核，希望孩子开开心心尝试说，经过时间和练习逐渐分清。

### 1. 要反对的是不合阶段的考核，不是准确表达本身

**【整理理解】** 视频并不是“语法不重要”，也不是“孩子永远不需要纠正”。相反，老师要求成人把意思传递准确，卡住时帮忙，长期继续练习。区别在于纠正的方式和期待的时间。

- 不合适：反复追问“昨天讲过，怎么还错”，让孩子当场证明自己不行。
- 更合适：提供正确示范，减少当前负荷，继续创造能成功表达的机会。
- 仍需观察：同一种错误是否越来越少、是否能离开固定提示、是否愿意继续参与。

### 2. 类比帮助理解态度，不等于科学证据

**【整理理解】** 走路和学习语言不是同一件事；类比不能直接证明某种训练一定有效。它在本讲中主要服务于“别用成人已经熟练的体验要求初学孩子立即熟练”这一提醒。

### 3. 快乐不是取消练习

**【整理理解】** 快乐和反复练习可以同时存在。若总是玩得热闹但孩子没有理解、没有被引导参与目标表达，也不等于完成本课。反过来，孩子每轮都哭闹或害怕犯错，说明当前难度或互动方式需要调整。

## 十二、语感、考试及教案：保留观点边界

### 1. 关于语感与成绩

**【视频讲解｜25:40–28:50】** 老师强调语感来自输入和输出双向运用，并表达对长期语言能力促进考试的积极看法。她在直播中使用了较强的考试成绩表述。

**【整理理解】** 可保留的方法重点是：不能只为一次答题结果牺牲长期交流能力。不能把直播中的乐观判断写成“按此方法孩子一定考 99 或 100 分”。考试结果还取决于具体题型、阅读水平、知识范围等，本视频没有提供可用于保证成绩的研究或数据。

### 2. 关于“按教案做为什么不行”

**【视频讲解｜29:10–29:44】** 老师强调要从教案抽象出模型，而不是只照着念。家长需要懂得桌面或现场互动的调整。

**【整理理解】** 可抽取的模型是：明确当前意思和目标 → 用熟悉材料示范 → 孩子卡住及时帮助 → 保持趣味 → 根据反应降阶或扩展 → 在后续场景循环调用。具体卡片数量和游戏顺序可以变，关键原则不应丢失。

## 十三、家庭练习示范：一条小步推进路线

**【补充示例｜以下是整理者另写的家庭方案，不是视频固定作业】**

### 步骤 1：准备少而熟悉的材料

先准备 3–5 个孩子能辨认的单个对象，例如 egg、fish、bowl。数量只是示范，不是规定。家长先核对表达：an egg，a fish，a bowl。此阶段不用多只鱼、不可数食物或一组新词增加难度。

### 步骤 2：先用近处对象建立指认关系

家长清楚指向桌边一张卡，说 This is a fish.。孩子只说 fish 时，家长给 This is … 的开头或一起说。不要连续问三遍还不给帮助。

### 步骤 3：随机换熟悉名词，但保留稳定任务

打乱卡片顺序，每次仍然只练 This is …。可以完成一句后轻拍桌子或做孩子喜欢的动作，让重复有互动结果。不要要求抢答速度。

### 步骤 4：若本次要引入近远对比，先提供清晰情境

家长和孩子站在相近位置，一张卡近，一张卡远；分别指认、示范 this / that。孩子不明白时减到一近一远，不同时加生词。也可选择暂不加入 that，留给下一讲。

### 步骤 5：陈述较顺后再做核实与角色互换

家长指鱼卡问 Is this a fish?，示范 Yes, it is.。再指不同卡做一次有清楚答案的核实。若孩子问句困难，由成人提供开头，不以完整自主发问作为第一轮门槛。

### 步骤 6：最后回到生活，而不是加一张测试卷

在收玩具、看绘本或找物品时，自然使用熟悉表达。游戏结束不代表句型退出生活；也不需要每看到一个物品就强迫孩子重复一遍。

## 十四、常见误读对照

| 容易误读成 | 更准确的理解 |
| --- | --- |
| 两周没完成就落后。 | 视频不设置统一进度；根据练习量和表现推进。 |
| 今天新句型，昨天的停止。 | 新目标有重点，旧目标继续循环。 |
| 内容包出现的都要立刻会。 | 集中练习、已知语言和铺垫输入的期待不同。 |
| 五步活动做过一次就叫内化。 | 要看能否跨场景理解、组织并选择调用。 |
| This is 就是 It’s 换个开头。 | 本课增加了指示和近远情境，不能只换声音。 |
| 声音大就是 that。 | 声音可增加体验，不是语法判断依据。 |
| 回答用 it 都错误。 | 先看实际情境是否成立，再看本轮目标是否完成。 |
| 不测试就不纠正。 | 继续给正确模型、支持和练习，避免即时考核式施压。 |
| 快乐等于没有学习目标。 | 仍要理解意思、参与输出、逐步提高独立程度。 |
| 老师讲过高分，就保证成绩。 | 这是直播观点，不是可验证的个体成绩承诺。 |

## 十五、练后观察与复习卡

**【整理理解】** 这些是观察方向，不是视频要求的统一测评标准。

- 所指：孩子知道我指的是哪一个，而不只是认出桌上有鱼卡吗？
- 组织：顺序打乱后，他仍能把熟悉名词放入完整句吗？
- 支持：他需要的是完整示范、开头提示，还是只需指一下？记录实际帮助，不夸大独立掌握。
- 区别：出现 this / that 时，距离与说话者视角是否清楚？
- 情绪：他愿意再玩，还是开始害怕说错？
- 迁移：在绘本或生活中，这句还会用吗？
- 滚动：It’s a … 有没有继续在合适场景中出现？

**本讲一句话复习：用准确的指示情境把 This is … 的意思讲清，在帮助下充分练习，再经过 Zoom in、绘本、日常和混合使用，逐步变成能主动调用的语言。**
