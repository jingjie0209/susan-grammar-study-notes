先看结论

本讲用 I like doing 把动作变成“我喜欢的事情”。重点不是先背动名词的术语，而是让孩子在真实选择中理解：喜欢的是一个活动。先固定 I like，接熟悉动作；之后再换一个动作或给动作加对象，不要同时把主语、态度、动作和长宾语全部随机化。

1. doing 在这里不是“正在做”

【视频讲解｜约00:00–08:00】课堂从 like 后面为什么接 doing 进入动名词，并提醒成人不要只按中文“做”去猜它的作用。

【语法校核】I like swimming. 中 swimming 是动名词，整体像一个名词性成分，表示“游泳这件事”。它不是现在进行时；现在进行时要有 be，如 I am swimming.。同一个 -ing 形式要看它在句子里的位置和功能，不能看到词尾就直接判定时态。

2. 先让孩子理解“喜欢哪件事”

【视频讲解｜约08:00–14:00】课堂把 like doing 放回日常活动，强调成人先观察孩子喜欢什么，再从孩子已经理解的动作开始。

【补充编排】可以把两张活动图放在面前：画画、跳舞。成人说 I like drawing.，再问 What do you like doing?。孩子指图、说 drawing、说 I like drawing，都能传递意思；先有选择和交流，再追求整句稳定。

3. 动名词后面还可以带对象

【视频讲解｜约14:00–18:00】课堂继续讨论动名词不是“只能单独出现的一个词”，动作本身还可以带宾语或其他成分。

【语法规范化】I like camping. 只说活动；I like sleeping in a tent. 则把地点补进去；I like reading books. 中 reading 后面还能有对象。对于幼儿，先把 like + doing 作为一个整体用熟，再逐步增加一个熟悉对象，不要把“动名词可以带宾语”变成一次性语法讲义。

4. 动名词和现在分词要分开理解

【视频讲解｜约18:00–23:00】课堂讨论 -ing 的不同功能，提醒成人不要把所有 -ing 都归成同一类。

【整理理解】I like swimming. 里 swimming 是喜欢的活动；a swimming boy 里 swimming 更像是在说明男孩正在游泳，作定语。儿童阶段不必要求说出“动名词／现在分词”，但成人要知道：形式相同不等于任务相同，先看它在句中做什么。

5. 先练一个变量，再决定是否扩展

【视频讲解｜约23:00–28:00】课堂反复强调随机组句不能靠把所有卡片同时打乱；新结构稳定后，其他位置才逐渐开放。

【补充练法】第一轮固定 I like，孩子接 drawing；第二轮仍固定 I like，只换成 singing；第三轮才给 I like reading books.。如果孩子把 like 或 doing 忘掉，成人可以给半句或直接示范，不把卡住解释成“不喜欢英语”。

6. 喜欢与不喜欢都要允许真实变化

【视频讲解｜约28:00–32:00】课堂把学习放回观点表达：孩子可以喜欢某个动作，也可以不喜欢，不要把练习做成唯一答案。

【整理边界】I like jumping. 和 I don’t like jumping. 都可能是真实表达。成人可以示范 I like reading.，孩子若说 No, I don’t.，先回应观点，再决定是否提供句型。安全、疲劳和拒绝优先于为了练句型继续追问。

7. 成人理解：like 后并不只有 doing

【整理者语法参考】I like to read. 与 I like reading. 在很多场景都能表达偏好，语气和使用习惯可能有差别；本讲只把 like doing 作为当前训练模型，不把它说成 like 后唯一合法结构。复杂的动词搭配和语体差异留给成人后续学习。

8. 一轮互动与观察

【补充编排】成人拿两张活动卡问 What do you like doing?，孩子可先选卡，成人代说 You like drawing.；愿意时再让孩子说 I like drawing.。只观察一件事：固定 I like 后，能否把一个熟悉动作作为“喜欢的事”接出来。
