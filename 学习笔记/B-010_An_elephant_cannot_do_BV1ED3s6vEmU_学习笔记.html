先看结论

本讲将 can／can’t 接到第三人称单数：An elephant can’t fly.。can 和后面动词不加 -s，但主语的冠词、指代和句子长度仍会增加负担。先固定主语或动词，再尝试双卡组合；because、拟人故事及其他情态表达都是可选扩展，不是每个孩子当轮必须完成的阶梯。

1. 不变的部分与会变的部分分开看

【视频讲解｜约00:00–04:50】课堂对比 can do 与一般现在时第三人称单数的差异：can 后不用随人称变 -s，但仍可能误加 does、to 或 -ing；名词冠词、单复数和代词也可能出错。加 because 后，又要组织另一个分句。

【语法规范化】An elephant can’t fly. / It can’t fly.；不是 An elephant can’t flies，也不说 doesn’t can fly。本轮先以清楚的普通大象作例，主语换成 Dad、the cat 等仍用 can’t + 原形。不能因此推论所有一般现在时动词都不加 -s。

【冠词提醒】a／an 看紧接词的起始发音：an elephant、an umbrella、a cat。早期由成人给整块主语，不把冠词选择变成每轮必考题。

2. 出错可能是多个任务叠加，不是能力标签

【视频讲解｜约02:00–08:10】课堂逐项梳理句子中可能出错的位置，并提醒有组织负担和停顿很正常，不拿网络上高度流利的片段当每次真实互动的标准。

【补充降级】先只说 It can’t fly.，明确 it 指眼前玩具象；较顺后再换 An elephant can’t fly.。或成人给 An elephant can’t…，孩子只接 fly。连续卡住时先拆句，非要求“多说”到自然不出错；不比较起步早晚或许诺固定年限。

3. 新词与双卡随机，什么时候才加

【视频讲解｜约08:10–11:50】课堂说明示范视频只是样本，会逐步引入词汇；出现名词与动词一起抽的组合。若双重变化难，就固定一个熟悉主语，如今天只谈爸爸，再换动作。

【整理理解】新词引入不等于新句型与陌生词同时无辅助输出。先演示新词到能理解，再放进已有框架。孩子能处理一个变量后，才考虑双卡；卡池不必全抽完，不用清点少一张就认为课程没完成。

4. 从固定到随机，留好退路

当前状态可选安排规范化示例
新主语较难固定熟悉角色，只换动作Dad can’t fly. / Dad can’t reach it.
动作较稳，想换对象固定 fly，只换清楚的单数主语An elephant can’t fly. / A cat can’t fly.
一个变量较顺且愿意玩少量名词＋动作双卡An umbrella can’t run.；明确是普通实物

【补充边界】组合不合适可换一张，也可明确 Let’s pretend. 后进入故事。想象中会跑的伞不等于现实物品会跑；机器的 run 又可能表示运转，不把所有名词与动词搭配用一个常识答案封死。

5. because 可以拆开，理由先有意思

【视频讲解｜约11:50–15:30】课堂围绕伞为什么不能跑，开放收集腿、轮子、位置等理由，并尝试让伞说话，接一个愿望或后续动作。

【补充示例】An umbrella can’t run. It has no legs.；两句熟悉后才示范 An umbrella can’t run because it has no legs.。若问 Why not?，孩子回答 No legs. 或指图也能传意，成人可温和补完整；不把日常简短回答一概判错。

【语法与逻辑校核】because 后接分句是本轮成人给的模型；because of 后接名词类结构，是另一个模型，不混成 because of it has no legs。故事中的魔法理由可接纳，但颜色、体型或人物特征不自动构成现实因果，也不借故事嘲笑真人。

6. 先听懂，再自然重述，允许停下来演

【视频讲解｜约15:30–22:50】老师建议认真听孩子想说什么，不先皱眉或急着指出错处；理解后用正确句子确认。还要给思考与表演留白，重视一次互动的质量，不只追求卡片数和句子速度。

【补充做法】孩子说 Elephant can’t flies.，成人回应 Oh, the elephant can’t fly.，继续指图或让玩偶接话。若想请他再说，可给句首，不每次强制重来。也可直接示范正确表达，不必假装听不懂；善意确认不能变成反复追问。

7. 成人拓展：be able to 与推测不照表硬背

【视频讲解｜约22:50–29:50】后段回顾能力、许可，并介绍 be able to、could 及一些推测表达。以下是语法校核，不作为儿童必达内容。

【语法校核】be able to 并非只用于书面；相较 can 常较正式，will be able to 等能表达 can 没有的某些形式。过去一次具体成功常用 was／were able to，过去一般能力常用 could，但感官动词及否定等有不同情况，不能简单说 could 一律不能指单次事件。

【重点校核】can be 可表一般可能性，不等于“百分百一定”；must be 在推测中是强推断，也不是数学保证。may、might、could 表可能时不能统一换算成固定百分比或永远不变的高低阶梯。maybe 是副词，may be 是情态动词加 be，不能按同一个词教。

8. 一轮可用互动与观察

【整理者编排】先摆玩具象，成人示范 An elephant can’t fly.，孩子可指图、接 fly，或用 It can’t fly.。愿意时固定 fly 换另一只熟悉动物；也可另轮用普通伞图片说 An umbrella can’t run.。想说理由则用已知的 It has no legs.，不强行连接 because。

【观察点】换一个熟悉单数主语后，孩子能否继续接用 can’t + 原形？若卡住，先固定主语；故事有不同设定先问清。用桌面玩偶与图片演，不飞跳、摔倒、举伞奔跑或拉真实动物来验证想象。
