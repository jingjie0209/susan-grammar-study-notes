先看结论

I want to… 是从“想要一个东西”走向“想做一件事”的新连接。先用孩子已经理解的动作，把 want to 与后面的原形接起来；to 漏了或句长增加后旧部分出错，都先减负、自然示范。成人可理解语法背景，但不把非谓语术语和整张用法表变成儿童任务。

1. 从 want 加名词，走到 want to 加动作

【视频讲解｜约00:00–06:00】课堂回顾已有动词模型，并用 want to do 说明两个动作相关表达如何连接，介绍有限与非有限动词作为成人背景。

【语法规范化】I want an apple. 表示想要苹果；I want to eat an apple. 表示想吃苹果。后一句的目标结构是 want + to + 动词原形，不是 want eat，也不把标题的 do 再额外接在 eat 前。先用 swim、draw 等熟悉动作，不一次解释所有动词搭配。

2. 儿童可以先用，不需要先背术语

【视频讲解｜约10:00–18:00】老师用“会按按钮不必先抄说明书”作比喻，强调在有意义的输入与输出中建立可调用的模型，再遇到类似结构时继续练习。

【整理边界】这不是说语法解释、阅读或听力没有价值，也不是学会 want to 后所有相似动词都自动掌握。成人可用简短说明辅助理解；孩子主要借情境知道“我想做什么”，从模仿、接词到自主表达逐步撤提示。

3. 成人语法校核：to do 不是万能的“目的、将来”公式

【视频讲解｜约04:00–12:00】课堂用 to do／doing／done 的一些典型倾向帮助成人联想，并谈到 plan、decide 等结构。

【语法校核】具体动词后接哪一种形式，仍取决于词的搭配与语义；不能只按“将来还是持续”选 to／-ing。to 不定式不总表示将来，-ing 也不总表示正在进行，过去分词也不总是被动。更不能把“一个句子只能有一个动词”推广到并列、从句等全部句式。本讲只把 want to + 原形先说清。

4. 长句听不清时，把连接位置托出来

【视频讲解｜约24:00–28:00】课堂提醒新模型容易漏 to，并示范在有交流意义的短问短答中，让 want to 多次被听到；不要只盯着第一次是否说全长句。

【补充示例】玩偶拿起画笔，成人说 I want to draw.；再问 Do you want to draw?。孩子可答 Yes，或接 draw。成人给 I want to…，孩子接 draw，再示范整句；不让一个单词反复背到厌烦后才进入活动。

5. 先固定 I want to，再换熟悉动作

【补充编排】第一轮只换 draw／sing／swim 等已知动作；如果需要宾语，先保持一个熟悉对象，如 draw a cat。别同时换动作、对象、冠词和数量。孩子提出自己更想做的事，就优先接他的意思，不要求抽到哪个就必须想做哪个。

意思规范例句注意
想画画I want to draw.不加 -ing
想画一只猫I want to draw a cat.宾语是另一个负担
只想要画笔I want the pen.不是每次都加 to

6. 卡住时先支持，不把一轮当作完成考试

【视频讲解｜约26:00–28:50】老师强调新模型需要建立机会，能跟读固定段落，不等于换一张卡后能立即组织新句。课堂的几天、几轮等例子，不是所有孩子的期限。

【补充练法】漏 to 时，成人按孩子的意思自然重述 You want to draw.，再把 I want to… 给他接用；若不想复说，就由成人完成示范并继续玩。先确认意愿，不把纠正变成不断要求“再说一遍”。

7. 同义表达留在适合的场景再学

【视频讲解｜约18:00–24:00】后段列举 would like to、feel like doing、hope 等表达，提醒不要因为成人觉得基础句简单就一开始堆很多形式。

【语法与语用校核】I’d like to… 并非只能成人、陌生人或高阶儿童使用；有熟悉情境时可以自然输入，只是不要求本轮全部输出。hope、wish 不能换算成固定成功概率，intend to 也不只见于学术文本。不要把同义词表当晋级标准。

8. 绘本连接与观察

【补充示例】看到人物画画，成人说 He’s drawing.，转向孩子问 Do you want to draw?。愿意就用小纸画一下；不愿意则接纳 No。想说原因可另给 It’s fun.，不要求每次接 because，也不拿真实危险动作演飞行。

【观察点】换一个熟悉动作后，孩子还能用 want to 接原形吗？回看：约00:00–12:00成人结构解释及本页校核；12:00–18:00模型与使用；24:00–28:50分段示范、降低新模型负担。只挑一个当前能参与的目标。
