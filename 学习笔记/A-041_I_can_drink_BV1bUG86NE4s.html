A-041｜I can drink：把正反句连成一个小主题

来源与阅读说明

原视频：https://www.bilibili.com/video/BV1bUG86NE4s/

本笔记依据主转写分段通读、关键窗口第二模型识别对照与视频画面抽样整理；不是人工逐字听写或完整字幕校订，也不替代原视频。

【视频讲解】概括课堂内容；【整理理解／语法规范化】区分整理判断与规范；【补充示例／练法】为便于使用新增，并非原话。时间为定位用近似范围。

---

1. 不只练肯定句：同一个 drink 也能做正反和提问

【视频讲解｜约00:00–03:00】老师开场提醒，引导输出样本不只是 I can drink，还出现不能喝的东西和疑问句。固定 drink 时，可以练 I can drink…、I can’t drink…、Can I drink…?；其中“能不能喝”可以服务于饮食、安全性和选择等话题，而不只是说一种能力。

【语法规范化】can 后接动词原形，不随主语变成 drinks；否定为 can’t / cannot，提问把 can 放在主语前。实际表达是在说能力、许可还是合适与否，要看语境，不把所有 can 都翻译成“有能力”。

2. 本讲真正的跃迁：几句话开始服务于同一主题

【视频讲解｜约03:00–10:00】样本先呈现不能喝的 hamburger，再呈现同样不能喝的 ink，最后找到可以喝的 juice。句型重复，但句与句之间已经有“寻找—排除—找到”的关系。老师用这个例子说明：几个简单句加上图片和逻辑，就能形成一个小主题，而不是互不相关的随机句。

【整理理解】早期随机抽卡的价值在于调动不同词；当基础稳定后，可以尝试让几个句子共同回答“我能喝什么”。不是要求现在必须编完整故事，也不是把每次抽卡都改成讲故事。

3. 从句子到迷你绘本：先有需要，再有选择

【视频讲解｜约04:00–05:00、09:00–11:00】老师把同一句型配不同对象、再建立一定逻辑的方式，与早期分级绘本作类比；还提到加入口渴和想喝东西，可以让这个小主题更像故事。

【补充示例】I’m thirsty. Can I drink this? No, I can’t drink ink. I can drink water. 用四张纸画串起来即可。关键是孩子知道为什么换到下一张图，不是只照顺序背四句话。此例为整理补充，不是视频逐字原句。

4. 换到其他动词时，不要一步换一大堆

【视频讲解｜约05:00–06:00、09:00–10:00】老师强调，从 I can see 到泛化的 I can do，中间仍可有固定一个具体动词的阶梯。换动词还涉及后面的宾语、名词形式和搭配；若这些没有熟悉，一次把很多新动词塞进安全主题，难度会突然变大。

【整理理解】先借已经熟悉的 eat 做“能吃／不能吃”的主题，再考虑新的动作。能说一个 can 句型，不等于所有动词和宾语都已自动化；一次只增加一个明显难点。

5. see 和 build 的展开：同一工具可以打开很多内容

【视频讲解｜约11:00–16:00】老师用 see 展开不同地点可以看见什么、看不见什么；用 build 展开 bridge、skyscraper、fort、castle 等对象，并说明遇到绘本上的桥，也能把近期练的 I can build / Can you build…? 接过去。

【语法规范化】搭配必须同时合乎词义与场景，不是任何名词都能无条件和任何动词配对。地点中有没有某种东西也依赖具体情境，不把课堂举例写成动物园或博物馆的普遍事实。

6. 新词从方便的地方来，不设“今天必须建十种”的清单

【视频讲解｜约15:00–18:00】老师反对把 build 固定成事先打印好的十种建筑，并要求全部练完。可以结合手头绘本、孩子的兴趣或现有玩具；突然遇到不会的词，可以一起查，但控制数量，别因为查二十个词打断整个互动。第二天忘了，再把昨天那个东西提起来即可。

【补充练法】成人先准备一两个容易用到的对象；孩子提出别的建筑时，允许换方向。查到一个词后，立刻放回句子和图里用，而不是转去收集一整张词表。

7. 进下一剧情不等于把前面关掉

【视频讲解｜约18:00–21:00】本讲把句与句的串联、主题、新词和内容包联系起来。老师说明，可以继续下一剧情，同时把 can 句型留在循环复习、zoom in 和动词指认里；也可以在某个动词上停留一阵，把对象和讨论做得更丰富。

【整理理解】推进和巩固可以并行。判断不是“这页讲完了吗”，而是孩子在新对象、新图里能否重新组织句子；尚不顺的部分，下次自然带回来。

8. 进度可以不匀速，但仍要观察真实困难

【视频讲解｜约21:00–25:00】老师用学走路和做饭等比喻说明，语言练习不是每个项目都匀速前进；允许遗忘、允许一个阶段集中在某个主题，不必把所有输入都变成逐项复习清单。

【整理边界】这是关于避免僵化管理的教学建议，不是否定所有评估、记忆研究或复习工具。观察是否理解、是否能换对象使用、是否需要帮助，比只数完成了几张卡更贴近本讲目的。视频中的神经元、饮食计量和比赛成效类比，不作为科学或结果保证。

9. 家庭实施：三张卡足够启动

【补充练法】①用水、果汁、墨水的图片固定 drink，成人演示正反；墨水仅作图片或安全假道具，绝不实际尝试。②角色提出“口渴”这个需要，孩子帮助排除一个选项，再找到合适的选项。③换到已熟悉的 eat 或 see，保留“有的行、有的不行”的逻辑。

孩子只说对象词时，成人自然给完整句并一起说；说顺后再问一句为什么。观察能否围绕同一需要说两三句，不规定必须几天会编故事，也不把水或果汁的语言示例当饮食建议。

10. 本讲复盘

从“把词连成句”进一步走向“把句连成主题”；固定动词降低难度，正反选择产生逻辑，绘本与兴趣提供新对象，旧句型在新剧情里继续出现。能看到联系，还要真正说出来、用起来。

---

一页复盘

本讲的新意是把几句简单句连出“需要—排除—找到”的逻辑；固定 drink 先说顺，再用熟悉动词和绘本对象继续串联。
