## 先看结论

本讲与 B-049 共用一支来源视频，对应视频中 never 这一支。结构与 always 完全同源：第三人称单数一般现在时加频率副词。always 说“总是如此”，never 说“从不如此”，sometimes 说“有时如此”。课堂强调三者不是三套新语法，而是同一框架下的频率变化；仍然分开练，是为了逐个稳定调用，不设固定周数。

never 本身带否定意义，所以肯定形式的 `He never does...` 已经表达“他不做”。这使主谓一致、否定意义和篇章证据同时成为重点。

## 1. never 已经表示否定

【语法校核】`He never plays football.` 表示他从不踢足球；不需要再加 don’t/doesn’t。若要加强或对比，可说 `He never plays football, but he sometimes watches it.`。

【整理边界】never 在句中表示频率为零，不是过去完成时或现在完成时专用词；`He never goes` 是一般现在时。

## 2. 主谓一致不能因 never 消失

【语法校核】`He never go` 仍然错误；实义动词要随第三人称单数变为 `goes/plays/likes`。否定词 never 不替代三单变化。

【补充示例】`She never eats candy.`、`The bull never opens the gate.`。助动词否定形式 `He doesn’t always...` 是另一结构，不要把 does 与 never 机械叠加。

## 3. never 也需要证据

【视频讲解｜约18:00–27:30】课堂把频率句放进篇章：一个主题必须由细节支持。说 `My dad never changes clothes`，需要具体行为证据，而不是只给孩子贴标签。

【整理理解】观察型 never 应基于可见习惯或明确故事设定：总穿同一件、从不吃胡萝卜的虚构角色。不要用 never 对真实人物作绝对、负面的性格判断。

## 4. always 与 never 的对称对比

【整理理解】`He always wears a jacket.` / `He never wears a jacket.` 可以在同一个人物卡上做对照，让孩子感受频率两端。中间可补 `sometimes`，建立 always—sometimes—never 连续尺度。

【补充编排】用三张图分别表示每天都穿、偶尔穿、从不穿，先分类再说话。孩子通过视觉频率理解词义。

## 5. 篇章仍用一个主题加三个细节

【视频讲解｜约05:15–18:00；约27:30–29:35】never 与 always 共用总分结构：一个主题句配三个行为证据，不必一开始写结尾总结。

【补充示例】主题 `The robot never eats human food.`；细节 `It doesn’t eat apples.`、`It doesn’t drink milk.`、`It only charges.`。允许使用不同句型服务同一主题。

## 6. 区分虚构角色与真实人物

【整理边界】绘本反派或玩具角色可以说 `The monster never helps.`，这是故事设定；对家人、同学则应避免把一次行为概括成 never。语言练习也要保护孩子不形成固定标签。

## 7. 从频率句进入复述和写作

【视频讲解｜约30:20–30:49】课堂提到后续可从复述到编故事，先看懂别人的故事再自己组织。频率句型正好用于概述人物习惯。

【补充编排】读完绘本后先用一句 always/never 总结人物，再找三张图作证据。孩子先说关键词，成人帮助成句，最终形成四句小段落。

## 8. 成人先练双向组织

【视频讲解｜约25:30–29:35】课堂要求成人既从细节归纳主题，也从主题寻找证据。never 的难点常不是形式，而是能否找到足够、准确、不过度概括的证据。

## 一轮互动与观察

准备一个虚构机器人角色的三张图：只充电、不吃苹果、不喝牛奶。成人给主题 `The robot never eats human food.`，让孩子把三张图归类并说 `apple`、`milk`、`charges`。孩子用词即可，成人补 `It doesn’t eat apples.` 等句子。只观察三件事是否都支持 never 的主题，不把 never 用于评价真实家人。
