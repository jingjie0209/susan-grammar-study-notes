B-008｜I can do｜先抓 can 加原形，按反应减掉多余变量

先看结论

本讲以 can + 动词原形建立新模型：先用熟悉、安全的动作说 I can…，再按需要区分“有能力”与“被允许”。可组合的句子很多，不代表要练完所有卡片。连续卡住时，少做几句、改用可独立使用的动词，或固定一个对象，保留当前真正要练的部分。

1. 情态动词模型供成人先理清

【视频讲解｜约00:00–06:40】课堂说明 can 等情态动词与动词原形一起构成谓语，并建议用 can do 这样简短的模型记结构，而不是只记一串中文术语。

【语法校核】本轮是 I can clap. / I can draw.，不是 I can to clap 或 I can clapping。can 不随第三人称加 -s，后面的基本动词也不加第三人称 -s。do 是模型占位，不是每句都要保留 do 再接另一个动词。

【整理边界】不能把“一个简单句只有一个谓语中心”简化成只能出现一个动词词形。be 可以在进行式、被动式中作助动词，也可跟在 can 后用原形，如 I can be quiet.。本轮不要求孩子背完整情态动词表。

2. 先选当前常用意义，再逐步看多义

【视频讲解｜约04:00–12:10】can 可表达能力、许可等不同意义；课堂讨论应按实际需要选重点，不把一个词的全部释义同时抄背。能力与许可可以用明确情境分轮说明。

【补充对照】I can clap. 说有能力；成人指着允许使用的纸说 You can draw here. 说许可。孩子有能力拿笔，不代表每面墙都允许画。以“纸上可以、墙上不可以”的安全图片说明，不用真实破坏或咬人来演示。

【语法提醒】Can you open the box? 也可能是在请求帮忙，不能每次都只译成“有没有能力”。本轮先固定一个能看懂的能力情境，许可与请求待相应语境出现再说明。

3. 会 I can see，不代表任何新词都能自动接上

【视频讲解｜约12:10–19:20】课堂指出：调用新词、处理冠词、单复数和对象都会增加组织负担。已经熟悉某个 can 句子，仍可能在换动词时卡住；动词指认与句子使用可以分步持续进行，不必等“所有动词都学完”。

【补充练法】先确认 clap 的意思，再用 I can clap.。新的是句型时尽量选熟悉词；句型熟了再加入一个已演示、能理解的新动作。已知动词、对象与细节有很多组合可能，但备课卡池不等于孩子一轮的任务量。

4. 降难度有两条路：去对象，或固定对象

【视频讲解｜约19:20–24:50】课堂反对一次必须说完一百句；发现多处出错或挫败时，减少量和难度。示范不加宾语，或保持同一个宾语，只变化动词。

孩子卡在哪里可怎样减少变量规范化示例
句首和动作连不上成人给 I can…，孩子接词clap → I can clap.
对象、冠词同时负担重选本身可独立用的动词I can walk. / I can draw.
想保留对象但总换得乱固定一个熟悉对象I can draw a cat. / I can feed a cat.

【语法边界】不能任意删掉每个动词的必需成分；如 put 通常要说明放什么、放哪里。表中 feed 只在玩具或图片里练，不让孩子自行喂真实动物。若冠词另需练习，可另轮处理，不让新句型每句都叠加同一困难。

5. 动作表情可以先加，复杂语言不必先加

【视频讲解｜约25:00–29:40】课堂用“尝试飞行却做不到”的表演，把短句连成小情节，并为下一讲 can’t 作正反铺垫；随后邀请孩子参与，再给予积极回应。

【安全改编】用玩偶小鸟说 I can fly.，再让普通玩偶小人说 I can’t fly.。只在桌面移动玩具，或原地摆手臂，不从高处跳、不摔倒模仿。表演帮助理解，不意味着加了动作就能自动理解所有超出语言和认知范围的话，也不采用固定“肢体占信息百分比”的说法。

6. 输入反面，不等于要求马上输出反面

【整理理解】成人可以在示范时带一次 I can’t fly.，让孩子看到能力限制；孩子当前仍可只说熟悉的 I can clap.。如果孩子主动用 can’t，可自然接住；不因课堂出现否定就把 can、can’t、问句、角色互换全部列为同轮考核。

【补充问答】Can you clap? — Yes. / Yes, I can.；What can you do? — Clap. / I can clap.。邀请孩子动作参与也有效。成人可托句，但不要求每次回答都重复整条动作句。

7. 一轮怎样做到可进可退

【整理者编排】选一两个孩子已懂的动作。成人拍手说 I can clap.，邀请孩子一起；问 Can you clap?，接纳动作或 Yes。需要时给 I can…，孩子接 clap。再换画画：I can draw.。孩子愿意才加 a cat，或让玩偶接一句话。

【观察点】更换熟悉动作后，是否仍能把 can 与“能做”对应？卡住就回到成人示范、接词或原动作，不必等连续错到某个次数才降级。对方已在组织时留白，不抢答，也不把练习不顺归咎于孩子或家长。

8. 后半段答疑如何使用

【视频讲解｜约30:00–35:15】答疑涉及动画音频、奖励后撤、重复读一本书、如何加新内容及成人解释词义。与本讲相连的原则是：在已有材料中按理解与参与程度加一点内容，不是每次换一整套材料。

【整理边界】不照搬个案年龄作为撤奖励时间，不把课堂随口给的输入效率数字当测量结果。积极回应可为点头、具体描述孩子说清了什么或继续游戏；贴纸和拥抱都不应成为强迫开口的条件，尊重孩子的选择。
