## 先看结论

本讲不是让孩子马上背一张“现在完成时公式表”，而是先给家长建立一个可用的底层框架：**现在完成时站在现在这个点回头看，统计或总结某件事截至现在已经完成、发生过、持续了多久，或是否有过某种经历。** 它和一般过去时的关键差别，不只是动词形式不同，而是“观察截止点”不同。

本讲还强调学习进度是螺旋上升：过去式的刻意练习相对稳定后，可以开始现在完成时的简单内容；但过去式仍要在日常、绘本、故事和跨句型练习里循环回去。不要等过去式的所有动词、所有变化都“彻底毕业”后才允许自己接触完成时，也不要把孩子偶尔抓住一句完成时，误判成已经稳定会用。

## 1. 进入完成时前，先判断过去式是否“相对稳定”

【视频讲解｜约00:00–06:43】课堂先回问过去式练得怎样，并把“会不会”拆成几个层次：能否把动词过去形式用对，能否和不同人称、不同时间状态搭配，能否在刻意练习之外逐渐随机调用，准确率是否在真实交流中上升。

【整理理解】过去式不是“学过规则就算会”。更接近真正会的状态是：看到一个过去事件，能判断需要过去式；需要时能把形式说出来；换人称、动词和场景后，仍能在意义传递中保持大致准确。

但这不等于必须把所有动词的过去式全部练完，才能开始下一阶段。课堂把更真实的进度描述成**螺旋上升**：一个句型的刻意练习达到相对稳定，就可以加入下一个简单句型；与此同时，前一个句型继续在内容包、日常交流、绘本讨论、自编故事和跨句型混合练习里复习。

如果过去式在刻意练习里还经常“卡壳、乱套”，成人可以先把过去式的基础练稳；如果过去式已经能在疑问、否定、不同人称和不同时间状态中相对准确地调用，就可以开始接触完成时的简单内容。孩子此时不必立刻开始完成时刻意练习，孩子可以先做输入铺垫。

## 2. 家长和孩子的任务不同：成人先理解，孩子先在场景里体会

【视频讲解｜约06:43–14:18】课堂区分了家长学习语法和孩子内化语法的路径。家长有较强的抽象和理性分析能力，可以先看语法说明，理清完成时到底在表达什么；但不能把这套抽象讲解原样搬给孩子。

【视频讲解】家长进入完成时刻意练习时，可以主动做随机组句，换不同情况、不同时间短语，并在日常、绘本、故事、跟孩子交流时循环调用。孩子则可以继续做输入铺垫，在大量可理解的内容里偶尔抓住一两个完成时表达。

【整理理解】孩子偶尔说出一句 `I have done it.`，只能说明他在某个场景里抓住了声音、意义或整体表达，不能直接等同于“完成时已经会了”。稳定会用需要经过可理解输入、场景理解、模仿、刻意练习、随机调用和持续复习的循环。

【给家长的转换原则】

- 成人层面：可以用中文、语法书、时间线和例句先把概念想清楚。
- 对孩子呈现：把概念转换成看得见、听得懂、能参与的场景，不要求孩子听抽象术语。
- 练习目标：不是让孩子背 `have + done`，而是让孩子在“事情已经完成／到现在有过几次／到现在持续多久”的场景里逐渐听懂并使用。

## 3. 现在完成时的核心：站在现在回头做总结

【视频讲解｜约14:18–18:28】课堂先把动作状态分成一般、进行、完成、完成进行四类，再集中解释现在完成时。现在完成时不等于“动作一定发生在现在”，也不等于“必须重复很多次”。一次完成的事情也可以用现在完成时，关键在于说话者站在现在这个点回看，并关注它对现在的意义、结果、次数、经历或持续时间。

【整理者语法校核】可以先用一个“现在的观察点”来理解：

> 过去发生的事情 + 说话者站在现在回看 + 统计／总结截至现在的结果或经历 = 现在完成时的核心视角。

例如：

- `I have done it.` —— 到现在为止，我已经做完了。
- `I have already done it.` —— 到现在这个点，我已经做完了，结果对现在有用。
- `Have you done it?` —— 到现在为止，你做过／做完了吗？关注的是当前是否已有这个结果或经历。

这里的“现在”不是说动作正在此刻发生，而是**总结截止点在现在**。所以“我两年前去过美国”仍可能说 `I have been to the United States.`：事件发生在过去，但说话者在现在总结“截至现在，我有过这段经历”。如果要突出明确的过去时间点，就转向一般过去时：`I went to the United States two years ago.`

## 4. 一般过去时与现在完成时：先看截止点，再看形式

【视频讲解｜约16:24–18:28】课堂用“站在哪里回看”区分两类时态。

| 对比 | 一般过去时 | 现在完成时 |
| --- | --- | --- |
| 观察位置 | 站在过去某个时间点讲过去发生了什么 | 站在现在回头做总结 |
| 重点 | 具体过去事件、过去时间线 | 截止到现在的结果、经历、次数或持续情况 |
| 典型时间 | yesterday、last week、two years ago 等明确过去点 | already、ever、never、before、recently、over the years、since、for 等，或不强调具体过去点 |
| 例句 | `I did it yesterday.` | `I have done it.` / `I have already done it.` |
| 关键提醒 | 明确过去时间点可以自然使用 | 不要和明确的过去时间点直接拼成同一核心表达 |

课堂明确用“我昨天已经洗完碗了”来提醒：如果你说的是昨天那个具体过去点，通常用一般过去时 `I washed the dishes yesterday.`；如果你要表达“到现在为止已经洗完了、现在结果可见”，就把重点放到现在，使用相应的现在完成时表达。初学时先不要把 `yesterday` 和现在完成时强行捆成固定句。

## 5. 完成时最容易卡住的五个坑

【视频讲解｜约20:20–22:51】课堂把完成时的难点概括为多个同时处理的任务。下面把机器转写里可辨认的课堂意思按语法顺序整理；术语解释属于整理者规范化。

### 5.1 先判断：当前到底要不要用完成时

完成时不是“看到事情做完了就自动套上”。先判断你是在具体讲一个过去时间点，还是在现在做截止到现在的总结。若只是讲 `yesterday` 发生了什么，一般过去时往往更直接；若是在回答“到现在做过吗、已经完成了吗、截至现在有几次、持续多久”，才进入现在完成时的思路。

### 5.2 过去分词要选对

现在完成时的结构里，主要动词不能直接随便放原形或一般过去式，而要使用过去分词：

- 规则动词通常是 `have/has + V-ed`，如 `I have finished it.`
- 不规则动词需要逐词积累，如 `do–did–done`、`go–went–gone`、`eat–ate–eaten`、`see–saw–seen`。

不要把“过去式”和“过去分词”混成同一列；也不要把少数动词的变化方式当成所有动词的推导规则。

### 5.3 第三人称要处理 have／has

完成时不仅要变主要动词，还要根据主语选择助动词：`I/you/we/they have done`，`he/she/it has done`。课堂提醒，完成时比前面一些过去式结构更容易让人同时分心于“什么时候用完成时”和“什么时候用 has”。

### 5.4 时间短语的意义要匹配

完成时不能只靠背一串时间词。先理解时间短语在回答什么问题：

- `already`：到现在已经完成；`I have already done it.`
- `ever`：截至现在有没有过某种经历；`Have you ever done it?`
- `never`：截至现在从未发生；`I have never done it before.`
- `before`：在此前有过／没有过；`I have done it before.`
- `recently`：最近发生过；不要把它机械等同为“此刻”。
- `over the years`：这些年间累计到现在；常用于总结长期经历或变化。
- `since + 起点`：从过去某个起点一直到现在，如 `I have lived here since 2020.`
- `for + 时长`：持续到现在的时间长度，如 `I have lived here for ten years.`

初学先从最常见、最短、最容易在生活里搭场景的 `already`、`before`、`never` 入手，再逐步加入 `since`、`for` 和更长的时间表达。

### 5.5 “瞬时动作”如何转成“到现在的持续状态”

这是课堂后半段强调的难点之一。某些动作发生的一瞬间就结束，不能直接说这个动作本身连续了十年；但动作完成后可能留下一个持续到现在的状态。课堂举到的可辨认例子包括：

- `I have owned the apartment for ten years.` —— 买／获得房屋是一次完成的事件，`own` 表示之后持续拥有的状态。
- `We have been married for ten years.` —— `marry` 是结婚这个瞬间，`be married` 是结婚后持续的状态。

【整理理解】这类句子不是在说“结婚动作连续十年”，而是在说“从那个完成点开始，某个状态一直持续到现在”。这也是为什么完成时学习不能只盯着公式，必须把事件、结果和持续状态放进场景里理解。

## 6. 从最常见、最短的模型开始做输入和刻意练习

【视频讲解｜约22:51–30:38】课堂建议从妈妈最常见、最常说、短而清楚的完成时表达开始，并围绕时间短语逐步展开。转写中可辨认的课堂模型包括：

- `I have already done it.`
- `I have done it before.`
- `I have never done it before.`
- `I have owned the apartment for ten years.`
- `We have been married for ten years.`

【补充编排】家长可以把一个熟悉动作放进真实需要里，而不是把例句当成孤立背诵：

1. 事情做完后自然说 `I have already done it.`。
2. 回答“以前做过吗”时用 `I have done it before.` 或 `I have never done it before.`。
3. 看到家庭长期状态时说 `We have lived here for ten years.`、`She has had this bag since 2020.`。
4. 练 `have／has` 时只改变主语，其他内容先不大幅增加：`I have done it.` → `She has done it.`。
5. 练过去分词时一次只换一个高频动词：`done`、`gone`、`eaten`、`seen`，同时保留相同场景。

这部分示例是整理者编排，不等于视频布置的统一作业。重点是让孩子或成人逐渐建立“事情已经完成／曾经发生／持续到现在”的意义网络。

## 7. 家长进入完成时后，过去式仍要继续练

【视频讲解｜约06:00–12:21；约29:00–35:30】开始完成时后，过去式不是被替换掉的旧章节。过去式可以在以下地方循环复习：

- 日常调用：昨天发生了什么、刚才做了什么。
- 绘本讨论：人物过去做了什么、接下来发生了什么。
- 自编故事：同一个角色在不同时间做不同动作。
- 句型串联：过去事件 → 现在结果 → 下一次计划。
- 内容包循环：在不同材料里反复遇到同一动词的现在式、过去式和过去分词。

孩子此时可以主要接受输入铺垫；家长则可以在自己的刻意练习中主动做完成时随机组句，再把抽象理解转成场景。不要只输出不输入，也不要只输入不输出：输入负责建立可理解的意义和例子，输出负责让成人发现自己是否真的能在场景中调用。

## 8. 完成时的使用场景并不如一般时态宽广

【视频讲解｜约34:29–38:02】课堂提醒，现在完成时的真实使用场景相对集中，不要期待找到一本“整本书都在讲完成时”的材料。先理解一个场景的用法，再在书、绘本、对话和日常中主动寻找同类表达。

【整理理解】越到后面的语法，使用范围可能越窄、场景越固定。学习策略不是把所有变体一次性学完，而是：

1. 先抓住少数高频模型和典型场景。
2. 在输入中识别它们，不急着每次都输出。
3. 当成人刻意练习相对稳定后，再做跨句型混合调用。
4. 继续回到过去式、现在进行时等更常用结构，保持语言网络的整体运转。

## 9. 本讲的家庭练习边界

【补充编排】

- 不用把 `have + 过去分词` 讲成孩子的背诵口令；先让孩子在场景中听懂“现在已经有这个结果／截至现在有过这种经历”。
- 不用把偶尔说中一句当成稳定掌握；观察能否换场景、换主语、换动词后仍保留意义。
- 不用把所有 `since/for/ever/never/already` 一次性塞给孩子；先选一个真实生活里经常出现的模型。
- 不用为了练完成时而牺牲自然交流；如果孩子当下只需要理解和参与，输入铺垫就是有效学习。
- 安全、真实的家庭沟通优先；语法正确率是逐步提高的，不是一次活动里全部验收。

## 10. 一页复习卡

- 核心视角：站在现在，回头总结截至现在的结果、经历、次数或持续情况。
- 基本结构：`have/has + 过去分词`。
- 最先记的模型：`I have done it.`、`I have already done it.`、`I have done it before.`、`I have never done it before.`。
- 和过去式的分界：明确过去时间点偏向一般过去时；现在完成时关注“到现在”。
- 五个坑：是否该用、过去分词、have/has、时间短语、瞬时动作转持续状态。
- 练习路径：成人先理清概念，孩子先做场景输入；先短句，再随机组句；完成时开始后，过去式继续循环。
