先看结论

本讲把完成时从“会不会套形式”推进到“能不能按意思分场景”。课堂先回顾过去分词和成人刻意练习，再以时间状语为入口，梳理完成时常表达的多种情景；对孩子不按语法类别分组，而是先选一个可操作、常见、能听懂的场景，在故事和内容包里反复使用。

The squirrel has done... 在本页作为第三人称完成时入口：松鼠已经完成某事，强调现在能看见的结果或当前意义。它和 The squirrel did... 的区别不在“谁做的”，而在说话者站在现在总结，还是站在过去叙述一个具体事件。

1. 为什么成人和孩子练法不同

【视频讲解｜约00:00–03:20】课堂先循环过去分词练法，并区分成人与孩子：成人可以按规则、分组和三种时态穿透场景；孩子不照搬词表，仍从名词卡、动词卡、绘本和剧情出发。

【整理理解】成人的“会”包括能自由调用和带孩子；孩子的“会”可以先表现为在具体剧情里理解并稳定回应。两条路径目标相连，但材料与门槛不同。

2. 长预热不是原地重复

【视频讲解｜约03:20–04:25】课堂指出完成时也需要长预热，过去式和完成时的输入可以交叉出现；日常对话、动画和绘本都能积累。孩子使用时不要求立即输出，也不能阻止他自然输出。

【整理边界】家长可以把完成时像一般语言一样自然说给孩子听，但不要每听到一个动作就停下来考完成时。预热是大量有意义的使用，不是连续做同一张练习纸。

3. 用时间意义给场景分类

【视频讲解｜约04:25–18:15】课堂围绕时间状语梳理多个场景：刚完成的事、做过／没做过、经历、过去几年发生的变化、做过多少次、最近如何等。不是所有场景同一难度，already、ever、never、before、次数、since/for、recently/lately 各自回答不同问题。

【整理理解】先问“我现在想总结什么”：结果完成、经历有无、次数、持续、近期变化。只在形式表上把所有时间词并排，会让孩子误以为它们可以随意互换。

4. 孩子第一次刻意练习不必穷尽场景

【视频讲解｜约18:15–20:10】课堂明确提出第一遍不需要做完全部场景，最容易的两个入口是“事情做完了吗”和“做过几次”；小孩子不必一次性理解所有抽象分类，小学阶段再单独处理一些考点。

【补充编排】第一周只固定“做完／没做完”或一个可数活动，等模型稳定后再换场景。若孩子只能在原物品上回答，先换物品；再换动作；最后才换主语和时间词。

5. 第三人称先练 have/has 配对

【整理理解／语法校核】The squirrel has done it. 中 squirrel 是第三人称单数，用 has；I have done it. 用 have。疑问句 Has the squirrel done it?，短答 Yes, it has. / No, it hasn’t.。过去分词本身不随主语变化。

【补充示例】可先固定同一个动作：The squirrel has eaten the nut.，再换角色 The rabbit has eaten the carrot.。一次改变角色和名词已经足够；不要同轮再加入时间从句和所有不规则变化。

6. 场景必须进入内容包

【视频讲解｜约05:30–06:25；约18:20–19:05】课堂要求每做一个场景，都在绘本讨论、日常对话和其他内容包里主动使用，并在输入中专门识别。完成时若只在练习页出现，孩子很难把它变成可调用的语言。

【补充编排】读完绘本后抓住一个角色结果：松鼠把坚果藏好了。成人说 The squirrel has hidden the nut. Now the nut is safe.，孩子可指图或接 hidden。第二天换绘本，仍寻找“已经完成并影响现在”的时刻，而不是背同一句。

7. 会了一点不等于完成时已经结束

【视频讲解｜约18:15–19:05】课堂提醒完成时的掌握可能持续数年，不会因为三岁多练过一次就永不需要。难度更高的经历、持续状态、瞬时转延续和复杂文本仍会在后面反复出现。

【整理边界】本讲只建立场景地图和第一批入口。孩子能在几个场景中理解、成人能在多个内容包中自然调用，是当前阶段成果；不把它包装成一次性通关。

一轮互动与观察

用一只松鼠玩偶和坚果完成小剧情：松鼠把坚果放进盒子后，成人说 The squirrel has hidden the nut. It’s in the box now. 孩子指盒子、说 hidden 或重复短段都算参与。轮换一次只改角色或物品。观察孩子是否把 has done 与“现在看得到的结果”连在一起，而不是只在听声音模仿。
