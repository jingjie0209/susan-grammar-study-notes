## 一、一句话主线：复数从这里加入，但不能在这里结束

**【视频讲解｜00:00–04:10】** 接着 A-010 的单数表达，本讲用较稳定的 I can see 引入名词复数。可以开始少量练，但不要求把所有变化规则一次过完。后续随机组句、Zoom in、绘本讨论和生活表达里，都要继续给复数出现的机会。

**【整理理解】** 本轮的新负荷尽量放在名词端：句首不变，后面从一个熟悉物体变成多个。学会一组不等于掌握全系统；没学完也不等于不能开始用。

## 三、比上一讲多了什么，又暂时不多什么

**【视频讲解】** I can see 的句首较稳定，有利于先处理名词复数。后面换成 they are、these are 一类形式时，还会多出主语与 be 动词的配合问题。

**【补充示例】** I can see a book. → I can see two books. → I can see many books.。这里先保留 I can see，改变的是数量和名词形式。

**【整理理解】** many 后面接可数名词复数。本讲标题不是要求每句都必须有 many：I can see books. 也可以表达看见一些书；若重点是复数，成人可先减去数量词，等组合较顺再加回来。

不能把所有词都硬接在 many 后面。例如通常表示饮料的 juice，宜说 some juice 或 a lot of juice，而不是把 many juice 当作普通数量表达。此为规范化语法补充。

## 四、两条线路同时保留：分组练熟与自然遇见

### 1. 集中练习优先用熟悉名词

**【视频讲解｜02:00–04:20】** 已经指认和使用过的名词可以分组，例如食物、动物，或者其他便于安排的方式。重点是组内有反复连接，不是今天只学 s、明天只学 es。

**【整理理解】** 熟悉对象提供意义支点。孩子知道 book，却还不会 books 的表达，比同时猜一个全新物体、新名词、数量词和句子开头更容易定位卡点。

“混合练”也不是把所有未知随机堆上去。这里可以是熟悉对象的复数形式有所不同，而不是多项陌生输出任务一起上。

### 2. 绘本遇到新名词时，不必为了进度挡住它

**【视频讲解｜04:20–12:10】** 老师同时允许在绘本讨论中遇到新的复数词。若意思传递清楚，配合实物、动作等互动，成人可以自然给出句子并帮助孩子参与。

**【整理理解】** 两条线路承担不同作用：一条方便给熟悉内容足够练习机会；另一条让表达在新内容中出现。绘本里听过、一起说过，不应直接登记为“今后每次都能独立用”。

老师将这种组合解释为对真实语言使用的模拟。这是她的教学思路，不等于视频已经提供了比较研究，证明某种安排对所有家庭必然最优。

### 3. 第一次理解充分，也仍需要后续再次使用

**【视频讲解】** 老师以洋葱等有实物支持的互动说明，意思、语言和参与可以同时发生；也区分第一次学得充分和以后是否忘记。

**【整理理解】** 可以保留的操作标准是：对象清楚、正确语言到位、孩子有参与机会、之后继续调用。不要把“今天说出了”扩大为“以后不会忘”。感官活动要看孩子接受程度，不需要强迫闻不喜欢的气味。

## 五、规则给成人做准备，不把表格变成孩子的入场考试

**【视频讲解｜12:10–19:50】** 中段讨论一般加 s、部分加 es、以 y 结尾及特殊变化，强调成人先弄清材料中的词怎样用，再提供正确模型，不必先让孩子讲出术语。

**【补充示例｜规范化速查】**

| 成人要核对的情况 | 示例 | 注意 |
| --- | --- | --- |
| 常见直接加 s | book → books；toy → toys | 以元音字母加 y 结尾的 toy，通常直接加 s。 |
| 常见加 es | box → boxes；dish → dishes | 选常见词先练，拼写与读音都要核对。 |
| 辅音字母加 y | baby → babies | 先改 y 为 i 再加 es，不套到所有 y 结尾词。 |
| 不规则或随词义变化 | child → children；fish | 逐词核对，不给所有词强套同一规则。 |

**【整理理解】** 直播里关于 o 结尾、食材可数性的便捷说法不能作为通用规则。例如 photo → photos、tomato → tomatoes，不能只用“有无生命”保证推导正确；食物有没有切碎也不是可数性的完整判断方法。本笔记不把这些简化说法写成定律。

规则表是成人查漏工具，不是要求孩子背完后才能说话。不规则词可以随清楚情境提供正确示范，之后继续复用。

## 六、成人练习：从“知道”走到能组织

**【视频讲解｜19:50–24:40】** 本讲很大篇幅给成人留任务：核对手头名词的复数，先在固定 I can see 中开口说顺，再换 they are、these are 等表达，最后放到绘本讨论中跨句型使用。

**【整理理解】** 可拆为三轮：第一轮核对词形；第二轮固定句首连接；第三轮换场景、换适合的表达。卡住时先看是词形不知道、名词调不出，还是主语与动词配合还不稳。

视频中“一秒说出”、几个月及大量句子的说法是老师对熟练度和练习量的强调，不是统一速度考试或效果保证。也不能把成人暂时不顺解释为家长不努力的证据。

**【补充示例】** 先 I can see two ducks.，之后单独一轮说 They are ducks.。两个形式尚不稳定时，不要每张卡都突然要求切换。

## 七、Zoom in：让多个对象真的产生互动

**【视频讲解｜24:40–27:50】** 老师用多只鸭子的声音说明：从一个变成多个，音效、角色或动作也可以有所变化，再接着讨论每个对象在做什么。

**【整理理解】** 这不是让成人立刻加一套新时态。当前只懂名词复数，就保留简单声音与动作；成人能用、孩子也看得懂的已知表达可以自然出现，新扩展不要求马上独立输出。

本讲没有重新逐项展开所有游戏，不能把另写的家庭玩法冒充老师完整演示。

## 八、家庭实践：一组旧词，分层连接

**【补充示例】**

1. 选孩子熟悉的 book、ball 等对象，先确认眼前确实有多个；数不清时协助点数。
2. 成人示范 books、two books。若名词短语不顺，先不加句首。
3. 连到 I can see two books.，需要时成人给开头，孩子接后半句。
4. 同一轮换熟悉对象，较顺后再加 many 或少量新名词，不一次扩完所有规则。
5. 绘本遇到多个熟悉对象时再用；孩子可指认、接短语或在提示下说整句。
6. 成人另做一轮 they are 的准备，不把自己的全量练习变成孩子当天的作业。

## 九、易错提醒与观察记录

- 不是所有名词都能放在 many 后；成人要核对词义和常见用法。
- 不是讲过复数表就能即时使用；重点是熟悉词能否与句子连接。
- 分组练与绘本自然输入互补，不需要选择其一，也不要求开放输入里的所有内容当场会。
- 不把“会一次”“跟着说过”记成“已独立掌握”。

**【整理理解】** 每次只记一个卡点：词形、数量、短语，还是句首连接？下一次针对这一小段给帮助，并保留旧内容再次出现的机会。

**本讲一句话复习：固定句首引入少量复数，在集中练习和自然使用中持续循环；成人先练会，不用规则表或速度标准考孩子。**
