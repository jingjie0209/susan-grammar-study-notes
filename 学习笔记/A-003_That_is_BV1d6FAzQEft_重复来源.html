一、本讲主线：远处指认＋旧知识循环＋已知加一

That is … 不是第三个需要孤立背诵的口令。它让孩子在远处指认的情境中继续练习完整表达，并把前两讲已经出现的冠词、名词和问答循环起来。

本讲反复解决三个问题：

1. 学到什么程度可以进入下一句？偶尔错与每句同样错，有什么区别？

2. 为什么学过的 It’s a …、This is … 不能像做完单元一样消失？

3. 在目标句型旁边加入 smelly、giant、Which 等表达，为什么不等于可以一口气并行推进很多新语法？

【整理理解】 主训练有一个集中目标，周边互动可以有理解得到的扩展。二者并不冲突。真正要避免的是把多个陌生知识叠在一起，又要求孩子立即、独立、完全正确地输出。

三、进入 That is … 前，先看什么

1. 不是固定顺序，而是有意义的小步推进

【视频讲解｜00:00–01:55】 老师先回顾前两天内容：It’s a …、This is …，以及五步内化。this / that 的区别可以先做，也可以分别做完整句后再比较。句子说不顺，阶梯就继续切小。

【整理理解】 灵活顺序不表示随意跳过理解。如果孩子还不知道自己指的是哪个、熟悉词也调不出来，直接追加 that，只会增加需要猜测的内容。

2. 本讲给出的准备状态：随机抽熟悉卡，能即兴组织

【视频讲解｜01:55–03:00】 进入本讲前，This is … 应达到相对稳定：随机抽一张熟悉卡，孩子能组织出句子。偶尔出现错误可以接受；但不能每句话都在同一个地方错，若总是如此，需要继续停留和处理。

【整理理解】 “即兴组织”区别于背固定顺序。例如孩子只会按 fish、egg、bowl 顺序说，换顺序就卡住，说明他对整套材料的记忆可能强于对句型的调用。随机更换熟悉材料，正是用来避免只背一串固定答案。

“相对稳定”不是视频定义的百分比准确率，也不等于全套五步已经彻底完成。这里是在讨论是否可以加入下一个集中目标，之后仍需持续内化。

3. 偶尔错与系统性错不能同样处理

【视频讲解】 老师允许偶尔错误，但提醒每句同样错时先停留。

【整理理解】 两种情况可以分别看：

• 偶发：已经多次自然说过 This is a fish.，偶尔卡在新一轮开头。可以提供短提示，再继续。

• 系统性：无论换什么熟悉卡，总是只说 This fish，或每次都等成人逐词领读。这时不要用“老师说可以错”掩盖需要补的台阶。

上述句子是整理者用于区分的例子，并非视频逐个举出的错误样本。

4. 问句最好也较熟；未熟的继续循环

【视频讲解｜03:00–03:55】 老师认为问句最好已经会，这样往下更舒服。如果 Is this … 还没有稳定，就放在循环复习里继续做。

【整理理解】 这不是“问句不会也完全不用管”，也不是“一处不完美就永远禁止接触任何新语言”。已经开始下一讲时，仍要如实保留旧目标的未完成状态，并安排后续支持性复习。

四、为什么旧句型不能毕业后消失

1. 做完一轮刻意练习，不等于完成终身保留

【视频讲解｜03:55–04:45】 老师强调前两个句型需要继续出现在输出中，可以放入猜词等不同活动。不能像一个学完的单元一样，过了就不再使用。

【整理理解】 句型从“这次练过”到“交流时能随手调用”，中间需要持续出现的功能场景。旧句型不是每日另背一遍的名单，而是继续承担实际的指认、命名、核实等任务。

例如今天目标是远处指认 That is …，近处玩具出现时仍可自然使用 This is …；谈到一个已有对象时，仍可以使用 It’s …。初期按游戏轮次分开更容易，稳定后再逐渐放入混合交流。

2. 所有语法的使用频率并不相同

【视频讲解｜04:45–06:40】 老师区分高频基础表达和复杂语境才出现的形式，以过去完成等为例说明权重差异。基础表达应长期在日常输入输出中保持；不常用形式可能调用较少。

【整理理解】 不要把“持续复习”理解成每天把英语所有语法刷一遍。复习要跟实际使用频率和孩子当前阶段匹配。视频中的比较是老师对课程安排的说明，不是要求幼儿现在开始练复杂完成时。

3. 不强行造句，也不彻底断开

【整理理解】 两个极端都要避免：为了打卡，每个家庭活动强制说十个旧句；或者学到第三讲后，前两讲再无场景使用。更可行的是保留熟悉小游戏，在绘本和生活中遇到真实需要时继续调用。

五、That is … 里仍然在练哪些语法

1. 名词、冠词和指示表达不是彼此孤立的任务

【视频讲解｜06:40–08:30】 老师复习本句涉及的单数、a / an、不可数名词使用以及 that 等。之前 It is …、之后 I can see … 等句型，会反复带着名词、冠词、单复数和代词一起练。

【整理理解】 一个真实句子往往同时承载多个知识点。孩子说 That is an egg. 时，不是只练 that：他还在练单个物体、egg 的调用、an 的使用和完整句子的组织。

家长需要先提供正确语言，但不一定把所有抽象规则拆成独立讲座再让孩子开口。

2. 不要求第一天全部掌握，也不等于完全忽略基础

【视频讲解｜08:00–09:50】 冠词的使用会持续练习，越往后也有复杂处。老师提醒 A 阶段要停留足够时间，别名词、冠词和复数都没稳定，就急着再增加动词任务。

【整理理解】 这两句话应同时成立：

• 第一节还不熟，是正常的学习状态，可以通过多种句型反复练。

• 总是不熟，却一直叠加新难度，会使后面要同时处理的事情越来越多。

不是把所有错误记账罚分，而是识别负荷：孩子正在学 that，如果每个名词也陌生、每个冠词也猜、问答也从零开始，那么本轮早已不是“只加一”。

3. 家长可以先核对最基本的示范句

【补充示例】 本讲集中练单个物体时，可以用：That is a fish.；That is an egg.；That is a bowl.。不要机械认为所有名词前都必须插入 a。

【整理理解】 不可数名词并不能一律塞进 That is a …。例如在通常的水的意义下说 That is water.。这个例子是语法补充，不代表视频安排了 water 专项训练。本轮若不准备处理这项区别，选清楚的单个可数实物即可。

六、远处指认：先把参照关系安排清楚

1. that 的“远”是情境关系，不是硬性米数

【视频讲解｜09:50–10:30】 本讲从远处卡片的安排进入 That is …，讨论怎样让孩子理解对象比较远。

【整理理解】 在本课的物体指认中，that 通常用于指向相对较远的对象。视频没有规定几米以上必须用 that。关键是对当前说话人而言的指示关系足够清楚。

不要把它推广成“英语里 that 永远只表示物理距离远”。本讲没有集中讨论其其他用法。

2. 大人和孩子都要相对离目标远一点

【视频讲解｜10:30–11:25】 老师指出，大人与孩子的站位和指向会影响孩子理解，提出两个人都离卡片相对远些的做法。

【整理理解】 如果家长站在门口，孩子却抱着目标卡，双方体验不同。“这个／那个”的示范可能不够直观。初始训练让两个人站在同一侧、面对远处目标，能减少这种额外歧义。

后续孩子真正理解后，再改变位置进行更丰富交流；不要在第一轮就以视角转换题检验能力。

3. 几张卡一起挂着时，指向必须明确

【视频讲解｜10:35–11:40】 视频讨论挂多张卡、用手电指向或投向目标等办法。

【整理理解】 指向不是可有可无的装饰。孩子需要确定家长说的是哪张卡，否则说不出可能来自目标歧义，而非忘了句型。

【补充示例】 把两张熟悉卡分开贴在墙面，大人和孩子站在另一侧，用手指或普通手电的光点明确选中一张，停一下再说 That is a fish.。不使用激光指眼睛，不让照明或动作成为危险游戏。

4. 游戏可以按句意组织，也可以迁移现成玩法

【视频讲解｜09:50–12:10】 老师再次说明，有的游戏适合直接按句意组织；也有游戏可以沿用，关键看孩子是否觉得有意思。

【整理理解】 “远处找到对象”是自然对应 That is … 的一类玩法，但不是唯一允许的玩法。投掷、选择、找卡等都可以服务于表达；需要保留对象对应和理解，不能只追求活动刺激。

七、陈述稳定后，让孩子提问、让孩子教大人

1. 问句要建立在已理解的核实功能上

【视频讲解｜12:10–12:40】 陈述较熟以后，引导孩子练问句。老师提出让孩子来教家长。

【整理理解】 问句不只是家长说一遍孩子重复一遍。角色互换意味着孩子开始承担核实、发问、提示或帮助的任务，交流不再只有成人出题。

【补充示例】 家长指远处鱼卡，提供 Is that a fish? 的模型。孩子能参与后，由孩子选卡并发问，家长回答 Yes, it is.。如果孩子只会说 fish，成人给问句开头；无需立刻完整自主提问。

2. 游戏式“我不会，你帮我”能增加孩子参与

【视频讲解｜12:35–13:25】 老师通过表情、语气示范家长假装不会、让孩子帮助和教自己，从而增加互动趣味。

【整理理解】 这里的“不会”是可理解的角色游戏，不应变成反复提供错误语法让孩子承担纠错责任。家长也不要把答不上来的孩子嘲笑为“连老师都当不了”。成人最后仍要提供可靠的正确模型。

3. 孩子教你，不等于考官换了位置

【整理理解】 有时家长虽然说“你当老师”，实质仍在检查每一个音、每一个词，并立即打断。这并未降低压力。真正的角色互换应该保留帮助、允许停顿，让孩子体验表达能够带来互动结果。

八、Zoom in 扩展：为什么可以出现 giant、smelly

1. 先从已知词出发，仍然把意思传递准确

【视频讲解｜13:25–14:30】 老师回应“大脚丫”等延展，强调从孩子已知的词出发，配合动作或声音，把意思传递准确。

【整理理解】 延展不是为了显示家长能说很多句，而是给已有词和句型增加可理解联系。如果孩子已懂 foot，用大小明显不同的图、玩具或夸张动作，可以给“大脚”的意思一个清晰场景。

2. 新形容词不必等到专门那一课才听到

【视频讲解｜14:30–16:00】 视频讨论 smelly，并出现巨大的脚的玩笑式表达；画面字幕显示 Wow, it’s a giant foot.。老师反对把书上的句子或当前句型当成唯一允许出现的语言。

【整理理解】 当前主练 That is …，自然互动仍可以调用已知的 It’s …，或在清楚的情境中介绍一个形容词。课程进度是集中训练顺序，不是英语日常输入的封锁线。

3. 出现过、一起说过、独立会用，是三个层次

【视频讲解｜16:00–16:50】 老师将这些扩展描述为铺垫，提醒家长调整最终期待。新表达出现和被引导说过，不代表已经完全内化。

【整理理解】 本讲可以建立一张分层记录：

• 听到并看懂：孩子知道大脚或臭脚玩笑在说什么。

• 在帮助下参与：成人给开头，孩子跟着或补足词。

• 能主动调用：换情境之后，孩子自己选用表达。

不要因为完成第二层，就把第三层当成下次必须展示的成果。也不要因为尚未达到第三层，就认定前两层没有价值。

4. 玩笑的对象和方式仍需合适

【补充示例】 可以用画在纸上的夸张脚、玩具或故事人物做 giant / smelly 的游戏，使用表情帮助理解。不要让“臭脚”成为对孩子身体的羞辱，也不需要真实刺激性气味。

本讲语言核心是清晰场景中的词义连接，而不是某种特定搞笑道具必须准备齐。

九、Which 和 What’s missing?：把游戏语言串起来

1. Which 可以从“在这些里面选哪个”理解

【视频讲解｜约 16:50–18:00】 老师讨论 Which，画面中出现 Which is the hand?，同时提到 What’s missing? 等游戏表达。

【整理理解】 多个对象中的选择，比孤立解释“which＝哪一个”更有沟通功能。成人提问、指向或摆出选项，孩子选择、指出，再得到语言示范，可以让词与动作任务连接。

2. 已有游戏本身就有可用语言

【视频讲解｜18:00–19:20】 老师强调游戏常用语和句型之间可以串联，鼓励理解底层思路，而不只机械限制为一句目标句。

【整理理解】 一次找卡活动，可能包括选择对象、确认它是什么、发现少了一张、将对象放远。各环节自然需要不同表达。但需要控制孩子当前承受的难度，不能把所有环节都当成新考点。

3. 发散不是家长另加长篇陌生独白

【视频讲解】 老师明确批评目标句之后自己说一大堆、却没有有效传递和内化的做法。

【整理理解】 判断扩展是否有效，可以看：孩子有没有看懂、能否通过指认或动作参与、是否与当前对象相关、是否有适当语言支持。句子多不是独立的质量指标。

4. 新输入仍保持“零期待”

【视频讲解｜19:20–19:35】 输入语言可以很丰富，但不能因为加了就要求孩子立刻会。老师使用“零期待”的说法。

【整理理解】 这里不是零目标、零帮助、零练习，而是对刚出现的扩展不设“当场自主完美输出”的门槛。家长仍有明确意图：准确输入、帮助参与、逐渐建立联系。

十、问答和否定在自然需要中出现

【视频讲解｜19:35–20:45】 老师讨论在互动中引入否定，出现表达需要时马上给例子、帮助孩子说全。

【整理理解】 可以先看孩子当前能力：如果陈述尚不顺，家长可以主要负责示范问答；如果问答已较熟，孩子可以承担更多。不要因为“可以自然引入”，就同时开展陈述、问句、否定、复数的高要求轮换。

【补充示例】 远处是鱼卡，家长问 Is that a bowl?，用明确表情表示不是，示范 No, it isn’t.，再说 That is a fish.。孩子愿意时一起完成；不以独立说出全组对话作为初次扩展的通过条件。

否定的作用是纠正对象判断，不能仅为收集变形数量而脱离交流需要。

十一、A 和 B 能否同时集中推进

1. 本讲的明确建议：不要把两套新进度并行叠加

【视频讲解｜20:45–21:20】 有人问引导输出 A 能否同时进行 B，老师给出不赞成的回应。

【整理理解】 这里指把 A 和 B 都作为集中推进的新学习任务，不是禁止生活中听到任何 B 阶段会讲的表达。上面 smelly、Which 等扩展，已经说明自然输入可以比当前目标丰富。

2. 老师更担心“已知加 N＋不许错”

【视频讲解｜21:20–22:45】 老师强调，混淆并不是最重要的危险。如果一次增加很多未知，还不许孩子错，孩子可能不断觉得自己不行、产生畏难乃至放弃。她要求保持已知加一，意义准确，期待合适。

【整理理解】 本讲所谓“加一”，是控制当前新增负荷的教学思路，不是可以机械计数的语言公式。一句短英语也可能含三个陌生词、一个陌生句型和一个不明白的玩法；它很短，但对孩子并不一定简单。

3. 难了时先退回哪一层

【整理理解】 可按当前具体表现调整：

• 对象不懂：换成熟悉卡，不先要求新名词。

• 所指不清：减少目标、拉开卡片、明确方向。

• 句型不顺：给开头、一起说，暂不加入更多变形。

• 游戏规则不懂：先做动作示范，降低规则复杂度。

• 情绪畏难：停止连续追问，改成能参与的小任务。

这是一份整理出的降阶检查表，不是视频逐项公布的固定程序。

十二、家庭练习方案：远处卡片指认与角色互换

【补充示例｜以下方案为另写示范，不是老师指定的统一作业】

准备：熟悉材料＋共同视角

选孩子已熟悉的 3 张单个物体卡，例如 fish、egg、bowl。贴在距离大人与孩子相对较远的位置，彼此留出间隔。家长与孩子先站在同一侧，确保都知道目标在哪。

开始前可用一两个近处对象复习 This is …。如果连这个都需要大量逐词提示，本次把主要时间用于复习，不急着把那一页做完。

第一轮：成人明确选卡并示范

家长指着远处鱼卡：That is a fish.。孩子只补 fish 也可以作为参与起点，但成人仍给完整模型。每次换卡，保持句型目标不变。egg 的示范是 That is an egg.。

第二轮：随机选择，逐渐减少帮助

孩子选择一张远处卡，家长按需要给 That is … 的开头，让孩子补足。能说完整时，不再每词抢着带读。孩子卡住立即帮，不以沉默等待构成小测验。

第三轮：稳定后引入核实问句

指鱼卡：Is that a fish?，成人示范 Yes, it is.。再用一次明确的否定情境。若同时处理问句和否定太难，本次只保留其中一个，另一项留在后续。

第四轮：孩子当引导者

孩子选卡，成人用夸张但友善的表情表示“帮我一下”。由孩子指、补开头或发问，成人配合回答。角色游戏的重点是参与和交流，不是让孩子校改一串错误句。

第五轮：只加一个清楚的扩展

在 foot 卡或大脚图上，家长用大小对比引入 giant；或者用表情做 smelly 的故事玩笑。本次不同时要求孩子学会 giant、smelly、Which、问句和否定。允许看懂、动作参与、成人辅助。

收尾：留下可复用的小游戏

收卡或看绘本时再遇到远处指认，可以自然调用 That is …。记录哪项需要帮助，下次继续；不必在活动结束追加考试证明孩子已经会。

十三、常见误区对照

误区本讲支持的处理
偶尔错，所以绝不能进下一讲。看总体是否相对稳定；偶尔错可接受。
老师允许错，所以每句同样错也直接前进。系统性同错先停留，提供支持并补台阶。
过完前两讲，旧句型可以永久停止。高频基础表达继续在游戏、绘本和生活中使用。
每天必须复习全部英语语法。不同表达有使用权重，按实际阶段和场景循环。
家长离卡远就够，孩子在哪里无所谓。初期共同视角更清楚，避免站位造成歧义。
当前主练 That is，只允许这一句出现。有意义的旧表达和低期待扩展可以自然串联。
引入 smelly，就说明当天应独立会用。输入、辅助参与、主动调用是不同层次。
Zoom in 就是家长说更多更长。看孩子能否理解和参与，不以句子数量衡量。
零期待等于不设学习目标。不强求新增表达立即完美输出，仍有准确示范与持续帮助。
A、B 不并行意味着生活中禁用 B 的词句。不并行集中新任务，不封锁自然可理解输入。

十四、练后观察：真实进度怎样记

【整理理解】 不用将以下条目变成孩子的考试表。它们供成人判断下次怎样帮忙。

• 准备状态：This is … 换熟悉卡后能否较稳定组织？问句哪些还需滚动？

• 意义：孩子知道目标是远处哪一个吗？指向或站位是否有歧义？

• 名词：本次是熟悉词吗？a / an 等由成人示范是否正确？

• 输出层次：是跟读、开头提示后补足，还是自行完整组织？如实记录。

• 错误类型：偶发卡顿还是每次同一处错误？是否需要返回上一台阶？

• 扩展期待：刚出现 giant / smelly / Which 时，有没有当场加考试门槛？

• 情绪：孩子是在参与和享受，还是担心永远说不对？

• 延续：旧句型和本句在绘本、生活里是否还有使用机会？

本讲一句话复习：从熟悉材料和清楚的远处指认出发，让 That is … 在帮助下逐渐稳定；旧句型持续循环，扩展坚持意思清楚、已知加一，不把新输入立刻变成考试。
