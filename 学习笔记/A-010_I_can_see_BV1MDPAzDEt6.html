一、为什么老师把 I can see 视为关键句型

【视频讲解】 开头指出两项作用：它可以作为引入名词复数的支架，也让孩子接触 can 加动词原形的表达。但这些用途不是一次同时完成，要由浅入深。

【整理理解】 固定 I can see，后面先连接熟悉名词，可以减少句首变化，让注意力集中在“看见什么、一个还是多个”。后面再更换动词、代词或位置描述时，任务会增加，不应直接跳到全部综合表达。

本讲可以用一条主线记忆：确认数的理解 → 先练单数结构 → 单独连接数量与名词 → 放回整句 → 稳定后再换问法 → 在不同场景循环，并分阶段加难。

三、句首先固定，为什么比同时换动词更容易组织

1. 固定 see，把变化放在已熟悉名词上

【视频讲解】 老师比较：固定 I can see，再处理名词数量；与把 see 换成多个动作词，是不同的任务。后者需要先认识动作词，有些动作词还会带宾语，句子变化可能更多。

【整理理解】 比如 I can see a book 与 I can see two books，句首相同；而引入新的动作及其对象时，成人得重新确认动作词、对象词和意思。这个比较是在说明变量数量，不代表名词复数对每个孩子一定轻松。

2. can 后面的动词形式暂时先不全展开

【整理理解】 规范化结构是主语 + can + 动词原形。I can see 中 see 保持原形。这里让家长知道结构即可，不要求孩子先背“情态动词”术语，也不要求立即轮换所有可与 can 搭配的动词。

【视频讲解】 老师把换动词放在后面：已学过其他句型、引入了一些动作词以后，再回来扩展，也属于间隔调取和螺旋上升。

四、把本讲拆成四个可观察的小任务

【视频讲解】 老师在开头和后面操作段反复把内容拆开，而不是直接让孩子输出 I can see 加所有复数名词。

【整理理解】 按实际操作可归纳为以下四项；它们可以部分并行，不是必须先把一项“练满”才碰下一项：

小任务规范化例子主要减少哪种负担
理解并使用当前数量指着一、二、三个物体逐件数先确认数量概念，不连长句。
固定句首，连接单数名词I can see a book.先稳定句首和一个熟悉物体。
单独练数量加名词one book / two books / three books暂时不加句首，集中练数量和复数形式。
把已较顺的短语放进整句I can see two books.再把几段熟悉内容连接起来。

这些例句为 【补充示例】。根据孩子基础，某项可能很快接住，某项需要更多时间；不能把表格当作每天固定升一级的课表。

五、数的认知要单独看：会背数列，不一定会数物体

1. 至少区分三种表现

【视频讲解】 老师提醒：孩子即使会从一念到十，也未必能把数字准确放到物体前面，可能漏数或不能对应具体数量。

【整理理解】 可观察：

1. 会说数列：口头依次念数字。

2. 会点数：指一个物体数一次，不漏、不重复。

3. 会说数量短语：知道几件，能把数字与物体名称连接。

这些不是同一项任务。英语表达问题也可能与点数还不稳定交织，不要只纠正复数词尾，却没有看见数量对应的困难。

2. 不需要先拉到一百才能进入句型

【视频讲解】 老师建议，在孩子能理解的少量数字范围内先连接表达。一边继续使用句型，一边慢慢增加数的范围，而不是为了“这一项全学完”先强练大量数字。

【补充示例】 当前一、二、三能点清楚，就用这三个数量画书、摆球、找图片。暂时不为了丰富题目加入十七或三十二。

3. 数字范围是个体表现，不是年龄标签

【视频讲解】 老师多次提醒考虑认知，并建议成人了解有关年龄的背景信息。她同时提到不同孩子的基础和经验不同。

【整理理解】 本笔记不提供“某岁必须数到多少”的标准；现场以孩子真实点数、判断和表达表现设计任务。查询信息或使用人工智能也不能代替观察，更不能把一个概括回答当作孩子的硬性达标线。

六、有关数字和语言的插话，保留什么、不照搬什么

【视频讲解】 老师讨论较大数、不同语言的数字组成，以及中英文都值得继续学，借此解释数字训练不一定简单，应慢慢使用和扩展。

【整理理解】 本讲可直接用于备课的是：

• 不要因为数字词表短，就默认数量表达没有困难。

• 数量概念与英文说法分别检查。

• 当前少量数字会用，之后再扩大范围。

• 双语学习不需要用“非此即彼”的方式处理。

直播中关于“所有人都切母语算数”“某语言的人数学一定更强”等概括，不在笔记中写成普遍事实；个别孩子从小到大的经历，也不作为其他家庭的统一时间表。

七、鼓励四件套：目标是让可达到的小进步被看见

1. 前期动员

【视频讲解】 开始前让孩子知道要玩什么、能怎样参与，给一点期待和信心，而不是上来就测试会不会。

【补充示例】 “今天我们找三本书，你来当找东西的人。”任务简单明确，不用“你必须比昨天说得更好”作开场。

2. 过程中的辅助

【视频讲解】 发现孩子卡住，给必要帮助，再逐渐撤；观察贯穿过程，不只是结束后打分。

【整理理解】 可以帮助点数、示范短语、给句首或留末尾；针对实际卡点给，不要把所有内容一次都说出来后又责问为什么不能独立。

3. 尽量及时给正反馈

【视频讲解】 老师强调在表达发生时及时回应，希望孩子看见自己完成了哪一小项。她也说明这是努力方向，不是机械要求每句话都套同一句夸奖。

【整理理解】 正反馈不只是不停说 good job，也可以认真执行孩子的意思、承接他的判断、展示他找到的东西。不要让反馈中断正常交流。

4. 结束时具体表扬努力和进步

【视频讲解】 不只泛泛说“很棒”，而是点明哪里做得更清楚、尝试了什么、完成了什么。

【补充示例】 “你这次指一件数一件，还自己接出了 two books。”它比“你今天终于没错”更能说明实际进步。

5. 对成功体验的理解边界

【视频讲解】 老师以“成功是成功之母”提醒家长减少持续挫败，并调整任务到孩子够得到的范围。

【整理理解】 这里不转写成“做好四件套就保证孩子不再讨厌任何学习”。可操作的目标是：不把互动设计成反复失败的考核；困难时给可用辅助；结束时准确看见已经完成的部分。

八、先让 I can see 的意思可见

1. 遮住、显现，建立情境对照

【视频讲解】 老师用闭眼再看、拿出物体、拿走卡片或缺失游戏等思路，让孩子看到“能看见”和“现在看不到”的差别。

【补充示例】 用一块布遮住已熟悉的球，再揭开：成人配合动作示范 I can see a ball。孩子愿意时接 ball 或 a ball；不需要闭眼，也能完成遮挡对照。

2. 否定可以由成人示范，不必同时成为输出目标

【视频讲解】 看不到时，成人可以给相应否定样本帮助理解，但孩子这次并不一定需要自己说 I can’t see it。

【整理理解】 “用正反对照传递意思”与“当前要求两个形式都能独立调用”要分开。先把肯定结构练起来，否定何时展开看后续安排和实际基础。

3. 不把看见练习变成背答案

如果物体每轮都不同，孩子需要依据当前内容选名词；如果只是成人反复同一句、孩子跟读，能说明声音熟悉了一些，却不能直接说明现场调用已经稳定。

九、数量加名词：先用实物或简单图画单独练

1. 画一件、再画一件，数量变化清楚可见

【视频讲解】 老师用容易画的物体举例，例如书或船：画出一件，再增加到两件、三件，把 one…、two…、three… 与具体数量相连。

【补充示例】 在纸上画一、二、三本书；指着对应组说 one book、two books、three books。画在单独纸上即可，不需要修改原卡片，也不追求精致插画。

2. 数字与复数形式一起听、一起用

【视频讲解】 老师希望孩子多次接触正确数量短语，而不是先长期固定错误组合，之后才纠正。

【整理理解】 对成人来说，先选少量自己确定的词形和读法，再提供正确样本。孩子出现漏词尾时可以自然示范、再辅助，不把“先听正确”变成“任何错误都不许发生”。

3. 规则复数不只等于机械写一个 s

【补充示例】 book/books、boat/boats 可作为简单起点；watch/watches 的形式和读法不同。成人应先核对，不在孩子刚建立数量关系时突然增加一串不熟规则。视频不是本笔记编写的完整复数语法课。

4. 说顺短语，再连回句首

【整理理解】 孩子已经能说 two books 时，成人先给 I can see…，孩子接 two books；接得顺，再考虑完整连接。若句首一加就卡，先继续短语和情境，不急于扩词量。

十、移动游戏让短语反复出现，而不是增加难度

【视频讲解】 可以把画着不同数量的纸放到地上，成人说一个，孩子移到相应图并说出来；速度、声音和顺序可以变化。

【补充示例】 三张纸分别是一本、两本、三本书。孩子可以走过去、指过去或移动一个小玩偶，按自己的意愿参与。成人先说慢一点，孩子完成熟悉短语；不以跑得快作为语言成绩。

【整理理解】 这里主要变化的是活动形式，语言内容可以保持稳定。若孩子点数还不稳，就只保留两张；若移动后忘了短语，就先指图说，再逐渐连接动作。

十一、视频说“本来以复数出现的词”，要注意区别

【视频讲解】 老师举了 glasses，以及图片里常呈现成组的 bananas、grapes 等例子，希望家长让孩子在相关场景中接触复数，而不是一直只练单个物体。

【整理理解】 这些例子不能全部归成“永远只用复数的名词”：

• glasses 若指眼镜，常用这种复数形式；不要用 a glasses 表示一副眼镜。

• bananas、grapes 可以在多个香蕉或葡萄的画面中用复数；一个香蕉是 a banana，一个葡萄是 a grape。

• glass 本身还有其他意思，因此不能由眼镜的用法推断所有 glass 都只能复数。

【补充示例】 确实有多个葡萄时示范 I can see grapes；确实只有一个香蕉时示范 I can see a banana。名词形式要符合你在谈的内容，不为了练复数而把实际单个道具硬说成多个。

十二、稳定以后，再展开问法

1. 一般疑问句：Can you see…?

【视频讲解】 成人先提供足够问句样本，孩子根据眼前情况回应，之后才更容易自己提问。

【补充示例】 Can you see a book? 可以回答 Yes, I can，也可以在练习需要时说 Yes, I can see a book。不应把真实沟通中的短回答判为语法错误。

2. 特殊疑问句：What can you see?

【视频讲解】 用来引出看见什么，可以回应已经练过的单数或复数名词结构。

【整理理解】 此时变化主要在问法。孩子是否会答，还要看他能否识别内容和理解问题，不是见到 can 就自动懂。

3. 问数量：How many… can you see?

【视频讲解】 老师明确说，how many 又要单独安排，不与 what 的任务一口气混成一项。

【补充示例】 How many books can you see? → I can see two books. 此处 books 是复数；问数量与只问“看见什么”不同。成人可以先用简短数量回应，但希望练全句时也要给足样本和辅助。

4. 问句不是第一天一起全压上

【整理理解】 不是认识 I can see 后立刻要求自己发问、反问、数数量、否定并连接新物体。按照实际需要每次增加一项；成人输入可以比孩子输出丰富，但要保持可理解。

十三、大数、换动词、加位置，为什么不在这里拉满

大数：可以后面回来，不必现在一次背完

【视频讲解】 老师谈到较大孩子可能对更大整数有兴趣；也说明不必为想象游戏画出全部数量。但这是后面的扩展，不是小数字刚开始就要求掌握数百、数千和复杂组合。

【整理理解】 想象游戏要先明确“现在是在假装”，否则孩子可能困惑为什么眼前没有对应数量。本笔记不把直播里大数名称的含混识别硬写成完整词表。

换动词：已有相应词汇后，再回到 can 的框架

【视频讲解】 先把 I can see 的用途稳定，再在动词有基础时回来扩大。这不是错过了课程，而是分次完成。

加位置：介词本身也要有铺垫

【视频讲解】 结尾答疑提到加地点，但提醒应再往后安排，因为位置、介词也是需要单独练的内容。

【补充示例】 I can see two books on the table 把数量、名词和位置连起来；它可以作为未来目标，不是刚会 I can see a book 当天就必须达到的版本。

代词和冠词：在使用中继续练，不等于一次全变

【视频讲解】 老师提醒，句型不只有表面那几个词，代词、冠词、复数等会在各次表达里出现。不能只背条目标题，就认为内部各项都完成。

十四、横向扩展：数字范围不变，换内容和场景

【视频讲解】 孩子只能数当前少量数字时，也可以在绘本中数不同物体，不需要立刻扩大数字范围。会回去复习是整个内容安排的一部分。

【补充示例】 已能用一、二、三：今天摆两本书，明天在绘本中找两只已认识的动物，后天找桌上的三件熟悉物品。新名称若不熟，成人先帮，不把新词也作为同一轮测试。

【整理理解】 横向扩展主要是“用得更广”，纵向增加可能是更大数字、更长结构或更难问法。两者都可以安排，但不要每次迁移都同时进行。

十五、循环复习为什么不是反复同一段文本

【视频讲解】 老师在收尾强调：旧句型和旧词可以多次出现，但每次场景、组合和表演可以不同，需要当场选择和连接。

【整理理解】 三种活动有不同作用，不能互相冒充：

1. 跟读原句：熟悉声音和节奏。

2. 在明确情境中接末尾：开始连接结构和内容。

3. 面对变化自己选词：练当前内容的组织和调用。

跟读不是没有价值，但完成跟读不能直接证明第三项已经稳定。循环时要观察孩子是否依据当下物体表达，而不只是说最熟的原答案。

十六、家庭练习示范：两条基础线，最后再连接

以下为 【补充示例】，不是原视频固定课表。

A 线：看见什么

• 用两三件熟悉物体，遮住再显现。

• 成人示范 I can see a…，孩子完成能接的部分。

• 保留肯定目标；看不到时成人可以示范否定，不强制孩子一起说。

B 线：几个物体

• 从孩子已能点清楚的一、二或三开始。

• 同一种熟悉物体，不先混很多名称。

• 数量短语由成人正确示范，孩子逐步接话。

连接两条线

• 短语较顺后，成人给 I can see…，孩子接 two books。

• 有必要时再回到 A 线或 B 线，不以退回为失败。

• 整句稳定后只换一个问法或一个场景。

• 下一轮复习保留旧内容，但改变顺序、物体或小情节。

收尾

具体说孩子今天做到了什么；记录卡在点数、名词形式、句首连接还是问法理解。下一次只针对一个主要卡点调整。

十七、常见误读与成人自测

容易误读更贴近本讲的理解调整方向
会念一到十，数量表达就会了数列、点数、数量短语不同单独看对应关系和连接
句型短，一周可以顺便练所有变化单数、复数、问法和位置都有变量当前只新增可处理的一项
一开始就必须练 I can’t see正反示范用于理解，不等于双重输出要求成人可先说否定样本
bananas/grapes 永远只能复数多个时用复数，单个也有单数根据实际场景选择形式
回到旧句型说明进度倒退带变化回来是循环的一部分观察新情境的实际调用
鼓励四件套保证所有学习都顺利重点是辅助和准确看见进步不作效果承诺，不忽视状态

成人复习问题：我今天看到的是“会背数字”还是“会点数”？哪部分应保持不变？我提供的数量短语是否准确？问数量是否又增加了一个新任务？下一次如何在同样数字范围内换一个有意义场景？

一句话总结：I can see 是承载熟悉名词和数量的支架；把数的理解、单数结构、数量短语、复数整句拆开，再用可见情境和辅助逐步连接，之后通过换问法、换场景和间隔回调继续扩展。
