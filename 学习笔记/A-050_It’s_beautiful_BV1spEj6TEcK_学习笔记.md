# A-050｜It’s beautiful：评价、理由与行动

## 来源与阅读说明

原视频：https://www.bilibili.com/video/BV1spEj6TEcK/
本笔记依据主转写分段通读、关键窗口第二模型识别对照与视频画面抽样整理；不是人工逐字听写或完整字幕校订，也不替代原视频。
【视频讲解】概括课堂内容；【整理理解／语法规范化】区分整理判断与规范；【补充示例／练法】为便于使用新增，并非原话。时间为定位用近似范围。

## 1. be＋形容词，开始承担评价的功能

【视频讲解｜约00:00–03:00】老师从结构问到用途：It’s beautiful. 不只是一个主系表句，也是在表达评价。不同人对美、冷热等可能感受不同，不能因为成人持不同看法，就要求孩子照自己的意见回答。

【整理边界】区分可核查的事实、个人感受与评价；人的认识会修正，不等于事实都任意变化或所有主张同样可靠。审美讨论不必先争出唯一正确答案。

## 2. 先把彼此真正的理由说清楚

【视频讲解｜约03:00–09:00】课堂借穿衣分歧展开：成人说清自己的担心，听孩子处境、身体感受或不想被孤立的理由，再一起协商。只说“别人都这样”，与描述自己的实际体验，并不是同一种支持。老师还提醒，事后别急着用 I told you so. 证明成人早就正确；把经历变成共同更新的经验，不抢走孩子自己思考的空间。

【整理边界】这是沟通示例，不把年龄、风力、穿衣或感冒说法变成统一健康规则，也不让孩子通过危险冷暴露证明谁对。语言练习可改用玩偶选衣，真实照护按实际情况处理。

## 3. 观点后面，接细节、理由或例子

【视频讲解｜约09:00–12:00】老师强调用 details、reasons、examples 支持 opinion，并把讨论指向共同理解和协商，而不是压服另一方。重点在解释“为什么这样想”，不是机械背一个标准答案。

【整理理解】对小孩子，一个颜色、形状或部位的理由已经可以成为起点，不要求一次列出三条完整论证。也不把课堂中的文化比较、考试或成长结果当普遍事实与保证。

## 4. 孩子觉得漂亮，先听他看见了什么

【视频讲解｜约12:00–16:30】即使成人觉得某张动物卡不好看，也可以先接住孩子的判断，再问 Can you tell me why?。孩子可能喜欢角、力量感等某一特征。成人可丰富艺术接触与观察，但不靠争执强改答案。

【整理边界】本讲有关顶级审美、色彩和作品高低的判断不写成普适定律；不设“穿衣不能超过几种颜色”等硬标准。描述自己的偏好与理由，比给孩子贴审美好坏标签更适合本练习。

## 5. 不漂亮怎么办？做一个能改进的小项目

【视频讲解｜约16:30–20:00】老师用机器人方脸等例子，把 Is it beautiful? → Why not? 接到 How can we improve it?，再尝试 Make it round.。觉得已经美，也能讨论是否愿意再作变化。

【补充练法】画一张机器人脸，孩子任选圆脸、颜色或装饰，说一项想改的地方，再真的改画。改进是可选创作，不意味着孩子喜欢的东西必须被成人修正，也不评价真实人物外貌。

## 6. “是什么—为什么—怎么办”，落在可做的事

【视频讲解｜约20:00–24:00】本讲把 project 作为展开方向：一起完成一个任务、有一个作品或改变。绘本也能联系孩子自己的生活，例如想不想加入游戏、多人一起玩怎样更开心、遇到分歧怎么处理。

【整理理解】落地可以很小：一幅画、一段介绍、一个共同决定，不是每次阅读都要交作品。课堂关于升学或工作的引申不当作所有制度的通则；知识理解与安静阅读也有自身价值。

## 7. 月亮很美：一个新词展开后，再回到主线

【视频讲解｜约24:00–26:00】老师用绘本月亮举例：觉得美，问理由；从颜色引入 silver，找别的同色物，再回到是否喜欢这轮月亮，接生活里见过的月亮、想画什么颜色。扩展后仍回到原来的评价任务。

【补充示例】I think the moon is beautiful. — Why? — I like its color. 如果 silver 是新词，其他句式尽量用熟悉的；复杂经历问句可由成人示范，不与新词一起强求输出。

## 8. 复数不只有全部肯定或全部否定

【视频讲解｜约26:00–28:30】面对多张卡，可分为都好看、都不好看、有些好看有些不好看，再逐个给理由或选一组改画。分类本身让复数表达有了真正的意思。

【语法规范化】They’re all beautiful. / Some are beautiful; some are not. 指定范围中余下全部可说 the others；泛指另一些可说 others，不把两者机械互换。I think 可标明个人判断，不要求别人接受相同审美。

## 9. 每页一个对象，也能在结尾汇总成复数

【视频讲解｜约28:30–30:00】老师提出，读完整本再把各页喜欢的对象合在一起回顾，就能说 They’re all beautiful.；也可带着“找美的东西”的小任务阅读，再数一数、介绍一下。

【补充练法】①每人选一张自己觉得美的卡；②各给一个理由，允许不同；③一起选一张纸画作变化，最后用单数或复数总结。观察能否表达自己的评价、听见另一种理由，并提出一个愿意做的行动。

## 一页复盘

beautiful 是评价入口：允许彼此觉得不同，先听理由，再讨论想做什么。练习不止于答漂亮或不漂亮，而是“是什么—为什么—怎么办”。
