Susan 随机组句｜核心速读

先看核心版

共 10 讲核心笔记

A-001 · 核心版

It’s a…｜说清“它是什么”

用清楚、熟悉的物体，把名词放进完整表达；不是只报词，也不是背固定顺序。

阅读核心版 →详细版
就地展开重点

记住这 3 点

  • 先传递意思：拿孩子知道是什么的实物或清晰图片，指着示范 It’s a…；多换对象，让句子与所指物对应。
  • 词和句型一起长：已知名词带新句型，熟悉句型再带新名词；起步材料少一些，别同时堆很多陌生词。
  • 帮助不等于考试：只说出名词也能参与，成人补开头、一起连成句，再逐渐减少提示；陈述较顺后才增加问答。

怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频逐句原话或统一作业。

  1. 准备几件熟悉的单个物体，成人先指认并完整示范。
  2. 孩子说 ball 时，给 It’s a… 的开头，一起完成 It’s a ball.；需要时继续带着说。
  3. 打乱顺序、换实物或绘本里的同类对象，看孩子是否仍能组织，而不是只会跟原顺序背。

It’s a ball. / It’s an egg. —— 同一表达，换熟悉名词。

易错提醒

  • a / an 按后面词的起始发音选择，也不能套在所有名词前；如通常意义的 water 不说 a water。成人先给正确模型。
  • 本轮先不把否定、复数、自主提问全部压上；会一次不等于以后都能独立用。

只观察这一件事：对象换了、顺序换了，还能在较少提示下说明它是什么吗？

A-002 · 核心版

This is…｜理解“这一个”

不仅换一个句子开头，还要让孩子看清“指的是这一个”，并把表达从卡片带到生活。

阅读核心版 →详细版
就地展开重点

记住这 3 点

  • 指示关系要清楚：用近处实物、手势与明确目标传递 this；近远来自情境，不是背中文翻译。
  • 内化有五个环节：辅助组句 → 围绕对象扩展（Zoom in）→ 绘本 → 日常 → 相近句型混用；不是各做一次就毕业。
  • 新旧表达继续滚动：集中一轮练 This is…，另一轮复习 It’s…；两个都不稳时，不逐卡随机切换考孩子。

怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频逐句原话或统一作业。

  1. 拿近处熟悉物体，明确指着说 This is a ball.，让语言和所指物对上。
  2. 只会说 ball 就给开头、一起说；加一个孩子看得懂的动作或声音，使互动有回应。
  3. 换到玩具、绘本和生活中继续指认；陈述较顺后再示范 Is this…?，逐步交换问答角色。

This is a ball. → Is this a ball? — Yes, it is.（后一步视理解情况加入。）

易错提醒

  • 孩子说 It’s a ball. 可能交流正确，只是没有用本轮目标；认可意思，再示范 this。
  • 及时帮助，不等于永远替答；问句、否定、复数不必首轮同时掌握，也没有统一几天达标期限。

只观察这一件事：离开原卡片，在真实指认中还会用吗？

A-003 · 核心版

That is…｜指认远处，旧句继续用

把“那个”放进清楚的远处指认情境；只加一个主要新难点，前面的句型不能学完就消失。

阅读核心版 →详细版
就地展开重点

记住这 3 点

  • 进入新讲先看基础：熟悉卡打乱后，This is… 能较稳定组织；偶尔错可提示，每句同处都错就再补台阶。
  • 远处目标要清楚：起步时成人与孩子站在同一侧、都离目标较远，再明确指向；that 不按固定米数划线。
  • 扩展与输出分层：giant、smelly 或选择游戏语可在清楚情境中出现，但听过、辅助说过不等于马上独立会用。

怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频逐句原话或统一作业。

  1. 将熟悉物体或卡片放在相对远处，双方站在一起，指着示范 That is a ball.。
  2. 给句首或一起说，换目标继续；陈述较顺后示范 Is that…?，让孩子逐步当提问者。
  3. 保留另一轮近处 This is… 和物体命名 It’s…；之后再依据情境练选择，不让旧表达退场。

远处：That is a ball.；近处：This is a ball.。先分轮练顺，再结合情境使用。

易错提醒

  • 成人远、孩子却抱着目标，可能使近远示范不清；先减少视角差异。
  • “已知加一”不是封锁其他输入，而是不并行推进多个陌生输出任务，又要求当场全对。

只观察这一件事：孩子能看清所指对象，并换熟悉名词组织句子吗？

A-004 · 核心版

What’s red?｜先认颜色，再描述物体

先分清颜色概念、英文标签和整句描述；用熟悉物体承载新颜色，不只背 red。

阅读核心版 →详细版
就地展开重点

记住这 3 点

  • 先盘点已知：学过前三讲，不代表词句都能调用；优先用孩子能认的名词，把新增负荷留给颜色。
  • 三层分开看：能同色匹配、听懂或说 red、能说 The ball is red.，是不同任务；卡住先找卡在哪层。
  • 颜色少量反复用：同色聚类、异色对比、寻找与分类，再迁移到绘本和衣物；不是挂了色表就自动学会。

怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频逐句原话或统一作业。

  1. 取几件颜色差别清楚的熟悉物品，先示范 red，让孩子找红色；可以先用指认参与。
  2. 找到后提供完整模型 The ball is red.；整句难就先词或短语，再逐步连句。
  3. 换帽子、卡片等旧名词继续描述，之后到房间或绘本里找红色，让旧词得到新用途。

What’s red? — The ball is red.；red → red hat → The hat is red. 可作降阶支架。

易错提醒

  • What’s red? 是找“什么是红的”，不等同于问某物颜色的 What colour is it?。
  • 指出是在说物体、卡片还是背景；不同时塞进很多新色、陌生名词和长句，也不追求一次教会。

只观察这一件事：孩子是在理解颜色关系，还是只对一张固定卡说 red？

A-005 · 核心版

What is blue?｜小台阶与撤提示

会说 blue 不等于会整句；困难时缩短表达，熟悉后留组织机会，别一直替孩子答。

阅读核心版 →详细版
就地展开重点

记住这 3 点

  • 台阶可进可退：blue → It’s blue. → The hat is blue.；中间短句是可选支架，不是所有孩子必走的固定流程。
  • 问答跟着理解加入：颜色与对象清楚后，逐步核实 Is it blue?，再示范否定；No 已有意思，不用先判错。
  • 新旧组合持续循环：同色换熟悉对象、旧色连新对象；复习时先给组织机会，卡住再补开头或完整模型。

怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频逐句原话或统一作业。

  1. 用熟悉的蓝帽或蓝球传义；按孩子当前能力示范短句或具体物体描述。
  2. 意思清楚后问 Is it blue?；孩子只说 Yes / No，就承接意思并示范较完整回答，不强迫重答。
  3. 下一轮先留接话机会，需要时加提示；在绘本或生活物品中复用，不只刷蓝色专用卡。

It’s blue. / The hat is blue.；自然遇到牛仔裤时用 The jeans are blue.。

易错提醒

  • jeans 自然用复数形式，成人不能为了只练 is 而示范错误句；但这不等于立即全量练复数。
  • 撤提示不等于禁止再帮助；颜色、名词、问法和规则不要一起变新，也不照搬别人的学习天数。

只观察这一件事：孩子比上次少需要哪一段提示？遇到困难，是否仍能得到支持？

A-006 · 核心版

It’s a yellow pear｜颜色放到名词前

把已熟悉的颜色和名词连接成描述；新增重点是组合结构，而不是又学一堆新词。

阅读核心版 →详细版
就地展开重点

记住这 3 点

  • 先确认旧基础：颜色标签、物体名称和基本句首尽量熟悉；别把新颜色、新名词、新问法同时当输出目标。
  • 句子切成小段：yellow book → a yellow book → It’s a yellow book；成人给够模型，再留一小段让孩子接。
  • 先分组，后混合：同色换物体练顺；加入新颜色时累计复习旧组，再逐步混色、交换提问角色和迁移场景。

怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频逐句原话或统一作业。

  1. 先用熟悉对象和旧句预热，让孩子知道自己能参与；再示范 a yellow pear 这一新组合。
  2. 整句难就练短语，能接一小段就留一小段；提示按反应增减，不硬等孩子失败。
  3. 同色换熟悉名词，较顺后再换颜色；听懂 Is it a yellow pear? 后逐步引导问答和角色互换。

a yellow pear → It’s a yellow pear.；换熟悉物体：It’s a yellow book.。

易错提醒

  • 孩子只说 Yes 可能已经正确回应；承接意思、补完整模型，不把简短回应一概判错。
  • The pear is yellow. 与 a yellow pear 都能连物体和颜色，但结构不同；不要只背梨这一句。

只观察这一件事：换熟悉颜色或名词，还能组合吗？需要的是词汇帮助，还是句子开头？

A-007 · 核心版

What is big?｜检查概念，控制新难度

句法看起来类似，实际任务仍可能不同；先看“大”的概念与表达分别是否接得住。

阅读核心版 →详细版
就地展开重点

记住这 3 点

  • 分开看认知与语言：能判断当前对象大不大，和能听懂 big、组织完整句，不是同一件事。
  • A 系列是在示范小步推进：熟悉名词、句首、游戏为新内容搭桥；把这套方法迁移到后面，而不是只记课序。
  • 成人完整输入，孩子分层参与：给简单、清楚的句子；孩子可以先指认或接短段，不必马上复现成人全部语言。

怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频逐句原话或统一作业。

  1. 选熟悉、大小对比清楚的物体，先让孩子通过指认或分类理解当前 big 的意思。
  2. 示范 The ball is big.，再按能力给句首或留 big；如果接不住，就减短、换熟悉材料。
  3. 把熟悉对象放在一起复习、换对象描述；更完整的大小游戏与扩展可结合 A-008，不急着一轮做全。

What is big? — The ball is big.（对象与大小关系要清楚。）

易错提醒

  • 能说颜色句，不代表大小概念和大小描述自动会；不能只因语法类似就跳过传义。
  • 尝试引导后若困难，降低要求；别把多种新词、句型变换和复杂规则一起作为输出考点。

只观察这一件事：孩子卡在判断大小、听懂 big，还是把词连接成句？下一步只补当前卡点。

A-008 · 核心版

What is small?｜观察、接受、调整

看到孩子的实际困难再调整要求；输出可以变短，但仍保留看得懂、听得懂的互动。

阅读核心版 →详细版
就地展开重点

记住这 3 点

  • 观察不是打分：先看卡点，接受当前能参与到哪一步，再减短句子、减少陌生词或补提示。
  • 大小有参照：同一物体与不同对象比较，可能显得大或小；先说清比较情境，不能把意见不同自动判错。
  • 输入和输出要求分开：成人可用不同的清楚问法邀请一个熟悉回答；my / your 可配归属和手势输入，不强求当场自主说。

怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频逐句原话或统一作业。

  1. 用熟悉物体建立明显对比，先指认 small；成人说清自己指的是哪个物体。
  2. 示范 The ball is small.；孩子说 small 也先承接，再给句首、一起连句。
  3. 随理解程度换对象或加入明确归属的物品；孩子接不住就退一步，不因为计划写了就硬推进。

What is small? — The ball is small.；my / your 先配合谁拿着、谁拥有来理解。

易错提醒

  • 降低输出难度，不是从此取消所有可理解的多样输入，也不是永久停在单词。
  • 初期 big / small 任务不叠加比较级、多种时态和生词；所谓短句也不能装满陌生词。

只观察这一件事：孩子能用动作或短语参与吗？调整之后，是更容易接话还是仍在猜？

A-009 · 核心版

It’s not / It isn’t｜否定句切小练

说不出否定句时，先定位困难，再把表达切小；稳定之后才混合肯定与否定。

阅读核心版 →详细版
就地展开重点

记住这 3 点

  • 困难不只有“不懂”：可能是连读、句长、意思或不愿参与；先区分，再决定慢一点、分段或换互动。
  • 给可接的小段：It is not 可拆开练，成人说前面、孩子接 not；逐步连回句子，不要求第一次就全说。
  • 先单项，再混合：借熟悉词、玩具角色、简单规则反复使用，较顺后再切换肯定与否定，迁移到绘本和角色游戏。

怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频逐句原话或统一作业。

  1. 指着明确的熟悉对象，示范一个不符合眼前物体的判断，让“不是”有清楚意思。
  2. 示范 It is not…，按卡点分段、变语速或让玩具接话；孩子能完成一小段就继续搭桥。
  3. 表达较顺后轮流判断，再带到绘本中否认或纠正角色说法；遇到困难就回到短段帮助。

指着船：It is not a car. / It isn’t a car.；可由成人先说 It is，孩子接 not。

易错提醒

  • No, it’s a boat. 可能交流正确，只是没用目标否定结构；先认可意思，再示范目标句。
  • 不把初始困难变成持续纠错比赛；直播里的年龄、脑或 AI 类插话不作发展标准或研究结论。

只观察这一件事：分段后能接上吗？换回完整句或新场景时，还需要哪一小段帮助？

A-010 · 核心版

I can see…｜数量与整句分开搭桥

固定 I can see，再连接熟悉名词和数量；会背数列，不代表会点数或会说数量短语。

阅读核心版 →详细版
就地展开重点

记住这 3 点

  • 数量任务分开看：口头数列、逐件点数、数量加名词分别观察；先用孩子能点清的小数量，不急着扩到大数。
  • 四个小任务可拆可连：当前数量 → 单数整句 → 数量名词短语 → 复数整句；按卡点练，不是每天固定升一级。can 后接动词原形，先固定 see。
  • 鼓励贯穿过程：开始前说明任务，过程中给帮助，表达时及时回应，结束时具体指出努力和进步；不只是泛泛夸“棒”。

怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频逐句原话或统一作业。

  1. 摆一到几件熟悉物体，让孩子指一件数一件；数量不清就先帮助点数。
  2. 先说 I can see a book.，再单练 one book / two books，成人示范正确单复数。
  3. 短语较顺后连成 I can see two books.；之后再分阶段加问句、换场景，不同时轮换许多动词。

one book → two books → I can see two books.（不是 three book。）

易错提醒

  • 不要只纠正词尾而忽略漏数、重复数；数字范围看实际能力，不按年龄硬设线。
  • banana / grape 都有单数，并非永远复数；问句和更大数字随后逐步扩展，没有统一达标天数。

只观察这一件事：孩子现在困难在点数、复数短语，还是接上 I can see？只增加当前够得着的一步。
