A-001 · 核心版

It’s a…｜说清“它是什么”

用清楚、熟悉的物体，把名词放进完整表达；不是只报词，也不是背固定顺序。

阅读核心版 →详细版
就地展开重点

记住这 3 点

  • 先传递意思：拿孩子知道是什么的实物或清晰图片，指着示范 It’s a…；多换对象，让句子与所指物对应。
  • 词和句型一起长：已知名词带新句型，熟悉句型再带新名词；起步材料少一些，别同时堆很多陌生词。
  • 帮助不等于考试：只说出名词也能参与，成人补开头、一起连成句，再逐渐减少提示；陈述较顺后才增加问答。

怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频逐句原话或统一作业。

  1. 准备几件熟悉的单个物体，成人先指认并完整示范。
  2. 孩子说 ball 时，给 It’s a… 的开头，一起完成 It’s a ball.；需要时继续带着说。
  3. 打乱顺序、换实物或绘本里的同类对象，看孩子是否仍能组织，而不是只会跟原顺序背。

It’s a ball. / It’s an egg. —— 同一表达，换熟悉名词。

易错提醒

  • a / an 按后面词的起始发音选择，也不能套在所有名词前；如通常意义的 water 不说 a water。成人先给正确模型。
  • 本轮先不把否定、复数、自主提问全部压上；会一次不等于以后都能独立用。

只观察这一件事：对象换了、顺序换了，还能在较少提示下说明它是什么吗？

A-002 · 核心版

This is…｜理解“这一个”

不仅换一个句子开头，还要让孩子看清“指的是这一个”，并把表达从卡片带到生活。

阅读核心版 →详细版
就地展开重点

记住这 3 点

  • 指示关系要清楚：用近处实物、手势与明确目标传递 this；近远来自情境，不是背中文翻译。
  • 内化有五个环节：辅助组句 → 围绕对象扩展（Zoom in）→ 绘本 → 日常 → 相近句型混用；不是各做一次就毕业。
  • 新旧表达继续滚动：集中一轮练 This is…，另一轮复习 It’s…；两个都不稳时，不逐卡随机切换考孩子。

怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频逐句原话或统一作业。

  1. 拿近处熟悉物体，明确指着说 This is a ball.，让语言和所指物对上。
  2. 只会说 ball 就给开头、一起说；加一个孩子看得懂的动作或声音，使互动有回应。
  3. 换到玩具、绘本和生活中继续指认；陈述较顺后再示范 Is this…?，逐步交换问答角色。

This is a ball. → Is this a ball? — Yes, it is.（后一步视理解情况加入。）

易错提醒

  • 孩子说 It’s a ball. 可能交流正确，只是没有用本轮目标；认可意思，再示范 this。
  • 及时帮助，不等于永远替答；问句、否定、复数不必首轮同时掌握，也没有统一几天达标期限。

只观察这一件事：离开原卡片，在真实指认中还会用吗？

A-003 · 核心版

That is…｜指认远处，旧句继续用

把“那个”放进清楚的远处指认情境；只加一个主要新难点，前面的句型不能学完就消失。

阅读核心版 →详细版
就地展开重点

记住这 3 点

  • 进入新讲先看基础：熟悉卡打乱后，This is… 能较稳定组织；偶尔错可提示，每句同处都错就再补台阶。
  • 远处目标要清楚：起步时成人与孩子站在同一侧、都离目标较远，再明确指向；that 不按固定米数划线。
  • 扩展与输出分层：giant、smelly 或选择游戏语可在清楚情境中出现，但听过、辅助说过不等于马上独立会用。

怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频逐句原话或统一作业。

  1. 将熟悉物体或卡片放在相对远处，双方站在一起，指着示范 That is a ball.。
  2. 给句首或一起说，换目标继续；陈述较顺后示范 Is that…?，让孩子逐步当提问者。
  3. 保留另一轮近处 This is… 和物体命名 It’s…；之后再依据情境练选择，不让旧表达退场。

远处：That is a ball.；近处：This is a ball.。先分轮练顺，再结合情境使用。

易错提醒

  • 成人远、孩子却抱着目标，可能使近远示范不清；先减少视角差异。
  • “已知加一”不是封锁其他输入，而是不并行推进多个陌生输出任务，又要求当场全对。

只观察这一件事：孩子能看清所指对象，并换熟悉名词组织句子吗？

A-004 · 核心版

What’s red?｜先认颜色，再描述物体

先分清颜色概念、英文标签和整句描述；用熟悉物体承载新颜色，不只背 red。

阅读核心版 →详细版
就地展开重点

记住这 3 点

  • 先盘点已知：学过前三讲，不代表词句都能调用；优先用孩子能认的名词，把新增负荷留给颜色。
  • 三层分开看：能同色匹配、听懂或说 red、能说 The ball is red.，是不同任务；卡住先找卡在哪层。
  • 颜色少量反复用：同色聚类、异色对比、寻找与分类，再迁移到绘本和衣物；不是挂了色表就自动学会。

怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频逐句原话或统一作业。

  1. 取几件颜色差别清楚的熟悉物品，先示范 red，让孩子找红色；可以先用指认参与。
  2. 找到后提供完整模型 The ball is red.；整句难就先词或短语，再逐步连句。
  3. 换帽子、卡片等旧名词继续描述，之后到房间或绘本里找红色，让旧词得到新用途。

What’s red? — The ball is red.；red → red hat → The hat is red. 可作降阶支架。

易错提醒

  • What’s red? 是找“什么是红的”，不等同于问某物颜色的 What colour is it?。
  • 指出是在说物体、卡片还是背景；不同时塞进很多新色、陌生名词和长句，也不追求一次教会。

只观察这一件事：孩子是在理解颜色关系，还是只对一张固定卡说 red？

A-005 · 核心版

What is blue?｜小台阶与撤提示

会说 blue 不等于会整句；困难时缩短表达，熟悉后留组织机会，别一直替孩子答。

阅读核心版 →详细版
就地展开重点

记住这 3 点

  • 台阶可进可退：blue → It’s blue. → The hat is blue.；中间短句是可选支架，不是所有孩子必走的固定流程。
  • 问答跟着理解加入：颜色与对象清楚后，逐步核实 Is it blue?，再示范否定；No 已有意思，不用先判错。
  • 新旧组合持续循环：同色换熟悉对象、旧色连新对象；复习时先给组织机会，卡住再补开头或完整模型。

怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频逐句原话或统一作业。

  1. 用熟悉的蓝帽或蓝球传义；按孩子当前能力示范短句或具体物体描述。
  2. 意思清楚后问 Is it blue?；孩子只说 Yes / No，就承接意思并示范较完整回答，不强迫重答。
  3. 下一轮先留接话机会，需要时加提示；在绘本或生活物品中复用，不只刷蓝色专用卡。

It’s blue. / The hat is blue.；自然遇到牛仔裤时用 The jeans are blue.。

易错提醒

  • jeans 自然用复数形式，成人不能为了只练 is 而示范错误句；但这不等于立即全量练复数。
  • 撤提示不等于禁止再帮助；颜色、名词、问法和规则不要一起变新，也不照搬别人的学习天数。

只观察这一件事：孩子比上次少需要哪一段提示？遇到困难，是否仍能得到支持？

A-006 · 核心版

It’s a yellow pear｜颜色放到名词前

把已熟悉的颜色和名词连接成描述；新增重点是组合结构，而不是又学一堆新词。

阅读核心版 →详细版
就地展开重点

记住这 3 点

  • 先确认旧基础：颜色标签、物体名称和基本句首尽量熟悉；别把新颜色、新名词、新问法同时当输出目标。
  • 句子切成小段：yellow book → a yellow book → It’s a yellow book；成人给够模型，再留一小段让孩子接。
  • 先分组，后混合：同色换物体练顺；加入新颜色时累计复习旧组，再逐步混色、交换提问角色和迁移场景。

怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频逐句原话或统一作业。

  1. 先用熟悉对象和旧句预热，让孩子知道自己能参与；再示范 a yellow pear 这一新组合。
  2. 整句难就练短语，能接一小段就留一小段；提示按反应增减，不硬等孩子失败。
  3. 同色换熟悉名词，较顺后再换颜色；听懂 Is it a yellow pear? 后逐步引导问答和角色互换。

a yellow pear → It’s a yellow pear.；换熟悉物体：It’s a yellow book.。

易错提醒

  • 孩子只说 Yes 可能已经正确回应；承接意思、补完整模型，不把简短回应一概判错。
  • The pear is yellow. 与 a yellow pear 都能连物体和颜色，但结构不同；不要只背梨这一句。

只观察这一件事：换熟悉颜色或名词，还能组合吗？需要的是词汇帮助，还是句子开头？

A-007 · 核心版

What is big?｜检查概念，控制新难度

句法看起来类似，实际任务仍可能不同；先看“大”的概念与表达分别是否接得住。

阅读核心版 →详细版
就地展开重点

记住这 3 点

  • 分开看认知与语言：能判断当前对象大不大，和能听懂 big、组织完整句，不是同一件事。
  • A 系列是在示范小步推进：熟悉名词、句首、游戏为新内容搭桥；把这套方法迁移到后面，而不是只记课序。
  • 成人完整输入，孩子分层参与：给简单、清楚的句子；孩子可以先指认或接短段，不必马上复现成人全部语言。

怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频逐句原话或统一作业。

  1. 选熟悉、大小对比清楚的物体，先让孩子通过指认或分类理解当前 big 的意思。
  2. 示范 The ball is big.，再按能力给句首或留 big；如果接不住，就减短、换熟悉材料。
  3. 把熟悉对象放在一起复习、换对象描述；更完整的大小游戏与扩展可结合 A-008，不急着一轮做全。

What is big? — The ball is big.（对象与大小关系要清楚。）

易错提醒

  • 能说颜色句，不代表大小概念和大小描述自动会；不能只因语法类似就跳过传义。
  • 尝试引导后若困难，降低要求；别把多种新词、句型变换和复杂规则一起作为输出考点。

只观察这一件事：孩子卡在判断大小、听懂 big，还是把词连接成句？下一步只补当前卡点。

A-008 · 核心版

What is small?｜观察、接受、调整

看到孩子的实际困难再调整要求；输出可以变短，但仍保留看得懂、听得懂的互动。

阅读核心版 →详细版
就地展开重点

记住这 3 点

  • 观察不是打分：先看卡点，接受当前能参与到哪一步，再减短句子、减少陌生词或补提示。
  • 大小有参照：同一物体与不同对象比较，可能显得大或小；先说清比较情境，不能把意见不同自动判错。
  • 输入和输出要求分开：成人可用不同的清楚问法邀请一个熟悉回答；my / your 可配归属和手势输入，不强求当场自主说。

怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频逐句原话或统一作业。

  1. 用熟悉物体建立明显对比，先指认 small；成人说清自己指的是哪个物体。
  2. 示范 The ball is small.；孩子说 small 也先承接，再给句首、一起连句。
  3. 随理解程度换对象或加入明确归属的物品；孩子接不住就退一步，不因为计划写了就硬推进。

What is small? — The ball is small.；my / your 先配合谁拿着、谁拥有来理解。

易错提醒

  • 降低输出难度，不是从此取消所有可理解的多样输入，也不是永久停在单词。
  • 初期 big / small 任务不叠加比较级、多种时态和生词；所谓短句也不能装满陌生词。

只观察这一件事：孩子能用动作或短语参与吗？调整之后，是更容易接话还是仍在猜？

A-009 · 核心版

It’s not / It isn’t｜否定句切小练

说不出否定句时，先定位困难，再把表达切小；稳定之后才混合肯定与否定。

阅读核心版 →详细版
就地展开重点

记住这 3 点

  • 困难不只有“不懂”：可能是连读、句长、意思或不愿参与；先区分，再决定慢一点、分段或换互动。
  • 给可接的小段：It is not 可拆开练，成人说前面、孩子接 not；逐步连回句子，不要求第一次就全说。
  • 先单项，再混合：借熟悉词、玩具角色、简单规则反复使用，较顺后再切换肯定与否定，迁移到绘本和角色游戏。

怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频逐句原话或统一作业。

  1. 指着明确的熟悉对象，示范一个不符合眼前物体的判断，让“不是”有清楚意思。
  2. 示范 It is not…，按卡点分段、变语速或让玩具接话；孩子能完成一小段就继续搭桥。
  3. 表达较顺后轮流判断，再带到绘本中否认或纠正角色说法；遇到困难就回到短段帮助。

指着船：It is not a car. / It isn’t a car.；可由成人先说 It is，孩子接 not。

易错提醒

  • No, it’s a boat. 可能交流正确，只是没用目标否定结构；先认可意思，再示范目标句。
  • 不把初始困难变成持续纠错比赛；直播里的年龄、脑或 AI 类插话不作发展标准或研究结论。

只观察这一件事：分段后能接上吗？换回完整句或新场景时，还需要哪一小段帮助？

A-010 · 核心版

I can see…｜数量与整句分开搭桥

固定 I can see，再连接熟悉名词和数量；会背数列，不代表会点数或会说数量短语。

阅读核心版 →详细版
就地展开重点

记住这 3 点

  • 数量任务分开看：口头数列、逐件点数、数量加名词分别观察；先用孩子能点清的小数量，不急着扩到大数。
  • 四个小任务可拆可连：当前数量 → 单数整句 → 数量名词短语 → 复数整句；按卡点练，不是每天固定升一级。can 后接动词原形，先固定 see。
  • 鼓励贯穿过程：开始前说明任务，过程中给帮助，表达时及时回应，结束时具体指出努力和进步；不只是泛泛夸“棒”。

怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频逐句原话或统一作业。

  1. 摆一到几件熟悉物体，让孩子指一件数一件；数量不清就先帮助点数。
  2. 先说 I can see a book.，再单练 one book / two books，成人示范正确单复数。
  3. 短语较顺后连成 I can see two books.；之后再分阶段加问句、换场景，不同时轮换许多动词。

one book → two books → I can see two books.（不是 three book。）

易错提醒

  • 不要只纠正词尾而忽略漏数、重复数；数字范围看实际能力，不按年龄硬设线。
  • banana / grape 都有单数，并非永远复数；问句和更大数字随后逐步扩展，没有统一达标天数。

只观察这一件事：孩子现在困难在点数、复数短语，还是接上 I can see？只增加当前够得着的一步。

A-011 · 核心版

I can see many things｜复数分组练，继续用

固定句首引入少量复数；分组练熟悉名词，也让复数继续出现在绘本、扩展和生活里。

阅读核心版 →详细版
就地展开重点

记住这 3 点

  • 本轮主要变名词：先保留 I can see，连接熟悉对象的复数；不是第一周把所有复数变化规则学完。
  • 两条线路一起走：熟悉名词分组练，不必按 s、es 规则逐组讲；绘本遇到新例子也可清楚传义、自然使用。
  • 成人先练会：核对词形，在固定句首里开口说顺，再换 They are 等表达；新句首与动词配合是另一项难度。

怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频逐句原话或统一作业。

  1. 选几种已经认识的物体，确认有多个；短语难就先练 books / two books，不急着连长句。
  2. 接到 I can see two books.，按需要给句首；较顺后加 many、换熟悉对象，不同时全变新。
  3. 绘本里看到多个对象时再用，成人可以加清楚的动作或音效；跟着说过，不算以后都能独立调用。

I can see a book. → I can see two books. → I can see many books.。

易错提醒

  • many 接可数名词复数；通常表示饮料的 juice 不说 many juice，可用 a lot of juice。
  • 知道规则不等于能即时组织；“一秒”“第一周”等说法不作统一考核，也不能用简便记忆法推导所有词。

只观察这一件事：卡住的是词形、数量短语，还是接上句首？固定其他部分，只补这一小段。

A-012 · 核心版

It’s my…｜所属看说话人，代词分轮练

用归属清楚的熟悉物品练 my / your；先短语后整句，其他所属代词按实际需要回来练。

阅读核心版 →详细版
就地展开重点

记住这 3 点

  • my / your 跟说话人变：成人问孩子的东西可用 your，孩子说自己的东西用 my；不是固定给两堆物品贴标签。
  • 意思先清楚：用双方真实物品或已分配的卡片，让归属看得见；名词尽量熟悉，不让新物体名称挡住主目标。
  • 代词不是一张表一次学完：先 my / your，his / her 等可先在场景里输入，较熟后再回访同一句型单独练。

怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频逐句原话或统一作业。

  1. 选双方归属明确的熟悉物品，成人指着示范 my hat / your hat，先固定角色。
  2. my hat 较顺后连 It’s my hat.；接不上就给句首或一起说，不同时索取整套长问答。
  3. 意思清楚后核实 Is it your hat?，逐渐换物品和角色；随后在生活里再用，不照抄别人的进度。

妈妈指孩子的帽子：Is it your hat?；孩子：It’s my hat.。

易错提醒

  • my、your 后接名词；mine、名词加 ’s 和全部所属代词，不在本轮一口气独立掌握。
  • 趣味不等于真的抢孩子物品；先说顺再考虑提速，没有“几遍就必须会”的统一期限。

只观察这一件事：孩子卡在 my 加名词、整句连接，还是谁在说？先补实际卡点。

A-013 · 核心版

She is…｜身份说清楚，新词接回旧句

先解决“他／她是谁”，再让 he / she 与 who 接回适合的旧表达；串联不是机械换词。

阅读核心版 →详细版
就地展开重点

记住这 3 点

  • 第一次先做身份：选熟悉人物、家人照片或明确角色，清楚指向后示范 She is… / He is…，不同时练全部功能。
  • 新词要回到旧句：身份较顺后，可选熟悉的 my、can see 或否定做连接；只选语义合适、孩子接得住的形式。
  • 用已知解释未知：不懂人物就换熟悉对象，指代不清就明示，句子难就给短段；能配对不等于已能组织整句。

怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频逐句原话或统一作业。

  1. 指着已明确称呼的熟悉人物，示范 Who is she? — She is my mom.，让对象与表达对上。
  2. 需要时成人给 She is，孩子接 my mom；换另一个熟悉人物，观察而非要求先背代词表。
  3. 选一条较熟旧句，如 He can see a ball.，用清楚角色情境再练；卡住就回到身份，不全变新。

She is my mom.；已有 can see 基础后：He can see a ball.。

易错提醒

  • 不要凭长短头发、衣着猜代词，不把直播里的年龄例子当发展标准。
  • 不能把每个 it 自动换成 he / she；职业、位置、进行时等是后续空间，不是首轮必修。

只观察这一件事：指向明确时，新代词能否接上一个熟悉句段？陌生的是人物、指代还是后半句？

A-014 · 核心版

It isn’t mine｜先所属，再分轮加变化

用已知 my / your 加物品搭桥，先弄清 mine / yours，再连接肯定、否定、问答与名词替换。

阅读核心版 →详细版
就地展开重点

记住这 3 点

  • 所属跟说话人看：mine 是说话人的，yours 是对方的；用清楚实物和多次对应示范，不只背中文标签。
  • 形式要分清：my hat 与对象明确时的 mine 可说同一归属，但不说 mine hat；成人也要读清 mine 末尾的 n。
  • 五个任务分层做：所属意思、两种形式的联系、肯定否定、名词替换、问答；先小段再整句，不一次并行考。

怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频逐句原话或统一作业。

  1. 复习 my hat / your hat，成人对应示范 It’s mine. / It’s yours.；先固定角色和所指物。
  2. 做 Yours or mine? 的短回应，较顺后给句首连 It’s mine.；需要时回到指认和模型。
  3. 随后分轮试 It isn’t mine.、Is it yours? 或 The hat is mine.，在生活里复用，不同时加入复数等新难度。

It’s my hat. → It’s mine.；不是我的：It isn’t mine.。

易错提醒

  • 单独问句与否定句要逐步练；暂不叠加 Isn’t it yours? 这类否定问句，不等于取消问答。
  • 孩子只说 No 或 Yours 可能交流正确；承接意思再示范目标句，不用羞辱或连续逼问。

只观察这一件事：卡点在所属与视角、my / mine 形式，还是整句连接？一次只支持一处。

A-015 · 核心版

My mom’s…｜分三路连接，一次变一项

所属短语分别连接单数、不可数和复数句；用一个变量搭一个场景，别同时换所有东西。

阅读核心版 →详细版
就地展开重点

记住这 3 点

  • 三种材料分层：my mom’s hat、my mom’s juice、my mom’s glasses；先熟悉单个物体，其他方向逐步加入。
  • 复数不只改名词：I can see 后改复数，句首不变；这里 They are 还要配合多个对象，可先固定开头练顺。
  • 变量就是场景：所有者、物品、数量、是或不是、核实问句，都可成为变化；每轮只加一个主要陌生点。

怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频逐句原话或统一作业。

  1. 先用归属清楚的熟悉物体，my mom’s hat → It’s my mom’s hat.；卡住就先练短语。
  2. 换熟悉所有者或物品，先不同时换两项；遇到饮料可正确示范 It’s my mom’s juice.。
  3. 之后单独练多个物体或眼镜，固定 They are，连接 They are my mom’s glasses.；较顺再加否定或问答。

It’s my mom’s hat. / It’s my mom’s juice. / They are my mom’s glasses.。

易错提醒

  • 不说 a my mom’s hat，也不因东西“数不完”就当不可数；成人先核对具体用法。
  • 成年人的分类与大量练习不是孩子同日作业；实战卡住要看卡点，不只一味增加重复量或强求速度。

只观察这一件事：卡住的是所属短语，还是单复数与句首配合？固定其余变量，只补这一段。

A-016 · 核心版

There is…｜第一个“硬骨头”分层搭阶梯

There be 同时叠加语序、be、名词、介词和长度；先拆短、固定变量，再长期串联。

阅读核心版 →详细版
就地展开重点

记住这 3 点

  • 先分清“拥有”与“存在”：I have 处理拥有，There is/are 处理某处存在。
  • 第一轮先守住 There is/are；过去、将来时与就近原则先由成人理解，不急着让孩子全套输出。
  • 省能量也重要：卡片、身体位置、声音和固定回应流程可复用；按孩子反应找适合的模式，不天天购买新道具。

怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频逐句原话或统一作业。

  1. 生活或绘本先预热“哪里有”，成人先自己拆句。
  2. 先固定 There is a… 加熟悉名词；另轮用实物练 in/on/under 短语，不同时加入复数和全部地点。
  3. 两段较顺后连起来，接着另轮做 There are、数量与换地点；绘本和生活再调取，不只重复一句。

There is a robot in the box. / There are two books on the table.

易错提醒

  • 不要把中文“有”全翻成 have，也不要一次讲完所有时态和介词。
  • 视频中的长期时间说法不是统一达标年限；偶尔出错不等于完全没学会。

只观察这一件事：卡在 There is、单复数、介词、地点名词，还是句子太长？一次只支持一处。

A-017 · 核心版

What's in the sea?｜介词连接名词，接回旧模型

介词像连接名词的胶水；固定 in 后，把地点和新词串回 There be、问答及简单句模型。

阅读核心版 →详细版
就地展开重点

记住这 3 点

  • 介词常接名词性成分；“胶水”是理解入口，and 也可接词或短语，不能把课堂简化当无例外定义。
  • 介词关系用容器、图片和真实位置传递，不只背“in=在里面”。
  • 自己加工才是主线：读完合上笔记，用新地点自己组两句；知道别人的模型不等于自己能开口迁移。

怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频逐句原话或统一作业。

  1. 用盒子和几张熟悉卡片体验 in：固定 in the box 换物品，不急着同时考问句和复数。
  2. 较顺后固定物品换容器；在绘本遇到 zoo 等地点，把它接回 There’s / I can see，而不只报新词。
  3. 成人用谁—做什么—地点等模型练替换，不把顺序当所有英文句子的唯一公式；孩子只加接得住的一步。

There's a hamburger in the basin. / Can you see a robot in the zoo?

易错提醒

  • in 后的动作常用 -ing；like to read 的 to 是不定式标记，不是所有介词都能接 to do。
  • 看过讲义不等于会迁移，固定变量后再替换。

只观察这一件事：卡在空间关系、名词词汇，还是旧句型连接？

A-018 · 核心版

What's on the grass?｜on、否定与“会”的层级

先分层练 on 和 There isn’t，再用间隔回收提升从刻意练习到新场景调用的层级。

阅读核心版 →详细版
就地展开重点

记住这 3 点

  • 本讲从 in 换到 on，并加入不存在的否定；三层变化不要同轮全压。
  • 会不是固定次数：能指认、能套句型、能迁移到绘本和讨论，是不同层级。
  • 成人可借 -ing 理解名词性用途与修饰语，再用卡片扩展动作；孩子本轮不需要词性分析。

怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频逐句原话或统一作业。

  1. 固定 on 的真实位置，再替换熟悉物品。
  2. 较顺后用 There is / There isn’t 做有/没有对照；若 on 仍陌生，可暂用已熟 in，别把两项新难度一起考。
  3. 在新地点、绘本和生活中间隔调取，再加熟悉颜色或动作；只会在原游戏回答，不登记为已全掌握。

There's a book on the table. / There isn't a robot on my arm.

易错提醒

  • 不以“三遍”“一周”等数字承诺掌握；不把高级 doing 分析变成孩子入场考试。
  • 名词卡是思维提示，不必一次要求所有词性变化。

只观察这一件事：卡在 on、否定、长句气息，还是成人语法理解？

A-019 · 核心版

I can't see…｜冠词与名词形式的综合场景

固定 I can’t see，再分层加入冠词、复数、代词和修饰语；冠词在多个场景中逐步稳定。

阅读核心版 →详细版
就地展开重点

记住这 3 点

  • 先从 a/an、the、零冠词的当前实例理解；a/an 看起始发音，不看字母，the 需有清楚指向。
  • 成人先核对手头名词并想清意思；a fox、the fox、foxes 不只是形式不同，指向也不同。
  • 冠词、代词、复数不是一讲解决，而是在不同句型中反复回收。

怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频逐句原话或统一作业。

  1. 先用清楚对象练 I can’t see a…，让否定意义成立。
  2. 成人输入可更丰富，孩子本轮只固定一个场景；随后换到双方已知的 the，再另轮加复数。
  3. 较顺后接 my watch、on the bed 等已知修饰；需要表示“一个也看不见”时可示范 any，不同时全扩。

I can't see a fox. / I can't see the sun. / I can't see foxes.

易错提醒

  • 通常否定用 any；特殊语境的 some 含义不同。定语从句、不可数或地名等也不能套绝对冠词规则。
  • 看不见不等于不存在；物体可能只是被遮住。句首短，也不等于后面的名词形式简单。

阅读核心版 →详细版
