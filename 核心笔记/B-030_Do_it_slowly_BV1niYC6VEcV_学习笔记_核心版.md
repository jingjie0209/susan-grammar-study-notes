# B-030｜Do it slowly!｜把 slowly 织入网络｜核心版

> slowly 与 fast 形成速度对比；若负担大就拆开练。重点是用一个副词重新调取已有名词、动词和句型。

## 记住这 3 点

- slowly 修饰动作；slow 可修饰名词，如 a slow turtle，slowly 可说 The turtle walks slowly。
- 副词新增后若整句混乱，先固定 Do it 或让孩子用动作选择，不急着加新词。
- 旧内容占主导，新内容少量加入；连接密度比词汇配额更重要。

## 怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频原话或统一作业。

1. 先演示 Do it slowly，孩子可只接 slowly 或模仿慢动作。
2. 在 open、walk、eat 等熟悉动作中迁移。
3. 愿意时加入问句、really 或 slowest 等可选扩展。

Do it slowly! / Dad eats slowly. / Now I know how to waddle.

## 易错提醒

- slowest 涉及比较关系，不是 slowly 的必然下一关。
- 不要只让成人连续表演；让孩子选择、尝试并真实来回。

**只观察这一件事：**副词加入后，孩子能否保留已有动作和对象意义？
