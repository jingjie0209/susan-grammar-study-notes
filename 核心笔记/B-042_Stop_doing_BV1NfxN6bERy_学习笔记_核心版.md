# B-042｜Stop doing｜制止与语气选择｜核心版

> Stop doing 表示停止正在做的事情，语气通常直接；亲子中要按危险和场景选择强烈或礼貌表达，并区分 stop doing 与 stop to do。

## 记住这 3 点

- stop doing 中 doing 是 stop 的宾语；stop to do 是停下原事去做另一件事。
- Stop doing 语气强，适合明确的即时制止或安全边界。
- Would you mind not doing…? 更礼貌，但功能仍是要求停止。

## 怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频原话或统一作业。

1. 先用玩具动作示范 Stop。
2. 加正在发生的动作：Stop jumping on the sofa.
3. 用 keep/stop 反差让孩子理解继续与停止。

Stop running. / Would you mind not shouting here?

## 易错提醒

- 不要把普通偏好升级为呵斥。
- dding 在此是宾语，不是进行时；逻辑主语表达属于后续拓展。

**只观察这一件事：**孩子是否把 stop 与当前动作对应，而不仅仅对成人音量作反应？
