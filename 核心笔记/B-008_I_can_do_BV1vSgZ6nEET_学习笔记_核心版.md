# B-008｜I can do｜抓住 can 加原形，按反应减变量｜核心版

> 先用熟悉动作说 I can…，让 can 加动词原形与“能做”对应。可组合很多句，不代表一轮要清空卡池；卡住就减少量、去对象或固定对象。

## 记住这 3 点

- I can clap. / I can draw.；can 后不加 to、-ing 或第三人称 -s。do 是模型占位，不是每句都要另加 do。
- 能力、许可和请求看情境；先做一种清楚用途，需要时再对比。会 I can see 不代表新动词都能自动接上。
- 新的是句型时用熟悉词；框架熟了再引入一个能理解的新词。宾语等细节另加，不把连续出错当成必须再多练的理由。

## 怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频原话或统一作业。

1. 成人拍手示范 I can clap.，邀请孩子一起；Can you clap? 可先用动作或 Yes 回应。
2. 需要时给 I can…，孩子只接 clap；较顺再换另一个熟悉动作，不抢答。
3. 想加对象才示范 I can draw a cat.；若对象成负担就退回 I can draw.，或另轮固定 a cat。

I can clap. → I can draw. → I can draw a cat.。最后一步是可选细节，不是每个动词都能任意删掉必需成分。

## 易错提醒

- 成人可先输入 I can’t fly. 作对比，不要求孩子马上输出否定；先听懂与主动使用是不同信号。
- 飞行故事用桌面玩偶，不跳高摔倒；不规定一百句或奖励后撤年龄，不把动作能解释一切当定律。

**只观察这一件事：**换一个熟悉动作后，孩子能否理解并接用 I can…？若更难，能否退到句首提示或无对象短句？
