B-010｜An elephant can’t do｜固定一项，再试双卡组合

第三人称单数也用 can’t 加动词原形，不加 -s；冠词、名称与句长仍可能增加负担。先固定一项，再试少量双卡，because 与拟人故事只作可选分支。

记住这 3 点

  • An elephant can’t fly. / It can’t fly.；不是 can’t flies，也不说 doesn’t can。a／an 按起始发音选，成人可先给整块主语。
  • 双卡要求同时处理名词和动作；困难时固定主语或动词。新词先理解再入句，不把所有变化一次交给孩子。
  • 先认真听意思，再自然重述并留表演时间。不以卡片数或一秒正确作标准；原因可先用独立短句。

怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频逐句原话或统一作业。

  1. 指清玩具象，示范 It can’t fly.；需要时给 It can’t…，孩子接 fly，再试名称主语。
  2. 较顺后固定 fly 换一个熟悉单数主语；或另轮固定一个人物换动作，只选一路。
  3. 愿意时双卡抽到普通伞＋run：An umbrella can’t run.。想说理由先给 It has no legs.，连接 because 可稍后。

An umbrella can’t run. It has no legs. → An umbrella can’t run because it has no legs.。两句分说有效，不必每次合并。

易错提醒

  • 真实物品与想象设定分清；孩子简短答 No legs. 也能传意，成人补完整，不借体型、颜色嘲笑真人。
  • 成人拓展需校核：can be 不等于百分百，may／might／could 无统一固定百分比；be able to、推测表不是儿童必背阶梯。

只观察这一件事：换一个熟悉单数主语后，孩子还能接用 can’t 加原形吗？卡住先固定主语，而不是再加 because。
