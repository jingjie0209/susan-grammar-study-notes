# B-021｜I like doing｜喜欢某个活动｜核心版

> 把 doing 当作“喜欢的事情”来用。先固定 I like 与熟悉动作，再少量补对象；动名词术语和 -ing 的其他功能留给成人理解。

## 记住这 3 点

- I like swimming. 中 swimming 是动名词，表示活动；不要把所有 -ing 都当成现在进行时。
- like 后可接单独活动，也可带对象或其他成分；先以孩子能理解的动作和场景为主。
- 真实喜欢与不喜欢都可表达，短答、指图和拒绝都能传递意思，不把 like doing 练成唯一答案。

## 怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频原话或统一作业。

1. 固定 I like，孩子接 drawing／singing。
2. 顺后只换一个熟悉动作，再加一个熟悉对象。
3. 在生活或绘本里问 What do you like doing?，成人可补完整句。

I like drawing. / I like reading books.

## 易错提醒

- 不要把 like doing 说成 like 后唯一合法结构；like to do 另有使用场景。
- 不要同时随机主语、态度、动作、对象和冠词。

**只观察这一件事：**固定 I like 后，孩子能否把熟悉动作作为“喜欢的事”接出来？
