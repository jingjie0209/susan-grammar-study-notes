# A-044｜I can hear｜先闻其声，先练常用｜核心版

> 先给声音线索，再让孩子寻找并报告听到什么；成人遇到多种结构，先选常用的练清、解释语境，随即放回游戏和绘本。

## 记住这 3 点

- 固定 hear 后可换名词、复数、宾格代词与 something；形容词可放在 something 后。
- heard somebody do 常看事件整体，doing 强调过程；can hear 后描写当前动作优先用 doing，不按秒数机械区分。
- 成人的名词化表达是后续丰富，不是零基础一次掌握四种形式的要求。

## 怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频原话或统一作业。

1. 翻页先模仿一声，让孩子猜来源，再说 I can hear a cat 等基础句。
2. 成人只挑自己当前不稳的一对结构，用同一动词造句并补语境，慢慢解释区别。
3. 基础已顺再加 meowing 等过程表达，当周绘本立即用；孩子任务按反应缩小。

I can hear something loud. / I can hear the cat meowing.（补充例）

## 易错提醒

- 不要把所有用法、近义词和罕见表达一网打尽，也不把课堂年数当统一进度。
- 看图假装听到角色是想象游戏；保持舒适音量，不作听力测验或诊断。

**只观察这一件事：**换了声音来源以后，孩子能否回应；成人能否用清楚的语境解释自己选的形式？
