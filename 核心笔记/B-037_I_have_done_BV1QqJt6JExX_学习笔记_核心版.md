# B-037｜I have done｜现在完成时入门｜核心版

> 站在现在回头总结截至现在已经完成、发生过、持续多久或是否有过某种经历；先理清截止点，再处理过去分词、have／has和时间短语。

## 记住这 3 点

- 现在完成时的核心是“到现在”的观察点，不是动作一定正在现在发生。
- 基本结构是have／has + 过去分词；五个坑包括是否该用、过去分词、have／has、时间短语和瞬时动作转持续状态。
- 完成时开始后，过去式继续在日常、绘本、故事和跨句型练习里循环；成人先理解，孩子先做场景输入。

## 怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频原话或统一作业。

1. 先用I have done it／I have already done it建立“到现在已经完成”的场景。
2. 再加入before、never、since、for等高频时间意义，一次只改变一个变量。
3. 把过去事件、现在结果和持续状态串联起来，逐步做随机组句。

I have already done it. / I have never done it before.

## 易错提醒

- 明确的过去时间点和现在完成时不要机械拼成固定句；先判断截止点。
- 不要把偶尔说中一句当成稳定掌握，也不要把语法说明原样讲给孩子。

**只观察这一件事：**孩子能否在场景中理解“到现在已经完成／有过经历”，并在不增加太多变量时保留意义？
