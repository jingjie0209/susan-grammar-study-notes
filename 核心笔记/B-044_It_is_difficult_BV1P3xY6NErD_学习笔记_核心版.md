# B-044｜It is difficult｜评价、角色与理由｜核心版

> Doing something is difficult 可评价事情本身；同一活动对不同角色可能难易不同。该句型可继续连接原因、能力、经历和观点讨论。

## 记住这 3 点

- doing 主语适合客观或概括的评价。
- for me / for a monkey 等视角能解释角色差异。
- 评价句可接 because、can、have done 等旧结构。

## 怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频原话或统一作业。

1. 先比较两个明显不同难度的活动。
2. 把同一活动放到不同角色身上。
3. 成人补理由，孩子先给关键词或因果的一部分。
4. 把“同一活动对不同角色不同”作为观察点，再成人补 because 理由。

Climbing a tree is difficult. / It’s easy for a monkey.

## 易错提醒

- 不要用 It’s easy 否定孩子的真实困难。
- 难易是条件和经验，不是对人的能力标签。

**只观察这一件事：**孩子能否理解同一活动对不同角色可能有不同评价？
