# B-036｜The robot didn’t do it yesterday｜过去式收束｜核心版

> 用第三人称否定把过去式的时间、否定、规则／不规则、人称和内容包串联起来；真正会是能继续谈现在与未来。

## 记住这 3 点

- didn’t标记过去，do保持原形；第三人称不再另加三单。
- 四个方向可作成人地图：I did／I didn’t／robot did／robot didn’t。
- 过去事件可以继续讨论地点、工具、感受、现在状态和下一次安排。

## 怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频原话或统一作业。

1. 用机器人演示没有完成的过去事件。
2. 逐步换常用动词、时间和对象。
3. 从过去回到现在感受和未来安全计划。
