B-023｜Dad likes doing｜第三人称 likes doing

主语换成 Dad 后，likes 出现三单标记；先固定 Dad likes，再接熟悉 doing，控制其他变量。

记住这 3 点

  • I like cooking 与 Dad likes cooking 对比主语和动词形式；can 或 like 后的 doing 不因此改变。
  • B 阶段重点是新结构和旧内容串联，不要把三单一次口误当成唯一验收指标。
  • 冠词、数量、代词等旧变量已稳定时再少量带入，不稳就先固定名词短语。

怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频逐句原话或统一作业。

  1. 固定 Dad likes，孩子接 cooking。
  2. 只换一个熟悉活动，之后再加一个熟悉对象。
  3. 与 I like doing、绘本和生活内容横向串联。

Dad likes cooking. / Dad likes cooking dinner.

易错提醒

  • 不要同时换主语、动词、宾语、数量和修饰语。
  • 不要为了纠正 likes 打断每一次有意义的交流。

只观察这一件事：主语换成 Dad 后，孩子能否保留 likes doing 的整体？
