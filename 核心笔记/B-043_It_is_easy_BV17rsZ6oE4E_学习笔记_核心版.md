# B-043｜It is easy｜动名词作主语｜核心版

> Doing something is easy 把“做某件事”整体当作主语进行评价；一个动名词作主语通常用单数谓语，doing 还能继续带宾语。

## 记住这 3 点

- 动名词把一个动作抽象成可谈论的“事情”。
- 单一 doing 主语常用 is；并列两个活动才可能用 are。
- Doing is easy 与 It’s easy for me to do 侧重不同。

## 怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频原话或统一作业。

1. 先固定评价词，只换熟悉活动。
2. 给 doing 加一个熟悉的宾语。
3. 用不同角色评价同一活动，形成简单对比。

Reading is easy. / Reading this book is easy for you.

## 易错提醒

- 不要把活动评价理解成对具体物品的形容。
- 不要把所有 it is easy to do 与 doing is easy 当作完全同义。

**只观察这一件事：**孩子能否把 easy/difficult 指向活动本身？
