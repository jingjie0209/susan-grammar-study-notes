# A-037｜I want to eat｜固定动词再逐步加一｜核心版

> 把 I want to eat 当作阶梯：先稳定 want to eat，再换宾语、加一个属性或原因，用持续输出提高组织速度。

## 记住这 3 点

- want to eat 同时处理两个动词，对中文学习者跨度较大。
- 换动词会连带宾语、冠词、单复数和搭配，不能算只加一个变量。
- 准确率要在有意义的长期输出中逐渐稳定。

## 怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频原话或统一作业。

1. 先固定 eat，只换熟悉食物或安全假想对象。
2. 再加一个形容词、数量或 because 原因。
3. 顺了以后再换动词，保持内容在孩子能理解的范围。

I want to eat a big hamburger. / I want to eat a desk because it is made of chocolate.

## 易错提醒

- 不要把 want 学会等同于 want to do 已经自动化。
- 不要同时堆陌生话题和多个新动词。

**只观察这一件事：**换了宾语后，孩子还能否保持 I want to eat 的整体反应？
