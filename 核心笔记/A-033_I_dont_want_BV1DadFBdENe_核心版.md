# A-033｜I don’t want｜否定、五感与具体理由｜核心版

> 用肯定与否定的强烈对比传递 don’t want，再用动作和五感把“不想要的理由”做出来；从已知句型出发，每次只加一点。

## 记住这 3 点

- I don’t want 可以借助 I don’t have / I don’t like 的旧模型；先让 want 与 don’t want 在同一场景中对照。
- 不要只说 inconvenient 等抽象词：用太重、看不清、找不到、太酸等可见可做的体验承载原因。
- why not 后可用选择、角色扮演和购物游戏继续展开；综合使用中的 don’t / doesn’t、三单和单复数混用是正常观察点。

## 怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频原话或统一作业。

1. 拿一个想要物和一个明确不要物，示范 I want it / I don’t want it。
2. 用安全动作演示一个原因，再说 I don’t want the… because…；没词就给两项选择。
3. 把否定放进购物或绘本，调用 it is、has、likes、there is 等已知句型扩展。

I don’t want the glasses because they are not convenient.；There is a stain on it.

## 易错提醒

- 不把孩子一次说错当成考试失败；先接住意义，再给正确模型。
- 五感演示用安全玩具和假动作，不踩坏眼镜、闭眼走动；角色故事不意味着需要矫正视力的人可不戴眼镜。

**只观察这一件事：**孩子能否在明确对象上表达不要？若能，下一卡点是原因、句型连接还是助动词变形？
