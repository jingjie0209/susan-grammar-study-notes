# B-013｜I want to do｜把 want to 接稳｜核心版

> 从想要物品走向想做一件事，先固定 I want to，再接熟悉动作原形。漏 to 时托住连接，不把成人的非谓语术语表交给孩子。

## 记住这 3 点

- I want an apple. 是要苹果；I want to eat an apple. 是想吃。want 后不是永远加 to，想接动作时本轮用 want to 加原形。
- do 是结构占位，不额外说 want to do draw。先用 draw／sing 等可独立使用的熟悉动作，需要宾语时固定一项。
- to do 不总表示将来，-ing 不总表示正在进行；具体搭配不能只靠“目的、持续”判断。先把 want to 模型用明白。

## 怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频原话或统一作业。

1. 玩偶拿画笔示范 I want to draw.；孩子可先接 draw，成人把 I want to… 整块给到。
2. 较顺后保持句首，只换一个熟悉动作；孩子真的不想做时不要求按抽卡答案表达意愿。
3. 有需要再加一个熟悉对象，如 draw a cat；在绘本中问 Do you want to draw?，愿意就画，不愿意也接受。

Do you want to draw? — Yes. / I want to draw.；不用每次都完整答，也不要求接 because。

## 易错提醒

- 自然重述 want to 后就继续交流；不连续要求“再说一遍”，不以几天、几张卡验收新模型。
- would like to、feel like doing 可自然输入，但不是本轮必背同义表；hope／wish 也没有固定实现概率。

**只观察这一件事：**换一个已知动作后，还能接 want to 加原形吗？意思清楚但句长难，就给句首接词。
