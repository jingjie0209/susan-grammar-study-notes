# B-017｜The monkey does it every day｜动作一换，三单也要跟着变｜核心版

> 先固定玩具角色和 every day，再少量换熟悉动作。陈述句练动词的三单形式，问句与否定另轮再做，不同时增加新时间词与长细节。

## 记住这 3 点

- The monkey runs every day.，不是 does runs。标题 does it 只有 do 本身表示“做”时保留，不在每个动作前再加 does。
- runs／washes／goes 有不同形式，先少量示范，不首轮混考所有变化。every day 与 always 的词序、意思也不能机械互换。
- Does the monkey run…? / The monkey doesn’t run…；does／doesn’t 后用 run 原形。肯定顺不等于四种变形一次都得说。

## 怎么练 · 3 步

以下为整理者补充练法与规范化例句，不是视频原话或统一作业。

1. 给玩具猴一个故事日程，示范 The monkey runs every day.；成人给句首，孩子接 runs，指卡也可参与。
2. 较顺只换 jumps；或另轮固定 runs 换一个熟悉单数角色。不同时换主语和陌生动词。
3. 孩子愿意时只加一个幻想地点，如 on the clouds；问句另轮让玩偶来问，先听懂与短答，再试发问。

Does the monkey run every day? — Yes, it does.；The monkey runs every day.，答句不把 runs 带回 does 后。

## 易错提醒

- 幽默用虚构角色或经同意的温和自嘲，不拿孩子、同学或家人贴“坏人”标签；不喜欢就换设定。
- 不实演吐口水、倒立、边吃边跑或摔倒。书上一次动作不等于日常习惯，事实与幻想分开。

**只观察这一件事：**只换一个熟悉动作后，还能在单数角色句中逐渐保留动词变化吗？先完整示范，不盘问尾音。
