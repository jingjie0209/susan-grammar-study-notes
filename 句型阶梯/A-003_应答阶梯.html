A-003 · 应答阶梯

That is…｜远处指向清楚，旧句型继续循环

在双方都看得清的远处指认情境中使用 that，不把距离或句型顺序变成死规则。

阶梯为整理者编排，不是原课固定六级表；按使用信号选层，不按年龄或天数硬分，不要求每次走完。示例和引导话术含补充内容，非逐字引语。

多种问法与引导语

同一句型，不同问法可能在做不同的事。先选孩子听得懂的一种；以下应答是场景示例，不是唯一标准答案。

  1. 开放提问表格问法·规范示例 · 原页已有引导

    What's that?

    可以这样回应That is a rabbit.

    与孩子站在同一侧，指清远处的兔子；不是只考 that 的声音。

  2. 动作／表达邀请原页引导·补充应答

    Tell Teddy what that is.

    可以这样回应That is a boat.

    请孩子告诉玩偶远处那个是什么。

  3. 判断核实原页引导·补充应答

    Is that a rabbit?

    可以这样回应Yes, it is. / No, it isn’t.

    指向明确后，再核实是不是兔子。

原问法：What's that?

原页三种引导及使用提醒

  • What’s that? — 与孩子站在同一侧，指清远处目标。
  • Tell Teddy what that is. — 请孩子告诉玩偶远处那个是什么。
  • Is that a rabbit? — 指向明确后，再核实是不是兔子。

起步先把目标指清，再引导表达；核实问句放在陈述较熟之后。What’s that? 用 It’s a rabbit. 回答也可以，不因没用 that 就判语法错误。

游戏详细说明 补充设计

每层对应一个可直接玩的活动。先按使用信号选择当前能参与的一层，不要求六个游戏连续完成；可选层不作为必过关卡。

以下游戏为整理者依据本讲阶梯和已校核笔记原则设计的家庭补充活动，游戏名称、道具与对话不是原视频逐字记录，也不是老师规定的固定教案。

共同准备：用清楚的兔子玩具、球或图片。成人与孩子站在同一侧，远处对象要看得清；不规定固定米数，不用攀爬或追跑取物。

基础游戏1 · 同看远处的朋友

这一层练什么：在共同视线中找到成人指的远处对象。

道具：一只熟悉的兔子玩具，摆在稳固、双方看得清的位置。

怎么玩

  1. 成人与孩子站在同一侧，指向兔子并示范 That is a rabbit.。
  2. 保持指向，问 What’s that?；孩子可以先指兔子或说 rabbit。
  3. 成人确认 That is a rabbit.；这一轮只观察指认，不需要孩子跑去拿。

亲子口语

成人（指向兔子）
That is a rabbit.
成人
What’s that?
孩子
Rabbit.（或先指认）

卡住时怎么接：如果孩子看向别处，就减少背景杂物、重新站到同一侧，先说清指哪个，不继续堆问句。

只观察一件事：能否与成人看向同一远处目标？

进阶一游戏2 · 远处介绍接半句

这一层练什么：把清楚的远处对象接进 That is a… 的句首。

道具：一只兔子玩具、一个玩偶听众。

怎么玩

  1. 先完整示范给玩偶听：That is a rabbit.。
  2. 仍指同一远处兔子，成人说 That is a…，孩子接 rabbit。
  3. 成人补完整句；愿意时请孩子用手势也指给玩偶看，不急着换词。

亲子口语

成人
That is a…
孩子
Rabbit.
成人
That is a rabbit.

卡住时怎么接：先确认孩子知道所指，再给词或一起说整句；不要把指向不明误当成不会 that。

只观察一件事：有指向和句首支架，能否把名词接上？

进阶二游戏3 · 远处目标换一换

这一层练什么：保持远指情境，随机替换熟悉名词。

道具：熟悉的兔子玩具和球，放在两个清楚可见的位置。

怎么玩

  1. 每次只突出一个远处目标，指兔子问 What’s that?。
  2. 孩子愿意时说 That is a rabbit.；再指球，仍从双方同一视线出发。
  3. 改变指向顺序，不让孩子背“兔子后面一定是球”；暂不加入颜色或新词。

亲子口语

成人（指兔子）
What’s that?
孩子
That is a rabbit.
孩子（改指球后）
That is a ball.

卡住时怎么接：词换了卡住，先给 That is a…；只有两个对象也混乱时，暂留一个。

只观察一件事：是否跟随当前指向选择名词，而不是沿用上一个答案？

进阶三游戏4 · 近处远处分轮介绍

这一层练什么：先分别复习 this 与 that，再在指向清楚时整合选择。

道具：一个近处球和一只较远、看得清的兔子玩具。

怎么玩

  1. 先一轮只介绍手边的球，成人示范 This is a ball.；之后另轮只介绍远处兔子。
  2. 两轮都较稳时，保持说话位置清楚，分别指近球和远兔，示范不同句首。
  3. 邀请孩子按所指对象选择介绍；不快速交替出题，也不把距离当绝对规则。

亲子口语

成人（手边球）
This is a ball.
成人（远处兔子）
That is a rabbit.
孩子（愿意时介绍远处目标）
That is a rabbit.

卡住时怎么接：this 和 that 混乱就退回分轮，站位不清就重排物品；It’s a rabbit. 的意思先接住，再补目标模型。

只观察一件事：清楚的说话位置与指向能否帮助选择，而不是机械轮流说两个句首？

进阶四游戏5 · 远处小确认

这一层练什么：对已明确的远处目标进行“是不是”的核实。

道具：兔子和球，成人能清楚指到其中一个。

怎么玩

  1. 先指兔子，成人自问自答 Is that a rabbit? — Yes, it is.。
  2. 再邀请孩子回答，先说 Yes 即可；不需要强行重复陈述句。
  3. 理解问法且否定已有基础时，再指球问同一问题；成人可承接 No 并补完整回答。

亲子口语

成人（指兔子）
Is that a rabbit?
孩子
Yes.
成人
Yes, it is.
成人（指球，后续）
Is that a rabbit?
孩子
No.

卡住时怎么接：若孩子只跟着说 rabbit，先重演一轮问答或暂回陈述；问法听不懂不是名词不会。

只观察一件事：能否对所指目标作肯定或否定判断，而不是忽略成人指的是哪一个？

进阶五游戏6 · 孩子来指路

这一层练什么：在回答熟悉后，让孩子指清远处目标并尝试提问。

道具：两个熟悉、可清楚指认的远处玩具。

怎么玩

  1. 成人先指一个对象问 What’s that?，由玩偶回答，演清角色。
  2. 让孩子选择并指向一个远处对象；愿意时由孩子问，成人答。
  3. 孩子只指不问时，成人可替他问并回答；另次再尝试自主问句。

亲子口语

孩子（指球，愿意时）
What’s that?
成人
That is a ball.
成人（角色交换后指兔子）
What’s that?
孩子
That is a rabbit.

卡住时怎么接：孩子指向模糊时先用手势共同确认；可以玩偶代言，不要求问句、陈述和否定同时完成。

只观察一件事：孩子能否把自己想问的对象指清，并理解成人在回答自己的问题？

游戏使用边界

  • 本活动用双方看得清的远处指认帮助理解 that；that 不是在所有语境中都只表示物理距离。
  • What’s that? 回答 It’s a rabbit. 也正确。先练清楚的远指，再复习近指；目标不明先解决指向，不先纠正句型。
  • 接住指认、动作、单词或其他正确回应，不以说满目标句换取物品；不催答、罚重说或把得分与奖励设为参与条件。
  • 一次只改变一个主要难点；不按年龄、固定轮数、秒数或天数升级。孩子不愿意继续就收尾，下次按实际反应选层。

原课依据与回看时间见下方“来源与回看”；游戏名称、道具、步骤和对话由整理者补充，未增加未经核实的原视频时间点。

卡住时，怎么接

先减少到一个远处目标，成人与孩子站在同一侧。句子卡住给 That is a…，指向不明先解决指向，不急着纠正单词。

使用边界

  • 本课的“远”是相对当前说话人的情境关系，不设固定米数，也不表示 that 在所有英语用法里都只指物理距离。
  • 旧句型继续复习；偶尔卡住可提示，若每句同一处都不懂先补台阶。只指认，不攀爬追跑或用激光指眼睛。

只观察这一件事：远处目标换了，孩子仍知道在说哪个，并能用熟悉词组织表达吗？
