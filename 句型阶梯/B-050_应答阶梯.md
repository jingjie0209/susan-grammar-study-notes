# B-050｜Never does｜应答阶梯

> 用 never 描述频率为零的习惯，保持三单，并用多个细节支持主题；避免把一次行为概括为“从不”。

阶梯为整理者编排，不是原课固定六级表；按使用信号选层，不按年龄或天数硬分，不要求每次走完。示例和引导话术含补充内容，非逐字引语。

## 家长引导（三种，按阶段选用）

- **What does the robot never do?** — 角色设定和图片明确时问，可答动作。
- **Does it ever eat apples?** — 核实频率，可答 No, never.
- **What details prove it?** — 主题已给时问证据，孩子可指图或说关键词。

never 本身已否定，句中仍要保持三单；真实人物标签要谨慎。

## 应答进阶总表

| 层级 | 使用信号 | 核心任务 | 随机组句／互动示例 | 适合阶段 |
| --- | --- | --- | --- | --- |
| 基础 | 理解从不发生的习惯 | 摇头、指图或 No | 孩子看见机器人只充电，成人说 It never eats food. | 意义理解 |
| 进阶一 | 愿意接动词片段 | never + 熟悉动作 | 成人 It never… → 孩子 eats apples. | 句段接用 |
| 进阶二 | 能说否定频率句 | 主语 + never + 三单动词 | The robot never eats human food. | 整句表达 |
| 进阶三 | 能换角色或动作 | 保持三单换动词 | The bull never opens the gate. | 变量扩展·可选 |
| 进阶四 | 能与 always 对比 | always / sometimes / never | It always charges. It never eats. | 频率尺度·可选 |
| 进阶五 | 能用证据支持主题 | 主题 + 三个细节 | It doesn’t eat / drink / cook. | 篇章表达·可选 |

## 卡住时，怎么接

先用三张图理解频率；孩子说不清时只让他选 always/sometimes/never。

## 使用边界

- never 句不要再加 don’t/doesn’t。
- 避免用 never 给真实人物贴绝对、负面标签。

**只观察这一件事：**孩子能否理解 never 的否定频率，并用多个证据支持主题？
