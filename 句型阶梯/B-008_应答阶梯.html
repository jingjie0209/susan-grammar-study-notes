B-008 · 应答阶梯

I can do｜熟悉动作带can，去对象或固定对象

先用熟悉安全动作建立 I can 加原形。卡住就减变量；对象、许可与否定故事另选，不要求清空卡池。

阶梯为整理者编排，不是原课固定六级表；按使用信号选层，不按年龄或天数硬分，不要求每次走完。示例和引导话术含补充内容，非逐字引语。

家长引导（三种，按阶段选用）

  • Can you clap? — 能力情境，先接纳动作或 Yes，再按需要示范 Yes, I can.。
  • What can you do? — 愿意展示时问，可答 clap 或 I can clap.，不强求每次整句。
  • Can I draw here? — 成人指纸询问许可；孩子可答 Yes。角色与意义都变了，只作另轮分支。

能力问句、开放展示与许可请求不同，不套同一答案。第三问中I指成人，不让孩子机械照说I can。

应答进阶总表

先看使用信号，再选当前能参与的一层；问答拓展可以暂缓。
层级使用信号核心任务随机组句／互动示例适合阶段
基础认识动作，愿意参与把能做与动作对应成人示范 I can clap.，孩子可拍手或指图。能力动作理解
进阶一动作词熟悉，句首需支持成人给 I can，孩子接词成人：I can… → 孩子：clap；不用clapping。句段接用
进阶二能接词，愿意少提示完整说自己能做的动作I can clap. / I can draw.；先选可不带对象的动词。整句换词
进阶三无对象短句较顺，愿意展开只加一个熟悉对象I can draw a cat.；对象难就退回 I can draw.。对象分支·可选
进阶四能说清当前组合，想换一点固定对象再换熟悉动作玩具情境：I can draw a cat. / I can feed a cat.，不喂真动物。固定对象迁移·可选
进阶五理解模型，愿意另轮探索许可或玩偶正反故事选一路指纸：I can draw here.；或普通玩偶 I can’t fly.，不强求否定。情境分支·可选

卡住时，怎么接

先少做几句；可用walk／draw等可独立使用的动词，或固定一个对象。新词先演懂；I can…托句，不连续追错。

使用边界

  • can后用原形，do是占位；不能把所有动词必需成分都随意删掉。
  • 只用桌面玩偶演飞行，不跳高或摔倒；不按年龄、卡片数或奖励强制开口。

只观察这一件事：换一个熟悉动作后，孩子还能理解并接用 I can 吗？必要时能否退回更少变量？
