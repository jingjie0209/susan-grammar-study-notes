# B-044｜It is difficult｜应答阶梯

> 用 doing 主语表达难易，理解同一活动对不同角色可能不同，并逐步连接原因和能力。

阶梯为整理者编排，不是原课固定六级表；按使用信号选层，不按年龄或天数硬分，不要求每次走完。示例和引导话术含补充内容，非逐字引语。

## 家长引导（三种，按阶段选用）

- **Is climbing a tree difficult?** — 图片或动作清楚时问，可答 Yes/No。
- **Is it difficult for you?** — 孩子体验后追问视角，可答 for me。
- **Why is it difficult?** — 已有线索时问原因，可先答一个关键词。

先同一活动的难易对比，再引入 for me / for a monkey 等视角。

## 应答进阶总表

| 层级 | 使用信号 | 核心任务 | 随机组句／互动示例 | 适合阶段 |
| --- | --- | --- | --- | --- |
| 基础 | 体验或看见活动 | 做动作、指图或回答难/易 | 孩子爬软垫，成人说 Climbing is difficult. | 意义理解 |
| 进阶一 | 愿意接活动短语 | 说 doing + 对象 | 成人 … is difficult → 孩子 climbing a tree. | 句段接用 |
| 进阶二 | 能说评价句 | doing + is + difficult | Climbing a tree is difficult. | 整句表达 |
| 进阶三 | 能加入角色视角 | for me / for a monkey | It’s easy for a monkey. | 视角扩展·可选 |
| 进阶四 | 能对比角色观点 | 两角色评价同一活动 | Climbing is difficult for me, but easy for a monkey. | 对比表达·可选 |
| 进阶五 | 能补原因或经历 | because / can / have done | Because I can’t climb well. | 理由串联·可选 |

## 卡住时，怎么接

先让孩子做动作或用图，不要求抽象讨论；卡住只保留活动词 and difficult。

## 使用边界

- 不要用 It’s easy 否定孩子的真实困难。
- 难易是条件与经验，不是能力标签。

**只观察这一件事：**孩子能否理解同一活动对不同角色可能难易不同？
