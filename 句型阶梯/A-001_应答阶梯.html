A-001 · 应答阶梯

It’s a…｜从命名单词，到独立换词组句

看到熟悉的单个物品，能说清它是什么，而不是背卡片顺序。

阶梯为整理者编排，不是原课固定六级表；按使用信号选层，不按年龄或天数硬分，不要求每次走完。示例和引导话术含补充内容，非逐字引语。

家长引导（三种，按阶段选用）

  • What’s this? — 指着眼前物品，邀请命名。
  • What’s in the bag? — 拿出袋中的一个物品，看看是什么。
  • Tell Teddy what it is. — 请孩子告诉玩偶它是什么。

起步先用一种熟悉引导；后两种为补充活动话术，听不懂时先示范，不因换问法而误判句型不会。

游戏详细说明 补充设计

每层配一个可直接玩的活动。先看使用信号，选孩子能参与的一层；不是六个游戏连做，也不是靠重复次数升级。

以下游戏为整理者根据本讲阶梯与已校核笔记原则设计的家庭补充活动，不是原视频中的固定游戏、逐字话术或标准教案。

共同准备：先选少量熟悉、看得清的单个可数物品。示例用梨、胡萝卜和兔子玩具／清晰图片；每次先确认双方看的是同一个对象。

基础游戏1 · 宝物亮相

这一层练什么：把眼前对象和名词对应起来；能指认或说一个词即可。

道具：一个熟悉物品或清楚的图片，例如一只梨；可配一个玩偶。

怎么玩

  1. 家长拿出梨，摆到孩子看得清的位置，先自然示范 It’s a pear.，不先考生词。
  2. 指着同一个梨问 What’s this?，留一点回应空间。孩子说 pear、指向梨或拿给玩偶，都算参与。
  3. 家长接成完整表达 It’s a pear.，让玩偶看看或接过梨；是否再玩由孩子决定。

亲子口语

家长（拿出梨）
It’s a pear.
家长（指着梨）
What’s this?
孩子
Pear.（也可以先指认）
家长
Yes, it’s a pear.

卡住时怎么接：孩子不说时，不连续追问。保持梨可见，再指给他看并示范 It’s a pear.；需要时用熟悉语言明确对象。

只观察一件事：能否注意到当前对象并用指认或词回应，而不是跟着成人随口模仿？

进阶一游戏2 · 接话小快递

这一层练什么：借成人的句首支架，把熟悉名词接进 It’s a…；不用独立说整句。

道具：一只梨或一根胡萝卜、一个空盒子和玩偶；物品一直可见。

怎么玩

  1. 让玩偶扮演收快递的人，成人拿着梨示范 It’s a pear.，再把梨放进敞开的盒子。
  2. 下一次拿起梨时，成人看着物品说 It’s a…，停下等孩子接 pear。
  3. 接上就由成人自然补完整句 It’s a pear.，请孩子把梨递给玩偶。孩子只想递也可以，不把递物当语言考试奖励。

亲子口语

家长（展示梨）
It’s a…
孩子
Pear.
家长
It’s a pear.
孩子和家长（愿意时一起说）
It’s a pear.

卡住时怎么接：接不出名词，就先示范 pear 或整句；孩子不必同时说。词能接住后再试句首留白。

只观察一件事：在熟悉开头之后，孩子能否接上当前物品的词，而不是固定接上上一轮的词？

进阶二游戏3 · 玩偶来认物

这一层练什么：在当前物品清楚的前提下，减少句首提示，尝试独立说完整句。

道具：玩偶一个和一个孩子熟悉的物品，例如梨；先不加入新词。

怎么玩

  1. 让玩偶看向梨，成人借玩偶问 What’s this?；让孩子明确是在向自己询问梨。
  2. 先不抢着给 It’s a… 的开头，留出回应机会。孩子愿意时自己说 It’s a pear.。
  3. 成人回应 Yes, it’s a pear.，再让玩偶轻轻点头或把梨放好；不要求每答一次都重复。

亲子口语

玩偶（成人代言）
What’s this?
孩子
It’s a pear.
玩偶（成人代言）
Yes, it’s a pear.

卡住时怎么接：孩子只说 pear，先回应 Yes, it’s a pear.。下一次需要时补回 It’s a…，而不是一直等到孩子说出来。

只观察一件事：能否比上一层少依赖一点句首帮助？独立说了一次，不等于以后每次都必须独立。

进阶三游戏4 · 换序找朋友

这一层练什么：对象和顺序变化时，根据眼前物品替换名词，避免背固定顺序。

道具：少量熟悉物品或清晰图片，例如梨、兔子、胡萝卜；不加入未学过的词。

怎么玩

  1. 先单独拿出一个对象，确认孩子认识；再逐个给其他熟悉对象亮相。
  2. 成人改变呈现顺序，每次只突出一个对象并问 What’s this?，不让孩子猜下一张。
  3. 可由孩子决定接下来展示哪一个；成人跟着同一对象问，孩子用原来的句型换名词。

亲子口语

家长（展示兔子）
What’s this?
孩子
It’s a rabbit.
家长（换成梨）
What’s this?
孩子
It’s a pear.
家长（再展示胡萝卜）
What’s this?
孩子
It’s a carrot.

卡住时怎么接：换词卡住就暂减物品数量，指清当前对象；需要时示范这个名词或提供句首。不要用固定轮流顺序代替真正看对象。

只观察一件事：改变出现顺序后，能否依据当前对象说话，而不是继续报上一轮的词？

进阶四游戏5 · 生活找同伴

这一层练什么：把卡片里的表达带到真实物品、玩具或绘本，不增加新句型。

道具：一张梨的图片和一只真梨；也可使用兔子图片与兔子玩具。材料安全、适合孩子操作。

怎么玩

  1. 先展示熟悉图片并沿用 It’s a pear.，再拿出真实的梨，让孩子看清二者指向同类对象。
  2. 指向真实的梨问 What’s this?；孩子说 It’s a pear. 时，成人自然承接。
  3. 邀请孩子把图片放到真梨旁边。之后在生活里再次遇见梨时再用同一句，不在同一轮增加颜色、数量或长描述。

亲子口语

家长（指向梨的图片）
It’s a pear.
家长（换成真梨）
What’s this?
孩子
It’s a pear.
家长
Yes, it’s a pear.

卡住时怎么接：换成实物后迟疑，就把图片与实物并排展示，成人重新示范；不因为孩子会说卡片，就认定实物上也必须马上会。

只观察一件事：换材料、换地点以后，是否仍理解这句话在说什么？需要的提示能否逐渐减少？

进阶五游戏6 · 轮到你问 Teddy

这一层练什么：回答较稳后，尝试交换问答角色；自主提问是可选拓展。

道具：一个玩偶和一个熟悉物品，例如胡萝卜；不把物品藏起来让人猜。

怎么玩

  1. 成人先演示一轮：对着玩偶问 What’s this?，再替玩偶回答 It’s a carrot.，让谁问谁答足够清楚。
  2. 把玩偶交给孩子，成人展示胡萝卜，邀请孩子来问；能问 What’s this? 就由成人回答。
  3. 若孩子更愿意回答，就交换回来。下一次再给提问机会，不把自己提问设为必须完成的关卡。

亲子口语

成人（对玩偶示范）
What’s this?
玩偶（成人代言）
It’s a carrot.
孩子（愿意时向成人问）
What’s this?
成人
It’s a carrot.

卡住时怎么接：孩子不知道轮到谁，就由成人持玩偶再演一次；也可把 What’s… 的开头留给孩子接 this，或暂时全部由成人问。

只观察一件事：孩子是否理解问与答的角色变化？不只是能否重复 What’s this? 的声音。

游戏使用边界

  • 指认、单词和完整句都可以是当前有效参与。先接住意思，再提供模型；不以说满整句换取物品，不强迫重说。
  • 一次只调一个主要难点：减少提示、换词或换场景。不要同时加入否定、复数、远近对比和自主提问。
  • 游戏是交流，不是记卡片顺序或猜隐藏物。对象没看清、词不熟时，先示范，不把猜不中当成句型不会。
  • 不设必须几分钟、几轮、几天过关；孩子不想玩就收尾。答对不必计分或换奖励，轮到孩子选择、摆放或让玩偶行动即可延续互动。

卡住时，怎么接

孩子只说 pear，先接住意思：Yes! It’s a pear.。下一轮给 It’s a… 的开头；能自己说时再退提示，不要求每次立刻重说。

使用边界

  • 起步先用熟悉的单个可数物品；成人按发音示范 a / an，例如 It’s an apple.，不先考规则。
  • 这轮不同时加入否定、复数和自主提问；进阶也包括少依赖提示、换场景，并非句子必须越来越长。

只观察这一件事：对象或顺序换了，能否少靠一点提示，说清它是什么？
