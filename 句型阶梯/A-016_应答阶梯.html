A-016 · 应答阶梯

There is…｜存在、句首、地点、复数分层搭桥

先看清“这里有什么”，固定 There is 连熟悉单数；地点短语与复数分别练，再按能力接回来。

阶梯为整理者编排，不是原课固定六级表；按使用信号选层，不按年龄或天数硬分，不要求每次走完。示例和引导话术含补充内容，非逐字引语。

多种问法与引导语

同一句型，不同问法可能在做不同的事。先选孩子听得懂的一种；以下应答是场景示例，不是唯一标准答案。

  1. 开放提问表格问法·规范示例

    What's on the table?

    可以这样回应There is a book on the table.

    让桌上的书清楚可见；回答 A book. 也是有效起步。

  2. 开放提问原页引导·补充应答

    What’s here?

    可以这样回应A book. / There’s a book.

    问这里有什么，可先答 A book.，成人示范 There’s a book.

  3. 开放提问原页引导·补充应答

    What’s in the box?

    可以这样回应There’s a book in the box.

    in 的关系与地点名词熟悉后再问盒里有什么。

  4. 判断核实原页引导·补充应答

    Is there a book in the box?

    可以这样回应Yes, there is. / No, there isn’t.

    较熟后核实是否存在，可答 Yes, there is. / No, there isn’t.

先选听得懂的问法；第三种问句及否定短答先由成人示范，不作首轮门槛。地点分支和复数分支可分别回访，不要求同轮长句。

层级使用信号核心任务随机组句／互动示例适合阶段
基础能注意到确实存在的熟悉物品生活中预热“这里有什么”指着书；孩子可先说 Book. / A book.，成人补模型。存在意思

进阶三短句较稳，当前空间关系尚需练先单练一种地点短语实物放入盒子：in the box；不同时考 on、under。地点短语
进阶四短句和地点短语分别较顺固定对象或地点，先分段再合句There’s a robot… + in the box → There’s a robot in the box.地点整合

卡住时，怎么接

先查存在意思、句首、复数、介词或长度，只补当前一处。长句可成人说 There’s a robot，孩子接 in the box；复数难就先留单数，不从头重考。

使用边界

  • 某处存在用 There is / are，谁拥有用 have，不能把中文“有”全部套成 have。There’s 是 There is 的缩写；复数练 There are。
  • 过去、将来时、就近配合和全套介词暂不压给孩子。卡片、声音、现成容器可复用；不用危险物品放头上，也不用速度或固定年限判定会不会。

只观察这一件事：固定单数与熟悉名词后，孩子卡在句首还是地点连接？一次只让一个变量变新。
