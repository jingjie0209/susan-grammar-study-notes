# B-043｜It is easy｜应答阶梯

> 把整个 doing 活动当作主语进行评价，理解单数谓语、doing 带宾语和不同评价视角。

阶梯为整理者编排，不是原课固定六级表；按使用信号选层，不按年龄或天数硬分，不要求每次走完。示例和引导话术含补充内容，非逐字引语。

## 家长引导（三种，按阶段选用）

- **Is reading easy?** — 活动已体验或图片清楚时问，可答 Yes/No。
- **What is easy for you?** — 让孩子选熟悉活动，可先答单词。
- **Why is it easy?** — 评价稳定后追加理由，可答 because + 关键词。

先固定评价词换活动，再给 doing 加对象；主客观差异属成人理解层。

## 应答进阶总表

| 层级 | 使用信号 | 核心任务 | 随机组句／互动示例 | 适合阶段 |
| --- | --- | --- | --- | --- |
| 基础 | 能参与活动并判断 | 做动作、指图或 Yes/No | 孩子完成拼图，成人说 It’s easy. | 意义理解 |
| 进阶一 | 愿意接活动词 | 说熟悉 doing 词 | 成人 … is easy → 孩子 reading. | 词段接用 |
| 进阶二 | 能说活动评价句 | doing + is + easy | Reading is easy. | 整句表达 |
| 进阶三 | 能给 doing 加对象 | doing + 名词 | Reading this book is easy. | 对象扩展·可选 |
| 进阶四 | 能比较两个活动 | 用 easier / difficult 对比 | Running is easier than swimming. | 比较拓展·可选 |
| 进阶五 | 能补角色和理由 | for me / because | It’s easy for me because I’ve done it. | 观点扩展·可选 |

## 卡住时，怎么接

活动难就退回到实物和动作；说不出整句时只让孩子接活动词或 easy。

## 使用边界

- 单一动名词主语常用单数谓语。
- Doing is easy 与 It’s easy for me to do 侧重不同。

**只观察这一件事：**孩子是否把 easy/difficult 指向活动本身？
