# A-050｜It’s beautiful｜应答阶梯

> 先允许孩子表达自己的评价，再用颜色、形状或部位补一个理由；改画、复数和生活连接都是可选拓展，不要求统一审美答案。

阶梯为整理者编排，不是原课固定六级表；按使用信号选层，不按年龄或天数硬分，不要求每次走完。示例和引导话术含补充内容，非逐字引语。

## 家长引导（三种，按阶段选用）

- **Is it beautiful?** — 邀请评价，可答 Yes, it is. / No, it isn’t.，不强求和成人一致。
- **Why do you think it is beautiful?** — 评价已经表达且孩子愿意继续时再问，先接受一个颜色或形状理由。
- **How can we improve it?** — 愿意做创作或改变时再问，可先从两个选项中选一个。

Is it、Why 和 How can we improve…? 分别承担评价、理由和行动任务。成人先听孩子的理由，不把审美讨论变成唯一答案或外貌评价。

## 应答进阶总表

| 层级 | 使用信号 | 核心任务 | 随机组句／互动示例 | 适合阶段 |
| --- | --- | --- | --- | --- |
| 基础 | 能对图片或物品表达喜欢／不喜欢，理解 beautiful 的评价意义 | 允许点图、选 yes/no 或说 beautiful | It’s beautiful.；成人先尊重孩子的选择。 | 评价理解 |
| 进阶一 | 评价意思明确，整句还需成人支持 | 成人给 It’s，孩子接 beautiful | 成人：It’s… → 孩子：beautiful；不喜欢时也可说 No，成人示范否定。 | 评价词段 |
| 进阶二 | 能稳定说评价句，愿意换对象 | 只换熟悉对象，保持 be 与主语匹配 | The moon is beautiful. / The flower is beautiful. | 评价整句 |
| 进阶三 | 评价较顺，能说一个理由或例子 | 问 why，只要求一个颜色、形状或部位细节 | I think it’s beautiful. — I like its color. | 理由连接·可选 |
| 进阶四 | 能听见不同观点，愿意讨论改变 | 用一张纸画做一个小改动，不评价真实外貌 | How can we improve it? — Make it round. / Change the color. | 行动分支·可选 |
| 进阶五 | 能围绕多个对象分类并总结 | 另轮加入复数或 some/all，保持对象范围清楚 | Some are beautiful; some are not. / They’re all beautiful. | 复数总结·可选 |

## 卡住时，怎么接

孩子只说 blue、moon 或 no 时，成人自然补成句并继续听理由。若理由难想，先给二选一；改画只做一个小项目，不要求每次读图都产出作品。

## 使用边界

- 事实、感受和评价要分开；成人觉得不美不等于孩子必须改答，也不把审美判断迁移成对真实人物外貌的标签。
- Some are beautiful、They’re all beautiful 和 others/the others 的范围不同；复数是可选拓展，不与新词、理由和创作在第一轮同时强求。

**只观察这一件事：**孩子能否表达自己的评价、给出一个可观察理由，并听见另一种看法后提出一个愿意做的小行动？
