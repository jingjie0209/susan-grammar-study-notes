# B-017｜The monkey does it every day｜应答阶梯

> 固定角色与every day，少量更换熟悉动词；问句、否定与修饰另轮按需加入。

阶梯为整理者编排，不是原课固定六级表；按使用信号选层，不按年龄或天数硬分，不要求每次走完。示例和引导话术含补充内容，非逐字引语。

## 家长引导（三种，按阶段选用）

- **What does the toy monkey do every day?** — 先有明确故事日程，可答runs／It runs every day.。
- **Does the monkey run every day?** — 可短答Yes／Yes, it does.，成人不把runs放回does后。
- **Tell the puppet about the monkey’s day.** — 愿意讲时选用，不要求编完整日程或多动作。

先定义这是玩具故事；书页一次动作不等于每天发生，短答不必扩成四种变形。

## 卡住时，怎么接

漏三单时按意思自然重述；先固定动作与角色，不同时补长地点、频率词和否定。

## 使用边界

- does／doesn’t后原形；does it不是任何动词前都加does。
- 不用真人当坏人，不实演吐口水或危险动作，孩子不喜欢设定就换。

**只观察这一件事：**只换一个熟悉动作后，还能在单数角色句中逐渐保留动词变化吗？先完整示范，不盘问尾音。
