This is…｜看清“这一个”，再迁移到生活

让 this 与当前说话人清楚指向的近处对象对应，不只是替换句子开头。

阶梯为整理者编排，不是原课固定六级表；按使用信号选层，不按年龄或天数硬分，不要求每次走完。示例和引导话术含补充内容，非逐字引语。

多种问法与引导语

同一句型，不同问法可能在做不同的事。先选孩子听得懂的一种；以下应答是场景示例，不是唯一标准答案。

  1. 开放提问表格问法·规范示例 · 原页已有引导

    What's this?

    可以这样回应This is a ball.

    指近处的球；It’s a ball. 同样是自然回答，不按唯一句首判对错。

  2. 动作／表达邀请原页引导·补充应答

    Tell Teddy what this is.

    可以这样回应This is a book.

    请孩子向玩偶介绍手边这个东西。

  3. 判断核实原页引导·补充应答

    Is this a ball?

    可以这样回应Yes, it is. / No, it isn’t.

    陈述较熟后，核实是不是球。

原问法：What's this?

原答句：This is

原页三种引导及使用提醒

  • What’s this? — 明确指向近处的一个物品。
  • Tell Teddy what this is. — 请孩子向玩偶介绍手边这个东西。
  • Is this a ball? — 陈述较熟后，核实是不是球。

前两种用于命名，第三种用于“是不是”的核实，不能要求同一种回答。What’s this? 回答 It’s a ball. 也成立；本轮练 this 时，成人再示范目标句。

每层对应一个可直接玩的活动。先按使用信号选择当前能参与的一层，不要求六个游戏连续完成；可选层不作为必过关卡。

以下游戏为整理者依据本讲阶梯和已校核笔记原则设计的家庭补充活动，游戏名称、道具与对话不是原视频逐字记录，也不是老师规定的固定教案。

共同准备：准备手边清楚可见的玩具球、玩具蛋或图片。成人与孩子先共同注意一个对象；this 的指向以当前说话人为准。

基础游戏1 · 手边小展台

这一层练什么：找到当前明确指向的近处物品，先确认对象与物品词。

道具：一个玩具球和一块干净桌面。

怎么玩

  1. 把球放在双方手边、看得清的位置，成人指向球示范 This is a ball.。
  2. 继续指着同一个球问 What’s this?；孩子可以指球、摸到球或说 ball。
  3. 成人承接 This is a ball.，请孩子把球放在展台中央；不要求先说完才准碰。

亲子口语

成人（指球）
This is a ball.
成人
What’s this?
孩子
Ball.（或先指球）
成人
Yes. This is a ball.

卡住时怎么接：如果孩子不知道在指什么，先只留一个物品，手势落到物品上；不先增加英语问题。

只观察一件事：是否看向或找到成人当前指的近处对象，而不是随便摸一件？

进阶一游戏2 · 介绍接力棒

这一层练什么：借 This is a… 的句首提示，把熟悉名词接进句子。

道具：一个球、一个玩偶；不用真的接力棒。

怎么玩

  1. 成人把球放在自己手边，朝玩偶完整介绍 This is a ball.。
  2. 让孩子也把球放在自己的手边；成人提供 This is a…，孩子接 ball。
  3. 成人补完整句，愿意时一起再说；孩子可把球递给玩偶结束这一轮。

亲子口语

成人
This is a…
孩子
Ball.
成人
This is a ball.

卡住时怎么接：名词想不起来就直接给 ball；只说 It’s a ball. 也先接住，再示范 this 的目标句。

只观察一件事：有句首支架时，能否把当前物品词接上？

进阶二游戏3 · 我来介绍这一件

这一层练什么：面对随机出现的熟悉近处对象，逐渐少靠句首。

道具：玩具球、玩具蛋；不使用易碎鸡蛋。

怎么玩

  1. 先把球放在孩子近处，成人指清对象并问 What’s this?。
  2. 孩子愿意时独立说 This is a ball.；随后换成玩具蛋，仍保持对象近且清楚。
  3. 改变呈现顺序，由孩子选要介绍哪一个；先只换熟悉名词，不加颜色。

亲子口语

成人（指球）
What’s this?
孩子
This is a ball.
孩子（换成玩具蛋）
This is an egg.

卡住时怎么接：如果换物品就停住，先缩减到一个对象并给 This is a…；an egg 由成人按正确发音示范，不考冠词规则。

只观察一件事：物品换了，是否依然看对象组句，而不是每次都说 ball？

进阶三游戏4 · 绘本走进小桌面

这一层练什么：从卡片迁移到手边实物或绘本中指向清楚的目标。

道具：熟悉的球图片与玩具球；或一页只有清楚球图的绘本。

怎么玩

  1. 先在图片上指清球，成人示范 This is a ball.。
  2. 把玩具球放到孩子手边，用同样的指向和 What’s this? 邀请介绍。
  3. 之后在绘本里遇到球时指清单个目标，复用原句；不同时加远近对比。

亲子口语

成人（指图片）
This is a ball.
成人（指手边玩具）
What’s this?
孩子
This is a ball.

卡住时怎么接：换材料后不确定，就把图片与实物并排展示，成人重给整句；不是换材料后必须立即独立。

只观察一件事：离开原卡片，是否仍知道 this 具体指的是哪一个？

进阶四游戏5 · 玩偶确认一下

这一层练什么：陈述熟悉后，根据真实对象回答“是不是”，不强求长答。

道具：玩偶、玩具球和玩具蛋。

怎么玩

  1. 成人先演示玩偶指着手边球问 Is this a ball?，再自己回答 Yes, it is.。
  2. 让孩子回应同样清楚的问题；先说 Yes 也可以。
  3. 若孩子已理解否定，再指着蛋问 Is this a ball?；先接住 No，成人补 No, it isn’t.。

亲子口语

玩偶（指球）
Is this a ball?
孩子
Yes.
成人
Yes, it is.
玩偶（指蛋，后续可选）
Is this a ball?
孩子
No.

卡住时怎么接：听不懂问法时先回到成人自问自答；不把只会陈述直接当作听得懂核实。

只观察一件事：是否按眼前对象作判断，而不是把每个问题都当作继续报名词？

进阶五游戏6 · 换你当介绍人

这一层练什么：在问法听熟、回答较稳后交换问答角色。

道具：一个玩偶和近处的熟悉玩具球。

怎么玩

  1. 成人先拿玩偶演清谁问谁答，使用熟悉的 What’s this?。
  2. 成人指向自己手边的球，让孩子对成人或玩偶发问；成人据实回答。
  3. 若孩子更愿意介绍或回答，就交换回来；核实问句另次再试，不一次加两种。

亲子口语

成人（先示范）
What’s this?
玩偶（成人代言）
This is a ball.
孩子（愿意时）
What’s this?
成人
This is a ball.

卡住时怎么接：孩子只想说答案就继续让他回答；需要时由成人说问句开头，或整句代言，不催独立发问。

只观察一件事：是否理解“我问你答”的角色变化，而不只是重复成人最后一句？

游戏使用边界

  • What’s this? 是命名，Is this a ball? 是核实。It’s a ball. 也是正确命名回应；练 this 时由成人自然补目标模型，不判孩子全错。
  • 先分轮复习 This is… 与 It’s…；陈述较稳后才引入核实，不把否定、复数和自主提问同时叠加。
  • 接住指认、动作、单词或其他正确回应，不以说满目标句换取物品；不催答、罚重说或把得分与奖励设为参与条件。
  • 一次只改变一个主要难点；不按年龄、固定轮数、秒数或天数升级。孩子不愿意继续就收尾，下次按实际反应选层。

原课依据与回看时间见下方“来源与回看”；游戏名称、道具、步骤和对话由整理者补充，未增加未经核实的原视频时间点。

卡住时，怎么接

只说 ball 时给 This is a…；说 It’s a ball. 时先认可意思，再示范 this。困难就一起说，不连续追问来考孩子。

使用边界

  • 先一轮练 This is…、另一轮复习 It’s…；两者都较稳后，再在清楚情境中练选择，不逐卡突袭切换。
  • 否定回答可以先 No，再接 No, it isn’t.；不是要求进阶四一次掌握全部问句、否定和复数。

只观察这一件事：换到手边实物或绘本中的清楚目标，还能理解并指认“这一个”吗？
