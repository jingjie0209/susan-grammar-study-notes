A-002 · 应答阶梯

This is…｜看清“这一个”，再迁移到生活

让 this 与当前说话人清楚指向的近处对象对应，不只是替换句子开头。

阶梯为整理者编排，不是原课固定六级表；按使用信号选层，不按年龄或天数硬分，不要求每次走完。示例和引导话术含补充内容，非逐字引语。

家长引导（三种，按阶段选用）

  • What’s this? — 明确指向近处的一个物品。
  • Tell Teddy what this is. — 请孩子向玩偶介绍手边这个东西。
  • Is this a ball? — 陈述较熟后，核实是不是球。

前两种用于命名，第三种用于“是不是”的核实，不能要求同一种回答。What’s this? 回答 It’s a ball. 也成立；本轮练 this 时，成人再示范目标句。

应答进阶总表

先看使用信号，再选当前能参与的一层；问答拓展可以暂缓。
层级使用信号核心任务随机组句／互动示例适合阶段
基础能找到成人指的那个近处物品确认指向与物品词指一指／ball；成人示范 This is a ball.指认起步
进阶一名词会说，句首还需要帮助用开头支架成句成人：This is a… → 孩子：ball；一起连句。辅助成句
进阶二能在帮助下说，开始想自己说随机换熟悉对象This is a ball. / This is an egg.独立组句
进阶三卡片上能说，离开卡片不稳定把近处指认带到绘本和日常拿近处玩具球介绍：This is a ball.场景迁移
进阶四理解陈述，也开始听懂核实回答一般疑问，按需补完整Is this a ball? — Yes. → Yes, it is.；不是时：No, it isn’t.核实问答·可选
进阶五回答较稳，愿意当提问者交换角色，自己发问孩子：What’s this? / Is this a ball? → 成人回答。角色互换·可选

卡住时，怎么接

只说 ball 时给 This is a…；说 It’s a ball. 时先认可意思，再示范 this。困难就一起说，不连续追问来考孩子。

使用边界

  • 先一轮练 This is…、另一轮复习 It’s…；两者都较稳后，再在清楚情境中练选择，不逐卡突袭切换。
  • 否定回答可以先 No，再接 No, it isn’t.；不是要求进阶四一次掌握全部问句、否定和复数。

只观察这一件事：换到手边实物或绘本中的清楚目标，还能理解并指认“这一个”吗？
