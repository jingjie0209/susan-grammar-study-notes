It’s not…｜先懂“不是”，拆小否定再撤提示

用熟悉物体理解否定，把难发的缩写或长句拆开，不把卡在发音当成整项不会。

阶梯为整理者编排，不是原课固定六级表；按使用信号选层，不按年龄或天数硬分，不要求每次走完。示例和引导话术含补充内容，非逐字引语。

多种问法与引导语

同一句型，不同问法可能在做不同的事。先选孩子听得懂的一种；以下应答是场景示例，不是唯一标准答案。

  1. 判断核实表格问法·规范示例 · 原页已有引导

    Is it an apple?

    可以这样回应No, it isn't.

    眼前是船。先接受摇头或 No，再示范短否定；It’s a boat. 可由成人补充，不要求一口气连说。之后按实物交叉判断，避免每轮背 No。

  2. 判断核实原页引导·补充应答

    Is it a boat?

    可以这样回应Yes, it is.

    否定较稳后用于肯定对照；不是每题都要说 No。

  3. 角色转述原页引导·补充应答

    Ask Teddy: Is it an apple?

    可以这样回应（孩子对玩偶）Is it an apple?

    成人借玩偶先演清谁问谁答；孩子不必立即自己提问。

基础游戏1 · 摇头说 No

这一层练什么：先表达否定意思，不把整句输出当参与门槛。

道具：一只熟悉的船玩具；苹果只作为错误名称，不必额外摆满桌面。

怎么玩

  1. 成人指着船问 Is it an apple?，让实际对象与问法都明确。
  2. 孩子知道不是，可以摇头或说 No，成人马上接住否定意思。
  3. 成人示范 No, it is not. It’s a boat.；后一句是成人补充，不要求孩子一起说。

亲子口语

成人（指船）
Is it an apple?
孩子
（摇头）／No.
成人
No, it is not. It’s a boat.

卡住时怎么接：若孩子不知道 apple 或 boat，先直接命名熟悉物品；没看懂错在哪里时，不先考否定。

只观察一件事：孩子是否确实在说“不是这个名称”，而不是只跟着摇头？

进阶一游戏2 · 接话小尾巴

这一层练什么：理解否定后，成人只留 not 这个最小部分。

道具：一只熟悉的船玩具。

怎么玩

  1. 指船问 Is it an apple?，先确认孩子知道不是苹果。
  2. 成人带出 No, it is…，停下来让孩子接 not。
  3. 成人完整重复 No, it is not.，不把名词短语接给孩子增加负担。

亲子口语

成人（指船）
Is it an apple?
成人（接话支架）
No, it is…
孩子
Not.
成人
No, it is not.

卡住时怎么接：not 难接就由成人说完；孩子说 No 已经有效，不为完成末词而罚重说。

只观察一件事：孩子能否把 not 接到否定意思上，而不只模仿一个孤立尾音？

进阶二游戏3 · 连词小火车

这一层练什么：把 is not 连为短段，减少一个词的帮助。

道具：原来的船玩具，可用两张空白纸象征词块，不要求认字。

怎么玩

  1. 先回顾完整的 No, it is not.，明确现在仍在谈这只船。
  2. 成人说 No, it…，孩子愿意时接 is not。
  3. 成人再自然连成短答；这一层不加 an apple 或 a boat 让句子变长。

亲子口语

成人（指船）
Is it an apple?
成人
No, it…
孩子
Is not.
成人
No, it is not.

卡住时怎么接：两词连不上就退回只接 not，或成人放慢示范；纸张只是游戏道具，不要求儿童读词卡。

只观察一件事：is not 这段是否比上一层更能连起来，同时仍表达否定？

进阶三游戏4 · 真假小侦探

这一层练什么：减少句首支架，独立说短否定。

道具：熟悉的船或猫玩具；成人每次指清一个对象。

怎么玩

  1. 孩子当侦探，成人指船故意问错误名称 Is it an apple?。
  2. 孩子独立判断，愿意时答 No, it is not.；只说 No 也先接住。
  3. 让孩子指出真实物品或把它摆到侦探桌，成人可补 It’s a boat.；不设积分换奖励。

亲子口语

成人（指船）
Is it an apple?
孩子
No, it is not.
成人
It’s a boat.

卡住时怎么接：独立说不出时补回 No, it… 或完整模型；不把“侦探”角色变成不能求助的考试。

只观察一件事：没有句首帮助时，能否作出有意义的否定，而不是只背 No 的声音？

进阶四游戏5 · 否定变变变

这一层练什么：可选：只选缩写或熟悉名词补语的一项。

道具：熟悉的船玩具；可以让玩偶用不同声音示范。

怎么玩

  1. 指船问 Is it an apple?，先让孩子按已有形式回应。
  2. 本轮只示范一个新形式：No, it isn’t.；若选择描述方向，则另轮示范 It’s not an apple.。
  3. 孩子选够得着的一种表达即可，不要求三种形式连说或轮流背。

亲子口语

成人
Is it an apple?
孩子（选短否定）
No, it isn’t.
成人（另一轮可选示范）
It’s not an apple.

卡住时怎么接：isn’t 难就保留 is not；名词补语难就保留短答。换玩偶声音可以增加趣味，不必增加句长。

只观察一件事：选择另一形式时，是否仍在表达真实的“不是”，而不是只机械换缩写？

进阶五游戏6 · 玩偶小考官

这一层练什么：可选：否定与旧肯定都稳后，按同一实物交叉判断。

道具：两个玩偶与清楚可见的船玩具。

怎么玩

  1. 成人借玩偶演清问答：指船问 Is it a boat?，回答 Yes, it is.。
  2. 另一个玩偶仍指船问 Is it a cat?，让孩子按实际对象说 No, it isn’t.；不固定一真一假的顺序。
  3. 孩子愿意时才接过提问角色；不愿自己问时，成人继续提问就可以。

亲子口语

玩偶甲（指船）
Is it a boat?
孩子
Yes, it is.
玩偶乙（仍指船）
Is it a cat?
孩子
No, it isn’t.

卡住时怎么接：混合后只会背 No 就先回到成人自问自答或分轮肯否定；不要用快速出题测反应。

只观察一件事：孩子是否按实物选择肯定或否定，而不是对每个问题都背 No？

游戏使用边界

  • 参考家长提供的六层游戏结构，但不用积分或奖品迫使输出；以实际对象和孩子能接住的支架为准。
  • No, it’s a boat. 等正确回应先接住意思，再示范目标形式；It is not / It isn’t / It’s not 不要求同轮全部掌握。
  • 接住指认、动作、单词或其他正确回应，不以说满目标句换取物品；不催答、罚重说或把得分与奖励设为参与条件。
  • 一次只改变一个主要难点；不按年龄、固定轮数、秒数或天数升级。孩子不愿意继续就收尾，下次按实际反应选层。

卡住时，怎么接

isn’t 难就用 is not，长句难就暂不连名词；成人给到孩子能接住的一段。提示可撤也可补回，玩偶代言、放慢或换声调均不必加长句子。

使用边界

  • No, it’s a boat. 在合适情境中是正确回应，只是没练到目标否定形式；先承接意思，再提供模型，不说“全错”或用惩罚逼重说。
  • It is not / It isn’t / It’s not 都有适用情境；不要求同轮掌握全部形式。混合时看是否按实物判断，别只数目标句重复了多少次。

只观察这一件事：孩子是在表达“不是”，还是对每个问题都背 No？困难在哪一小段，帮助就给到哪里。
