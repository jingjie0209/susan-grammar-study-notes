A-009 · 应答阶梯

It’s not…｜先懂“不是”，拆小否定再撤提示

用熟悉物体理解否定，把难发的缩写或长句拆开，不把卡在发音当成整项不会。

阶梯为整理者编排，不是原课固定六级表；按使用信号选层，不按年龄或天数硬分，不要求每次走完。示例和引导话术含补充内容，非逐字引语。

家长引导（三种，按阶段选用）

  • Is it an apple? — 眼前是熟悉的船时，示范“不是”。
  • Is it a boat? — 否定较稳后用于肯定对照；不是每题都要说 No。
  • Ask Teddy: Is it an apple? — 成人借玩偶先演清谁问谁答；孩子不必立即自己提问。

先让对象与问法清楚，再集中练否定；第二种为后续交叉判断，第三种为补充角色话术。否定表达有多种正确形式，不按唯一句子判交流对错。

应答进阶总表

先看使用信号，再选当前能参与的一层；问答拓展可以暂缓。
层级使用信号核心任务随机组句／互动示例适合阶段
基础认得对象，知道成人说法不符合先表达否定意思摇头／No；成人示范 No, it is not.意思起步
进阶一理解“不是”，长串声音难接成人留最小的否定词成人：No, it is… → 孩子：not。末词支架
进阶二not 可接，愿意多说一点把 is not 连起来成人：No, it… → 孩子：is not。短段连接
进阶三短段较顺，可减少句首帮助独立说短否定，不急加名词Is it an apple? — No, it is not.独立否定
进阶四短回答较稳，愿意再拓一项选一项：缩写或熟悉名词补语No, it isn’t.；或描述：It’s not an apple.形式拓展·可选
进阶五否定和旧肯定均较稳按实际对象交叉选择回答同一条船：Is it a boat? — Yes, it is.；Is it a cat? — No, it isn’t.交叉判断·可选

卡住时，怎么接

isn’t 难就用 is not，长句难就暂不连名词；成人给到孩子能接住的一段。提示可撤也可补回，玩偶代言、放慢或换声调均不必加长句子。

使用边界

  • No, it’s a boat. 在合适情境中是正确回应，只是没练到目标否定形式；先承接意思，再提供模型，不说“全错”或用惩罚逼重说。
  • It is not / It isn’t / It’s not 都有适用情境；不要求同轮掌握全部形式。混合时看是否按实物判断，别只数目标句重复了多少次。

只观察这一件事：孩子是在表达“不是”，还是对每个问题都背 No？困难在哪一小段，帮助就给到哪里。

来源与回看

  • 约 05:20–07:55：缩写拆开、回答缩短；不立即连后面的名词短语。
  • 约 25:25–30:10：按反应补提示；另一正确回答不判错；稳定后交叉及迁移。
