# A-011｜I can see many things｜应答阶梯

> 用已经认识的名词练复数，先固定 I can see；many、具体数量和新句首不同时加。

阶梯为整理者编排，不是原课固定六级表；按使用信号选层，不按年龄或天数硬分，不要求每次走完。示例和引导话术含补充内容，非逐字引语。

## 家长引导（三种，按阶段选用）

- **What can you see?** — 问看见什么，可先答 Books.，再示范整句。
- **Can you see any books?** — 核实有没有看见书，可答 Yes, I can.
- **How many books can you see?** — 能点数后再问数量，可答 Three.；不以 many 代替准确数量。

三种问法分别问内容、能否看见和数量，并非同一答案的替换提示。先用熟悉问法；many 不是每句必加，数量分支可暂缓。

## 应答进阶总表

| 层级 | 使用信号 | 核心任务 | 随机组句／互动示例 | 适合阶段 |
| --- | --- | --- | --- | --- |
| 基础 | 能看出一件与多件，对象名称熟悉 | 实物对应复数，不先背规则 | 一辆车／多辆车：a car / cars。 | 数量意思 |
| 进阶一 | 知道是多个，复数词形还需模型 | 先说熟悉名词的复数 | books / cars / ducks；成人先核对词形与读音。 | 复数词 |
| 进阶二 | 复数词能接，句首仍需支持 | 固定句首，让孩子接复数 | 成人：I can see… → 孩子：books。 | 接话支架 |
| 进阶三 | 接话较顺，能少依赖提示 | 同一句首，分组随机换熟悉名词 | I can see books. / I can see ducks. | 复数整句 |
| 进阶四 | 整句较顺，当前数量意思已清楚 | 只加 many 或具体数量中的一项 | 许多书：I can see many books.；点数后：I can see three books. | 数量分支·可选 |
| 进阶五 | 原材料较稳，换场景仍能理解 | 绘本或生活中调用，逐渐撤提示 | 看池塘：I can see ducks.；遇到新词先由成人示范。 | 场景迁移 |

## 卡住时，怎么接

先查是没看清多个、词形不会，还是句首接不上。分别退到实物、books 或接话；many 难就去掉。固定其余部分，不用加做整套规则题。

## 使用边界

- many 接可数名词复数，不说 many juice。分组可按熟悉主题，不必把 s、es 规则轮番讲给孩子；不规则词由成人逐词核对。
- I can see books. 本身正确；They are books. 增加了主语与 be 配合，要另轮练，不作本讲必过关。听过一次或跟说过，不等于已经迁移。

**只观察这一件事：**去掉 many、固定 I can see 后，能否把熟悉名词的复数接上？先补词形还是句首连接？
